# 0061. 기술 카드 이름과 장비 희귀도 이름

- 날짜: 2026-11-12
- 단계: 코어 기획 (네이밍)
- 라운드: 장비 기획 다각도로 확장 스레드
- 상태: 수락됨 (Lucy 2026-11-12)
- 관련: 0018 카드 네이밍 규칙, 0055 대표 카드 변형, 0056 장비 규칙

## 맥락
전용 무기가 대표 카드 자리에 넣는 기술 카드와 장비 희귀도에 이름이 없었어요.

## 고려한 선택지
- 기술 카드: 대표 카드에서 한 걸음 바뀐 고유어 / 영어 · 판타지풍 명사와 친숙한 한자어.
- 희귀도: 일반 · 유니크 · 전설 / 일반 · 고급 · 희귀 / 노멀 · 유니크 · 레전드.

## Lucy의 결정
- 이름은 한글로만 띄워 짓지 않아도 돼요. 알맞은 영어, 판타지풍 명사, 친숙한 한자어를 써요. 한자어는 과하게 쓰지 않아요.
- 기술 카드 이름은 갈래마다 하나예요. 공명이 올라도 이름은 같아요.

| 정령 · 갈래 | 이름 |
| --- | --- |
| 불여우 · 터뜨리기 | 플레어 |
| 불여우 · 번짐 | 와일드파이어 |
| 유리 도롱뇽 · 받아내기 | 크리스털 월 |
| 유리 도롱뇽 · 되돌리기 | 글래스 엣지 |
| 안개 고양이 · 얼리기 | 화이트아웃 |
| 안개 고양이 · 지키기 | 미스트 베일 |

- 장비 희귀도 이름은 일반(범용) · 유니크(전용 무기) · 전설(보스 장비)이에요.

## 근거
- 지금 카드 이름(템퍼드 글래스, 리코셰, 스타더스트)과 같은 결이에요.

## 기각한 것과 이유
- 고유어로만 띄워 지은 이름(불씨 찌르기, 굳은 유리 등): 딱딱하게 읽혀요.
