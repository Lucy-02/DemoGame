# 0056. 장비: 정령마다 전용 무기 1개, 희귀도 셋, 지니는 수 1·1·2

- 날짜: 2026-11-11
- 단계: 코어 기획 (장비)
- 라운드: 장비 기획 다각도로 확장 스레드
- 상태: 수락됨 (Lucy 2026-11-11). 숫자는 `TODO_TOKEN`, 이름은 `TODO_NAME`
- 관련: 0048 정령 장비·공명(PR #59), 0049 전투 보상 구조(PR #59), 0055 대표 카드 변형
- 자료: 프로젝트 파일 `equipment-design/SLOTS.md`

## 맥락
장비 첫 묶음과 규칙의 크기를 정했어요.

## 고려한 선택지
- 전용 장비: 정령마다 갈래별 2개 / 정령마다 1개.
- 세분화: 정예·보스 등급 / 희귀도.
- 지니는 수: 유체 1 · 성체 2 · 각성체 3 / 유체 1 · 성체 1 · 각성체 2.
- 옮기기: 자유 / 휴식 칸에서만 / 못 옮김.

## Lucy의 결정
- **전용 무기는 정령마다 1개, 그림 1장.** 대표 카드를 바꾸는 기술은 정령의 갈래에 따라 달라요. 그림은 같아요.
- **희귀도 셋.** 범용(능력치만, 정예) · 전용 무기(대표 카드를 바꿈, 정예) · 보스 장비(규칙을 건드림, 대가 붙음, 보스). 같은 장비의 상위 버전은 없어요.
- **지니는 수는 유체 1, 성체 1, 각성체 2.**
- **런 끝에 남기는 수는 지닌 수와 같아요.** 지닌 장비를 그대로 가져갈지 골라요.
- **장비는 다른 정령에게 못 옮겨요.** 새 장비를 받을 때 그 자리에서 바꿔 낄 수 있어요. 런 끝에 남길지 골라요.
- **장비 그림은 무기에 가까운 형태.** 전용 = 정령 고유 무기, 범용 = 고전 무기·방어구, 보스 = 묵은 나무·돌의 무거운 무기.
- 첫 묶음은 전용 3 + 범용 6 + 보스 3 = 12개.
- 부위, 세트, 무작위 옵션, 강화 재료는 없어요. 성장은 공명 하나예요.

## 근거
- 정령마다 무기 하나라 "이 정령의 무기"가 바로 읽혀요.

## 기각한 것과 이유
- 갈래마다 다른 전용 장비·다른 그림: 갈래에 따라 장비 그림이 달라 보여요.
- 정예·보스 등급 이름: 나오는 곳일 뿐 플레이어에게 뜻이 없어요.
- 애착물·자연물 형태의 그림: 무엇에 쓰는지 안 읽혀요.

## 결과와 후속 작업
- 0055의 "전용 장비를 둘 지니면 2장이 서로 다른 기술", "전용 장비 하나는 갈래 하나와 묶인다"는 이 결정으로 바뀌어요. 전용 무기는 하나이고 기술이 갈래를 따라요.
- 고른 그림: 불여우 = 불꽃 날 창, 유리 도롱뇽 = 진홍 유리 가시 완갑, 안개 고양이 = 서리 부채. 그림 파일은 아직 레포에 없어요.
- 갈래별 기술 초안은 프로젝트 파일 `equipment-design/SLOTS.md`에 있어요. 여러 적에만 켜지는 효과는 두지 않고, 같은 대상에 겹치는 효과는 겹칠 때마다 줄어요.
- 정할 것: 희귀도 이름과 표시 색, 숫자.
- 규칙 코드·데이터: `growth.json`의 칸 수, `EquipDef`의 등급 필드, 갈래별 기술을 담는 필드.
