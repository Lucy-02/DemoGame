# 0043. 못 내는 카드는 카드째 회색으로 뿌옇게

- 날짜: 2026-11-07
- 단계: 카드 UI
- 상태: 수락됨 (Lucy, 2026-11-07 "카드 자체가 투명해지는 게 좋을 것 같고 좀 더 뿌얘지는 게 좋아 보임, 회색 필터로" → 보드 안 3 "안 3이 좋아 보이네")

## 맥락
정본(0007, `battle-r5`)과 게임(`HandCard.ts`)은 못 내는 카드의 틀을 밝은 회색으로 바꾸고 그림만 투명도 0.45로 낮춰요. 밝은 창이 비쳐 오히려 창백하고 밝아 보였어요.

## Lucy의 결정
- 카드 전체(틀·그림·숫자)에 필터를 걸어요: 회색조 1, 대비 0.7, 밝기 1.1, 투명도 0.62. 흐림은 넣지 않아요 (우윳빛, 보드 안 3).
- 비교 그림: 결과 보드 "비활성 카드: 카드째 회색으로 뿌옇게" (https://claude.ai/artifact/MW7rxJHEQiypJoAhS4a3kL).

## 정하지 않은 것 / 바뀌는 것
- 0007의 "못 내는 카드도 정령 얼굴은 컬러"와 부딪혀요. 고른 안 3은 얼굴과 "화상 필요" 이유 띠도 같이 흐려지는 그림이었어요. 얼굴·이유 띠를 필터에서 뺄지는 Lucy에게 다시 물어요. 그 전에는 고른 그림 그대로예요.
- 마력 부족 동전 테(빨강)도 회색이 돼요. 같은 질문에 묶어요.
- 반영할 곳: `design/canon/battle-r5/page.html`의 `.cd.off` 규칙, `HandCard.ts`의 `setAlpha(0.45)`와 `cardOff*` 토큰(`design/tokens/tokens.json` → `pnpm tokens`). 아직 안 고쳤어요.
