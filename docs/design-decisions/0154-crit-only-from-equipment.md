# 0154. 치명은 장비로만 생겨요

- 날짜: 2026-11-18
- 단계: P6 엔진 구현
- 라운드: 평가 1라운드 적용 (전투가 결과를 정직하게 말하기, P1-12)
- 상태: 수락됨 (Lucy 2026-11-18 "추천대로"). 밸런스 재확인 필요.

## 맥락
아군 공격마다 치명 5%(빗나가면 +2%p씩, 1.5배)가 숨어 있었어요. 화면 어디에도 없고 용어 모음에도 없어서, 카드 숫자와 조준 결과가 말한 값과 실제가 달랐어요.

## 결정
- **기본 치명 확률과 빗나감 보정을 없애요.** 치명은 치명 확률을 주는 장비(수치 · 패시브)를 지닌 정령만 터져요. 치명 피해 배율(1.5배)과 장비 글은 그대로예요.
- 치명 확률이 없는 타격은 난수를 쓰지 않아요.

## 결과와 후속 작업
- `src/data/constants.json`(`crit_base` · `crit_pity` 삭제), `src/core/stats.ts`, `src/core/battle/pipelines.ts`, `BSpirit.critPity` 삭제.
- 골든 스냅샷: 아군 피해 기대값이 약 2.5%+ 줄고 난수 흐름이 바뀌어 인카운터 요약과 보스전 로그가 바뀌었어요. 20시드 봇 기준 전체 승수 914→888/1400, 1막 보스 41→33/60.
- 남은 것: 1막 목표(0020)에 맞는지 다시 재기. 장비 치명이 있는 정령의 카드 숫자 · 조준 결과에 치명을 어떻게 보일지.
