# 0001. 리뷰 보드를 claude.ai 아티팩트로

- 날짜: 2026-10-28
- 단계: 작업 방식
- 상태: 수락됨

## 맥락
시안을 보고, 리뷰어 지적에 스레드로 답하며 토론할 공간이 필요했어요.

## 고려한 선택지
- claude.ai 아티팩트: 어디서나 링크로 보고 댓글로 토론. Send to Claude로 Claude 세션을 깨움
- 맥 로컬 Vite 보드: 완전 통제, 맥 앞에서만, 알림 구조를 따로 만들어야 함
- Figma/Penpot 중심: 직접 손으로 편집, 유료 좌석 또는 셀프호스트 필요

## Lucy의 결정
claude.ai 아티팩트. https://claude.ai/artifact/K2By7mr5uWaJYH4RNWbLJ8

## 결과와 후속 작업
- Claude는 새 댓글 스레드를 직접 열 수 없어서, 리뷰어 지적은 보드 `db`의 카드로 쓰고 Lucy가 카드에서 스레드를 열어요.
- 결정과 값의 원천은 이 저장소예요. 라운드가 끝나면 보드 내용을 결정 기록으로 옮겨요.
- 첫 라운드는 파일럿. Send to Claude 왕복이 매끄럽지 않으면 같은 카드 형식으로 로컬 보드로 옮겨요.
