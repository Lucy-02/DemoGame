# 0051. 전투 결과 화면에 새 보상 구조 얹기 = E1 가로 그대로

- 날짜: 2026-11-10
- 단계: 전투 결과(0044) 보완, 보상 라운드 E
- 상태: 수락됨 (Lucy 2026-11-10 "E1이 좋다", "안 받기 없음", "처음부터 보이기")
- 근거 자료: **E1 https://claude.ai/artifact/JY6nFw4GK2WCKFwtqo1Cdj** (프레임 `/mnt/project-files/design/round-e/E1/`) · E2 https://claude.ai/artifact/Ec5PKyy3XEuJ5cyFjhhyCL · 브리프 `design/concepts/BRIEF.md` "# 보상 라운드 E"
- 관련: 0044 전투 결과, 0050 게임다운 표현(폴리싱 P1), 장비 스레드의 0048 정령 장비·0049 전투 보상 구조(PR #59, 이 문서를 쓰는 시점에 `main`에 없음)

## 맥락
0049가 전투 보상을 바꿨어요: 카드 3장 = 파티 정령마다 전용 카드 1장씩, 넘기기 = 골드 조금, 정예 = 카드 + 장비 하나(누구에게 줄지 고름). 0049는 화면 모양을 "Lucy 컨펌 뒤"로 남겼고, 0044 화면에 어떻게 얹을지 두 안을 봤어요.

## 결정
- **E1 가로 그대로.** 카드 3장은 지금 크기로 왼쪽에 가로로, 왼→오 순서 = 정령 줄 위→아래 순서. 주인은 카드 초상 홈의 얼굴, 같은 순서, 집을 때 주인 줄 강조로 읽혀요(이름표 없음).
- **넘기기 골드**는 버튼 안에 동전 기호 + 숫자(값 `TODO_TOKEN`), 호버 시 위 띠 골드 a→b.
- **정예 장비 줄은 처음부터 보여요.** 카드 아래 한 줄(왼쪽 열 폭, 휴식·이벤트 선택지 판과 같은 높이). 고르는 순서는 카드 먼저, 장비 다음. 한 번에 하나만 활성이에요(줄이 동시에 두 뜻을 갖지 않게).
- **장비는 꼭 받아요.** 장비 단계에는 넘기기가 없어요.
- 장비를 줄 정령 고르기: 세 줄이 모두 대상이 되고 줄마다 장비 칸이 보여요. 줄에 올리면 그 칸에 장비가 비쳐 보이고 바뀌는 능력치에 `+n`. 고르면 그 줄에 들어가요.
- 장비의 그림·기호·이름·효과 숫자는 아직 없어요(`TODO_ICON`, `TODO_NAME`, `TODO_TOKEN`). 줄 안 장비 칸 위치(이름 줄 오른쪽 끝)와 지닐 수 있는 수는 장비 데이터가 정해진 뒤 다시 봐요.
- 다 받은 뒤 나가는 방식은 0044 그대로.

## 구현 메모
- 보상 생성(정령마다 1장)·넘기기 골드·장비는 `src/core`·`src/data` 규칙 작업이에요(0049 후속). 화면은 "카드 목록 + 주인"을 받아 그리게 만들어서 규칙이 바뀌어도 그대로 쓰게 해요.
- 장비 단계는 규칙이 생긴 뒤에 켜요. 그 전에는 일반 전투 보상(카드 + 넘기기)까지 연결해요.
- 빠른 두 번 클릭으로 장비가 카드 주인에게 바로 가지 않게 단계 사이 짧은 입력 막기(`TODO_TOKEN`).

## 기각
- E2 줄 맞춤(카드를 세로로 주인 줄 옆에): 카드 넓이가 절반으로 줄고 왼쪽이 크게 비며, 말풍선이 카드 옆으로 가야 해요.
- 장비 거절, 장비를 카드 고른 뒤에야 보여주기.
