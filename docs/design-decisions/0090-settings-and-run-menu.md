# 0090. 설정 창과 판 안 메뉴: 가운데 창 하나, 메인 화면 줄 그대로

- 날짜: 2026-11-17
- 단계: P2 정보 구조·흐름 / P6 엔진 구현
- 상태: 수락됨 (디렉터 판단, Lucy 위임 2026-11-17 "능동적으로 판단하여 진행"). Lucy가 번호로 뒤집을 수 있어요. 배치와 값은 Lucy 확인 대기예요.
- 앞 결정: 0084 3 · 4 · 5 · 6 · 7번 (무엇을 넣을지와 규칙). 이 기록은 모양과 연결을 정해요.
- 시안 캡처: `/mnt/project-files/settings-menu/` (A-menu · A-confirm · A-settings · B-menu · C-menu). 실제 화면 부품으로 그려 찍었어요.

## 결정
1. **판 안 메뉴는 가운데 창(A).** 전투 위 창 틀(0069) 안에 메인 화면 메뉴 줄을 그대로 써요. 맨 위 강조 줄 `계속`, 아래로 `설정` · `메인으로`, 한 칸 띄워 `탐험 포기`. Esc와 오른쪽 위 톱니로 열고, Esc · 창 밖 · `계속`으로 닫아요. 전투에서 Esc는 집은 카드가 있으면 내려놓기가 먼저예요.
2. **설정은 같은 틀의 창 하나.** 메인 화면의 설정과 판 안 메뉴의 설정이 같은 창이에요. 한 줄에 이름 왼쪽 · 조작 오른쪽. 순서는 소리(전체 음량 · 음악 · 효과음) → 화면(전체화면 · 화면 흔들림) → 재생 속도. 상태는 모양으로 보여요: 막대 길이 + 숫자, 알약 손잡이 자리, 밝은 칸. `켜짐` · `꺼짐` 글자는 없어요 (0019 · 0050).
3. **바꾸면 바로 반영하고 저장해요.** 적용 · 되돌리기 버튼은 없어요. 저장 키는 `settings` 하나이고 소리 층(0087)과 같이 써요.
4. **포기 확인은 메뉴 자리에서 창이 바뀌어요.** 제목 `탐험을 포기할까요?`, 버튼 `계속`(조용한 판) · `탐험 포기`(위험색 채움, 덱 고르기의 빼기 확인과 같은 짝). `메인으로`는 잃는 것이 없어서 확인 없이 나가요.
5. **풀이는 호버에만.** `메인으로`(이 칸의 처음부터 이어짐) · `탐험 포기`(패배로 끝남, 경험 · 장비 남음) · `재생 속도` · `화면 흔들림`에 말풍선을 달았어요.
6. **재생 속도 `빠르게` = 행동 하나 250ms.** Lucy가 턴 재생 시간을 고를 때 본 후보(250 · 450 · 700) 가운데 가장 짧은 값을 임시로 써요. 그동안의 토큰 · 유닛 모션과 소리 박자도 같은 비율(1.8배)로 빨라져요.
7. **창은 비율을 지키며 늘어나요.** 그리는 크기는 1280×800 그대로예요. 창 모드에서는 창이 16:10으로만 늘어나고(최소 640×400), 전체화면에서 남는 곳은 바닥색이에요. 전체화면은 설정 값이 정본이고 F11로 바꿔도 설정이 따라가요.
8. **화면 흔들림 끄기는 값만 저장해요.** 지금 게임에 흔들림 · 화면 번쩍임이 없어서 걸 곳이 없어요. 모션이 넣을 때 `settingsOf(scene)?.shake`를 봐요.

## 기각한 것과 이유
- B 왼쪽 세로 메뉴(메인 화면과 같은 자리): 전투 위에서는 줄이 정령 그림과 겹쳐 읽기 어렵고, 판 안의 다른 창(덱 보기 · 전투 결과)이 모두 가운데 창이에요.
- C 메뉴와 설정을 나란히 한 창: 메뉴를 열 때마다 설정 여섯 줄이 같이 보여요. 자주 쓰는 `계속` · `메인으로`보다 가끔 쓰는 설정이 더 넓어요 (LUCY_CRITERIA 2 · 8).
- 설정 묶음 제목(`소리` · `화면`): 라벨이라 가는 선으로만 나눴어요 (0050).

## 남은 것 (Lucy 확인 대기)
- `계속` · `메인으로` · `재생 속도` · `화면 흔들림` 낱말, `탐험 포기` 줄의 기호(지금은 빈 자리).
- 창 폭 · 줄 높이 · 막대 · 알약 크기(실제 화면에서 견준 임시 값), 빠르게 250ms.
- 큰 화면에서 늘이면 글자가 조금 흐려요. 고해상도로 그리기는 뒤로 미뤘어요 (0084 11번 묶음).
