# 0161. 카드는 두 얼굴: 작은 얼굴은 그림 + 수치, 큰 얼굴은 유리 판에 효과문

- 날짜: 2026-11-20
- 단계: P6 엔진 구현
- 라운드: 카드 라운드 K · K2 (프로젝트 스레드 "카드 정보 위계 다시 잡고 리디자인")
- 상태: 수락됨 (Lucy 2026-11-20 "그래 그렇게 하자" · "좋네 추천대로 가자"). 크기 · 색 · 시간 값은 시안 임시 값
- 시안: L1 https://claude.ai/artifact/9UzXGeVYwJi6JkwwwsS55B (라운드 전체는 `design/concepts/LINKS.md`)

## 맥락
Lucy: 초상과 그림 사이 왼쪽 아래 빈 곳이 어색하고, 강화 단계 · 속성 표시가 여러 번 나와 정보 압박이 심해요. 평소 카드와 자세히 볼 때의 정보 위계부터 나누고 다시 그려요.

## 결정
- **정보 위계**: 작은 얼굴에는 비용 · 그림 · 최종 수치 · 이름만. 효과문 · 주인 · 속성 · 희귀도 · 강화 여부는 큰 얼굴에, 주인 · 속성 · 희귀도 이름, 계산, 강화하면 바뀌는 효과문, 용어 풀이는 곁쪽지에 둬요. 주인은 손패 묶음과 덱 줄의 머리가 말해요.
- **작은 얼굴** (손패 · 덱 보기, 90×126): 그림이 카드 전체, 아래 어두운 띠에 기호 + 수치(16px)와 이름. 초상 홈 · 그림 창 윗선 · 이름 띠 재질 · 속성 기호 · 희귀도 보석 · 숫자판은 없어요.
- **큰 얼굴** (172×248): 그림 위 유리 판(짙게, 높이는 효과문 네 줄 자리로 고정)에 이름 줄 · 효과문 · 기호 줄(주인 얼굴 · 속성 · 희귀도 · 강화 화살). 보상 · 상점 · 전투 고르기 창은 처음부터 큰 얼굴이에요.
- **가리킬 때**: 손패의 카드는 그 자리에서 큰 얼굴(1.2배)로 펼쳐져요. 이름 줄 끝에 최종 수치, 못 내는 사유는 윗선 가운데 표지. 집은 카드는 작은 얼굴 그대로 떠올라요. 다른 화면의 작은 얼굴은 가리키면 큰 얼굴이 위나 옆에 떠요.
- **곁쪽지**: 큰 얼굴에 머물면(0.5초) 옆에 유리 쪽지가 떠요. 키는 쓰지 않아요.
- **오른 수치**: ▲ 대신 숫자 색으로 알려요(능력치 · 강화 모두).
- **강화한 카드**: 덱 보기 · 휴식 · 덱에서 고르기의 작은 얼굴에만 수치 옆 화살 기호. 손패 · 보상 · 상점의 작은 얼굴에는 없어요(큰 얼굴 기호 줄에는 있어요).
- **못 내는 카드**: 작은 얼굴은 몸이 회색, 비용 동전(마력 부족이면 붉은 테)과 오른쪽 위 표지(자물쇠 + 필요한 조건)는 또렷하게(0043 그대로). 큰 얼굴은 그림만 회색이고 글은 그대로 읽혀요. 상점에서 골드가 모자란 카드도 같아요.

## 버린 것
- K2 이름 띠의 주인, K3 숫자 단, L2 유리 손패 + 종이 읽기, L3 종이 두 얼굴.
- Alt 키로 여는 곁쪽지.
- 종이 말풍선(카드 위 꼬리 달린 판), 속성 재질 띠와 재질 이름, 손패 들기 크기 비교(`?lift=`).

## 남은 것
- 준비된 카드의 받침 줄 · 지속 · 소멸 표지는 규칙 쪽 값이 화면에 오면 붙여요.
- 값(크기 · 색 · 유리 불투명도 · 0.5초)은 시안에서 옮긴 임시 값이에요. 상점 행 자리(첫 행 y 80, 행 사이 44)는 떠나기 버튼과 겹치지 않게 잡았어요.
- 판 결과 · 깃들기 · 갈래 고르기의 키운 카드는 작은 얼굴을 키운 그대로예요.
