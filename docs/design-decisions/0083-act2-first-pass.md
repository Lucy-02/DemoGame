## 넣은 것

| 영역 | 결정 |
| --- | --- |
| 방전 칸 | 적이 시간축에 구간을 깔아요. 그 안에서 끝나는 카드의 주인이 피해를 받고, 깐 적이 쓰러지면 꺼져요 (`EnemyMove.zones` · `zoneDmg`, `Battle.zones`) |
| 땅속 숨기 | 땅속에 있는 적은 피해를 받지 않고, 다음 행동 때 올라와요 (행동 `burrow`, 상태 `burrow`, `Battle.buriedAt`) |
| 주변 적 가속 | 살아 있는 동안 다른 적의 행동이 빨라져요 (`EnemyDef.haste`) |
| 첫 타격 되돌리기 | 턴마다 처음 받은 타격의 일부를 적 대신 때린 정령이 받아요 (`EnemyDef.reflectFirst`) |
| 막 넘기기 | 마지막 막이 아닌 보스를 이기면 정예와 같은 보상을 받고 다음 막 지도로 가요. 새 지도 · 그 막의 센 기운 · 모든 정령 회복 (`Run.nextAct`, `constants.json` `acts` · `act_heal_pct`) |
| 2막 적 | 잡몹 일곱, 정예 셋, 보스 셋. 편성 열다섯 (`encounters.json` `act: 2`) |
| 전기 기운 | 규칙 코드의 기운 목록에 `electric`을 더했어요 |

- **실제 게임은 아직 1막에서 끝나요** (`constants.json` `acts_enabled: 1`). 새 규칙 넷을 화면에 어떻게 보일지 시안이 먼저예요. 시험은 `?screen=legacy&acts=2`와 `pnpm runsim … --acts 2`.

## 1막에서 같이 바꾼 것 (파티 편차, 0076 4번)

- 몰아 치기로 틈이 열리는 문턱: 최대 HP의 15% → 12% (`gap.burst_pct`). 끊는 카드가 없는 파티도 틈을 열 수 있게.
- 칼바람 늑대 무리: 새끼 피해 6 → 5, 찢기 7 → 6, 울부짖기 +3 → +2.
- smart 봇이 카멜레온의 받아칠 기회와 숨기를 값으로 치게 했어요. 봇이 기믹을 몰라 낮게 나오던 몫이에요.

- 2막 적의 HP · 피해가 1막과 같은 수준이에요(보스 HP 132 ~ 146, 1막은 145 ~ 200). 판 안에서 파티가 세지는 폭(카드 · 장비)이 작아서, 숫자를 더 올리면 2막 첫 전투에서 막혀요.

## Lucy 확인 대기

1. **막 사이 회복은 전부** (`act_heal_pct: 1`). 30%로는 2막 통과가 18%였어요.
2. **2막 목표 수치.** 지금은 "1막을 넘긴 smart의 절반이 2막을 넘김"에 맞췄어요.
3. **막이 갈수록 세지게 하려면 판 안 성장이 더 필요해요.** 지금은 2막이 숫자가 아니라 규칙으로만 어려워요.
4. **2막 기운의 상성.** 땅 · 전기 · 빛은 상성표(`affinity_beats`)에 아직 없어요. 세계 문서의 고리(숲 > 땅 > 전기)를 넣으면 지금의 숲 > 물과 부딪쳐요.
5. **이름.** 2막 적 열셋과 기술 이름은 모두 임시예요 (`design/canon/naming/TODO_NAMES.md` 2절).
6. **화면.** 방전 칸 · 땅속 · 되돌리기 · 가속을 어떻게 보일지 시안이 필요해요.
