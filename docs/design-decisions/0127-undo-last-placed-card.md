# 0127. 놓은 카드 되돌리기: 놓기 직전 상태로 돌아가기

- 날짜: 2026-11-18
- 단계: P6 엔진 구현
- 라운드: 평가 1라운드 적용 (전투가 결과를 정직하게 말하기, P2-02)
- 상태: 규칙은 0074 7번(Lucy 2026-11-16) 그대로. 배지 기호만 임시, Lucy 확인 대기.

## 맥락
0074 7번이 "마지막에 놓은 카드만 되돌림"을 정했지만 전투 규칙에 없었어요. 0084 8번은 되돌리기가 있다는 전제로 턴 종료 확인을 넣지 않았어요.

## 결정
- **되돌리기 = 놓기 직전 상태로 돌아가기.** 놓을 때마다 직전 상태를 떠 두고, 되돌리면 그대로 돌려놓아요(마력 · 손패 · 놓는 즉시 처리된 효과 · 연속 횟수). 해방도 같아요. 거꾸로 하나씩 되돌려요.
- **새 정보를 연 놓기는 되돌릴 수 없고, 그 앞으로도 못 돌아가요**: 카드를 뽑았거나, 난수를 썼거나, 낙하 고르기가 열렸을 때. 낙하를 고른 뒤와 턴 종료 뒤에도 기록을 비워요.
- **조작**: 순서표에서 마지막에 놓은 토큰을 누르면 되돌려요. 그 토큰 오른쪽 위에 되돌리기 배지가 떠요(0074 토큰 그리기 규칙).
- 배지 기호는 있는 기호(`g-back`)를 빌린 임시예요 (TODO_ICON).

## 기각한 것과 이유
