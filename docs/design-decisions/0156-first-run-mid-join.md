# 0156. 첫 판 3층 뒤 둘째 정령 합류

- 날짜: 2026-11-18
- 단계: 코어 기획 (얻는 순서 · 균형)
- 라운드: 프로젝트 스레드 "판 안에서 덱 짓는 이유 세우기"
- 상태: 수락됨 (Lucy 2026-11-18 결정 카드 "혼자 출발, 3층 뒤 둘째 합류")
- 앞 결정: 0053 (얻는 순서), 0132 (보상 카드 · 길 피해), 0155 (막별 세기)

## 결정
1. 혼자 떠난 첫 판은 1막 **3층**(`constants.run_pool.join_floor`)을 마치고 지도로 돌아오면 둘째 정령이 깃들어요. 고르기는 판 끝 깃들기와 같은 화면이에요.
2. 깃든 정령은 **바로 그 판에 합류**해요: 유체, 꽉 찬 HP, 그 정령의 시작 덱을 들고 와요. 적 세기는 그때부터 둘에 맞춰요(0053).
3. 판 가운데서 깃들었으면 첫 판 끝에는 더 깃들지 않아요. 셋째는 그대로 첫 보스 뒤예요.

## 남은 것
- 첫 판 목표(0098)와 둘 파티 세기는 "적과 스테이지" 스레드가 이 값 위에서 다시 맞춰요.
- 새 화면은 없어요. 깃들기 화면을 그대로 써요. 골든 스냅샷은 그대로예요.
- 시뮬레이터는 혼자 떠난 유체 판에 이 규칙을 기본으로 걸어요(`--whatif nojoin`으로 끄기).
