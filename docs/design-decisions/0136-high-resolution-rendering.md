# 0136. 큰 모니터에서 배수만큼 촘촘히 그리기, 창 최소 크기, 글자 대비 재기, 번역 경계

- 날짜: 2026-11-18
- 단계: P6 엔진 구현
- 라운드: 평가 1라운드 적용 묶음 F (입력 · 접근성 · 해상도)
- 상태: 수락됨 (화면 모양이 바뀌지 않는 고침). 색 값 · 받침 · 낱말은 시안으로 Lucy가 골라요.
- 앞 결정: 0084 4번(16:10으로 늘이기), 0090 남은 것(고해상도 미룸), 0102(가장 작은 글자 12px).
- 평가 지적: P7-03 · P8-07(고해상도), P7-04 · P7-15(대비 · 창 크기), P7-10 · P7-11(번역 경계 · 긴 글).

## 맥락
캔버스가 1280×800 고정이라 1920×1080에서 1.35배, 4K에서 2.7배, 레티나에서 2배로 늘려 그려 글자와 그림이 흐렸어요.

## 고려한 선택지
- 모니터 크기로 배수를 한 번 고르고 카메라가 키워 그리기
- 창 크기가 바뀔 때마다 배수 다시 고르기
- 그림만 2배로 넣기

## 결정
1. **화면 좌표는 1280×800 그대로, 그리는 캔버스만 배수(1 · 2 · 3)만큼 키워요.** 배수는 켤 때 모니터 크기 × 기기 배율로 한 번 골라요(1920×1080 = 2, 4K = 3, 레티나 = 2, 1536×960까지는 1). 창에 맞추는 일은 그대로 `Scale.FIT`이에요. `?res=2`로 고정해 볼 수 있어요.
2. **화면 코드는 배수를 몰라요.** 카메라가 배수만큼 키워 그리고(`style/resolution.ts`), 글자(`textStyle`) · 기호(`loadIcon`) · 구운 텍스처(`createCanvas`)만 배수만큼 촘촘히 만들어요. 포인터 자리는 `pointerAt(p)`로 읽어요.
3. **창은 960×600까지만 줄어요.** 12px 글자가 9px 아래로 내려가지 않는 선이에요(전에는 640×400, 6px).
4. **글자 대비는 재서 알려 주기만 해요.** `pnpm check:contrast`가 고정 장면의 글자마다 WCAG 대비를 재고 4.5:1 아래를 적어요. 색 값은 Lucy가 고르니 실패로 막지 않아요.
5. **효과문 번역 경계.** 다른 언어는 `setCardTextWriter(locale, writer)`로 "효과 목록 + 보정된 수치"를 받아 자기 틀로 써요. 한국어 문장(`battle/effects.ts`의 describe)은 기본 언어 전용으로 그대로예요. `?locale=en`으로 다른 언어 이름이 칸에 들어가는지 봐요.

## 근거
1배에서는 22개 고정 장면이 main과 픽셀까지 같고, 2배에서는 같은 배치로 선명해요.

## 기각한 것과 이유
- 창 크기마다 배수 바꾸기: 이미 만든 글자 · 구운 텍스처를 다시 만들어야 해서 화면을 통째로 다시 그려야 해요.
- 그림만 2배: 캔버스째 늘어나 그대로 흐려요.
- 대비 검사를 `pnpm check`에 넣어 막기: 값은 Lucy가 고를 일이고, 브라우저가 있어야 재요.

## 결과와 후속 작업
- `src/presentation/style/resolution.ts`(새 파일), `game.ts`, `style/text.ts` · `icons.ts` · `opacity.ts` · `motion.ts`, 구운 텍스처 열 곳, 포인터 자리 읽는 세 장면, `electron/main/index.ts`, `tools/visual/contrast.ts`, `src/core/text.ts`.
- 영어 카드 이름 38개는 이름 띠(90px) 안에 들어가요(가장 긴 것 86px). 넘칠 때의 규칙은 번역을 시작할 때 Lucy가 골라요.
- 진화 컷신은 2배에서 직접 보지 못했어요. 임시 UI(`placeholder/`)의 글자는 배수를 따르지 않아요(화면은 제자리에 그려져요).
- 남은 것(Lucy 선택): 대비가 낮은 글자의 색, 오른쪽 위 기호 받침, 카드 속성 기호 받침, 해방 표지 기호, 섞여 쓰이는 낱말, 글자 크기 설정을 둘지. 컨트롤러 · 스팀 덱은 범위 밖(Lucy 2026-11-18).
