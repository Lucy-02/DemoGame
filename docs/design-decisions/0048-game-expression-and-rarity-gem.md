# 0048. 게임다운 표현: 글자보다 기호, 의미색은 표지로, 희귀도는 정령 결정

- 날짜: 2026-11-10
- 단계: 묶음 A·B(0046·0047) 뒤 표현 라운드 V → W → 폴리싱 P → 희귀도 표기 → 보석 G
- 상태: 수락됨 (Lucy 2026-11-10 "V3 > V1 >>> V2", "W2도 흐름은 좋은데", 폴리싱 P1 "나쁘지 않네", 희귀도 "색이나 기호로" → R-B, 보석 G3 "희귀도 낮으면 점점 작아지도록" → "좋네")
- 근거 자료: 링크 전체 `design/concepts/LINKS.md` (표현 라운드 V·W·P, 희귀도, 보석). **기준 화면 = 폴리싱 P1 https://claude.ai/artifact/Amo4umtjRj1ng12sfCbU5k**, **보석 = G3 https://claude.ai/artifact/1EYq4m1GC7iwEP6mg917VG**. 보석 SVG 사본 `design/review/gem/`.

## 맥락
묶음 A·B 정리안을 본 Lucy가 "배치나 흐름은 아주 적절한데 게임 치고 텍스트가 많고 기호·벡터를 덜 써서 웹서비스 같다. 게임은 라벨 등 설명 문구도 자제하는 게 좋다"고 했어요(상점만이 아니라 전체 피드백). 배치·흐름은 두고 표현만 바꾸는 라운드를 이어서 돌렸어요.

## 결정
- **배치·흐름은 0044·0046·0047 그대로.** 오른쪽 정령 세 줄, 정원 정본, 가운데 유리 틀.
- **글자보다 기호와 큰 숫자 (V3 바탕 + V1 기호).** 늘 보이는 글자는 이름·숫자·버튼 동사만. 라벨은 정본 기호(`public/assets/ui/icons/`)로, 설명은 호버 말풍선으로. 예외: 이벤트 상황문, 되돌릴 수 없는 확인 문장(TEXT_RULES 9절), 정원 탭 이름.
- **의미색은 표지로 (W2).** 바탕은 차분히, 의미색은 기호·큰 숫자·얇은 테·화면당 주 버튼 하나에만. 치료 연두, 위험 붉음, 골드 금빛, 성장 자두빛, 능력치마다 한 색. 판을 의미색으로 채우지 않아요(W1 기각).
- **한쪽만 두꺼운 테두리·밑줄 강조 금지.** 테는 고르게 1px.
- **크기는 여정 순서 (P1).** 지금 고를 것이 가장 크고, 확인용(골드·기록)은 위 띠에 작게. 같은 무게는 같은 크기·같은 줄. 9화면이 하나의 격자(바깥 여백 48, 왼쪽 열 48–612, 정령 줄 664–1232, 위 띠, 버튼 줄 아래 끝 = 정령 줄 아래 끝). 버튼은 한 모양.
- **상점은 카드 6장 3×2 격자**, 빼기·치료는 격자 오른쪽 두 칸(카드 두 줄 높이), 떠나기는 다른 화면의 넘기기와 같은 자리에 조용히. 6장은 `constants.json` `shop.card_count` 5 → 6 변경이 필요해요(데이터·골든 테스트, 구현 PR에 이유 적기).
- **보상 카드를 고를 때 들어 올리지 않아요.** 선택은 자두빛 테 + 주인 줄로 들어감.
- **희귀도 = 정령 결정 보석 (G3 v2).** 0008의 "카드 아래 점"은 캐러셀 인디케이터로 읽혀 폐기. 비용 동전 아래 보석 칸 하나(카드 폭 92에 13, `TODO_TOKEN`), 일반 이슬 결정(68%) → 고급 두 잎 결정(84%) → 희귀 별 결정 송이(100%). 같은 밑점에서 자라고, 점 수·크기·색이 함께 올라가요. 기본 카드는 없음, 전투 손패는 표시 안 함(0008 유지). 외곽 층(잉크) 아래 + 몸 층(희귀도 색) 위 두 번 그려요. 칸은 12px 밑으로 내리지 않아요. 색(시안 값) 일반 `#c3c8cb`, 고급 `#8079e0`, 희귀 `#e5799c` → `color.rarity.*`는 Lucy 확정 전까지 `TODO_TOKEN`.
  - 0008의 "희귀도에 색 기각"은 Lucy가 다시 열었어요(11/10 "색이나 기호로").
  - 보석은 카드에만 써요. 정령(성장 단계)에는 쓰지 않아 성장 표시와 헷갈리지 않게 해요. 호버 이름은 일반·고급·희귀.
