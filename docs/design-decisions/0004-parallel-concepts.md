# 0004. 디자인 루프를 "병렬 컨셉 → 체리피킹"으로 바꿈

- 상태: 수락됨 (Lucy, 2026-10-28)
- 대체: 0002의 "시안 2~3개 → 리뷰어 전원 리뷰" 순서

## 배경
전투 화면을 통째 시안 3개로 비교하고(R03), 이어서 항목별 조립기로 쪼개려 했어요. Lucy 피드백:
- 완성된 묶음 3개 중 고르기는 배치·밀도·구도·디테일을 컨펌하기 어렵다.
- 그렇다고 한 변수씩 순서대로 정하는 건 너무 순차적이고 지엽적이다.
- 한 아티팩트를 계속 고치면 지난 맥락을 계속 다시 읽어야 한다. 컨셉별 에이전트가 각자 아티팩트를 내는 게 LLM에 맞다.

## 결정
여러 화면을 담은 컨셉 시안을 에이전트별로 병렬 생성 → Lucy가 화면·조각 단위로 체리피킹 → 섞은 2~3안을 다시 병렬 생성. 리뷰어는 필요한 화면에만.

## 1~3라운드 결과 (링크는 `design/concepts/LINKS.md`)
- 1라운드 5컨셉: 정원 그림책, 테이블 위 카드 게임, 세 정령의 덱, 작전판, 여백과 안내
  - 폐기: 작전판, 테이블 위 카드 게임
  - 보상 화면: 정원 그림책 채택
- 2라운드 지도: C (가까운 길 + 전체 미니맵 + 슬림 파티 패널, 절제된 글래스) 채택
- 2라운드 전투: B (주인 묶음 손패) 채택 → 3라운드에서 과밀 완화, 우상단을 아이콘식 해결 순서표로
- 열린 기획 질문: `design/concepts/TIMELINE_QUESTIONS.md`
