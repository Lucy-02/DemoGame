# 0092. UI 모션 3차: 숫자 바뀜 · 가리킴은 제자리에서 흐려지며 바뀜

- 날짜: 2026-11-17
- 단계: P4 하이파이 (전투 · 지도 · 이벤트 · 휴식 · 전투 결과 · 상점 · 출전 준비 · 메인)
- 상태: 디렉터 판단 (Lucy 위임 2026-11-17). Lucy가 번호로 뒤집을 수 있어요. 새 값은 없고 0086의 임시 토큰을 그대로 써요.
- 관련: 0086(기준 · 남은 빈 곳 1 · 4번), 0089

## 결정
| # | 곳 | 결정 |
| --- | --- | --- |
| 1 | 전투: 마력 숫자 · 더미 수 | 숫자가 달라지면 앞 숫자가 흐려지며 바뀌어요(160ms). 세어 올리지 않아요 |
| 2 | 가리킴 · 누름으로 화면이 바뀌는 곳 (이벤트 · 휴식 · 전투 결과 · 상점 · 출전 준비 · 메인) | 앞 모습이 흐려지며 새 모습으로 바뀌어요(160ms). 풀이 말풍선도 같이 흐리게 떠요 |
| 3 | 지도: 가리킨 칸의 테 · 풀이 | 흐리게 나타나고(160ms) 벗어나면 흐려져 사라져요(120ms) |

- 모션 줄이기: 흐려짐 없이 바로 바뀌어요.
- 구현: 화면을 통째로 다시 그리는 구조는 그대로 두고, 앞 모습을 한 장으로 떠서 위에서 흐려 보내요(`crossPaint`).

## 기각
- 가리킨 것이 커지거나 떠오름 (0077: 상태는 제자리).

## 남은 것
- 새 모양이 필요한 여덟 곳은 움직이는 시안으로 Lucy에게 물었어요: 상태 칩 · 방어도 깨짐 · 차징 시작 · 브레이크 · 해방 · 전투 시작 · 승리 · 패배 (`design/concepts/LINKS.md` "모션 3차").
- 정령 관리 탭 전환, 깃들기, 덱 보기 줄 접힘, 막 넘김은 그대로예요.
