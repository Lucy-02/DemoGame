# 0060. 적과 스테이지 방향: 세 막, 풀에서 뽑기, 질문 하나, 틈을 만들어 가라앉히기

- 날짜: 2026-11-12
- 단계: 코어 기획 (적 · 스테이지)
- 라운드: 프로젝트 스레드 "적과 스테이지 기획하고 디벨롭"
- 상태: 수락됨 (Lucy, 2026-11-12 "추천 괜찮네", "세 막으로 하면 되겠다"). 숫자 · 이름은 시험 값 · 후보
- 제안서: https://claude.ai/artifact/1vSY34uCEJjpNRwcPeZPPB
- 조사: 공유 폴더 `enemy-design/research/` (A 적 설계 문법, B 런 랜덤 구조, C 테마 · 보스)

## 맥락
1막 적(0057)과 보스 뼈대(0032)는 있었지만 막 수, 런마다 달라지는 층, 보스를 "가라앉히는" 방식, 적의 생김새가 비어 있었어요. 보스는 하나로 고정, 이벤트는 4개였어요.

## Lucy의 결정

| 영역 | 결정 |
| --- | --- |
| 런마다 달라지는 것 | 풀에서 뽑기(막 보스는 후보 중 하나, 막 시작부터 공개, 약한 풀 → 강한 풀, 같은 편성 반복 금지, 이벤트 늘리기) + 오늘 센 기운(막의 세 기운 중 하나가 그 런에서 세고, 출전 전에 공개). 거친 적 특성은 정예부터 |
| 막 | **세 막** + 근원 보스전 한 판. 막마다 고리에서 이웃한 두 기운 + 고리 밖 하나. 1막은 불 · 숲 · 바람 그대로 (0017) |
| 적 문법 | 적 하나에 질문 하나. 막이 오를수록 시간축을 쓰는 적(움직이는 시각 · 횟수가 다른 적)을 늘림. 짝 편성은 0057 그대로 |
| 무속성 적 | **둬요** (Lucy). 약점도 저항도 없는 적 |
| 막 크기 | 잡몹 7 · 정예 3. 보스 수는 세부 설계에서 (센 기운과 맞추면 기운마다 하나) |
| 보스 | 큰 차징을 끊거나 늦추면 틈이 열리고, 틈 동안 크게 가라앉음. 틈 없이도 깎임 |
| 적의 생김새 | 키우는 대상이 정령일 뿐, **적은 정령 · 현상과 관련될 필요 없음** (Lucy). 표준 아키타입, 현상 덩어리, 깃든 것을 섞어도 됨. 그림 시안은 따로 |

## 기각한 것과 이유
- 갈리는 지역(막마다 지역 둘): 콘텐츠 두 벌. 출시 뒤.
- 기운을 런마다 뽑기: 지역 모티프가 흐려지고 0017 · 0028을 바꿔야 해요.
- 1막 뒤 갈림길, 네 막: 균형 · 그림 값.
- 보스 점수 경주(HP 없음): 카드 전체를 다시 봐야 해요.
- 전투 안 적 행동 무작위: 시간축에서 읽고 맞춰야 해요.

## 결과와 후속 작업
- `docs/design/05-world.md`의 "적 (한 줄)"과 막 표를 고쳤어요. 막 보스 = 큰 정령(0032)은 그대로예요.
- 적 이름 규칙(현상 명사, 동물 · 괴물 금지, 2026-11-03)을 일반 적에도 그대로 둘지는 Lucy 확인 대기예요(`docs/handoff/OPEN_QUESTIONS.md`).
- 세부 설계(런 구조 규칙, 세 막 뼈대, 1막 적 설계안)는 Lucy가 본 뒤 데이터에 넣고 `pnpm runsim`으로 재요.
