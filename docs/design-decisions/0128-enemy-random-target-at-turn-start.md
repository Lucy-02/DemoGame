# 0128. 적의 무작위 대상은 턴 시작에 정해 보여요

- 날짜: 2026-11-18
- 단계: P6 엔진 구현
- 라운드: 평가 1라운드 적용 (전투가 결과를 정직하게 말하기, P1-06 · P2-04)
- 상태: 수락됨 (Lucy 2026-11-18 "추천대로"). 쓰러진 대상의 대체 규칙은 작업 가정.

## 맥락
적의 무작위 공격은 맞는 순간에 대상을 뽑아서, 아군이 여럿이면 받을 피해에 안 보였어요. 방어 카드를 누구에게 줄지 근거가 없었어요.

## 결정
- **적의 무작위 대상은 턴 시작에 뽑아요.** 적 행동을 시간축에 박을 때, 행동 순서대로 뽑아 둬요. 여러 번 치는 공격은 타격마다 하나씩이에요. 무작위로 거는 약화 · 취약 · 화상도 같아요.
- **보이는 것은 있는 표시 그대로예요.** 뽑힌 아군이 하나면 의도 알약에 그 아군 얼굴, 여럿에게 갈리면 주사위. 받을 피해 · HP 막대의 깎일 구간에 들어가요.
- 숨음 · 도발은 전처럼 행동하는 순간에 먼저 봐요.
- 뽑아 둔 정령이 그사이 쓰러지면 앞열이 맞아요 (작업 가정).
- 아군 카드의 무작위 대상은 그대로예요 (0123).

## 기각한 것과 이유
- 맞을 수도 있는 피해를 따로 그리기: 새 표시가 하나 늘고, 방어를 누구에게 줄지는 여전히 몰라요.

## 결과와 후속 작업
- `src/core/battle/`(`EnemySlot.aim` · `Battle.aimOf` · `pickTargets`의 `by`), `src/presentation/battle/fromBattle.ts`(의도 대상).
- 골든 스냅샷: 턴 시작에 난수를 더 쓰게 되어 인카운터 요약과 보스전 이벤트 로그가 바뀌었어요.
- 남은 것: 여럿에게 갈린 무작위 공격을 가리켰을 때 맞는 아군만 짚기.
