# 0077. 순서표 토큰 모션

- 날짜: 2026-11-16
- 단계: P4 하이파이 (전투 화면, 해결 순서표)
- 라운드: 스레드 "순서표 토큰 모션 디자인하기", 시안 https://claude.ai/artifact/QdoR6vEwWrmapWUkFEupzw
- 상태: 수락됨 (Lucy, 2026-11-16 "0나 1가 2나 3나 5가 6가 7나", 4번은 0076의 16). 시간 · 곡선은 시안 값이라 구현 때 `provisional.motion`에 넣어요.
- 관련: 0038 · 0074(표기), 0019(문장 대신 형태 · 모션), 0050(의미색 채움 금지)

## 맥락
턴 재생(행동 하나 450ms)은 들어갔지만 모션이 없어 순서표가 장면마다 통째로 바뀌었어요. 모양은 0074 그대로 두고 움직임만 정했어요.

- 고르지 않은 것: `+n` 접힘과 가리킬 때 흰 테는 손패 호버와 같은 흐려짐(160ms).

## 기준
- 토큰은 순서가 바뀔 때만 자리를 옮기고, 상태(지나감 · 지금 차례 · 차징 · 끊김)는 제자리에서 바뀌어요.
- 내가 일으킨 변화는 160ms 안쪽, 재생 중 변화는 450ms 한 걸음 안에 끝나요.
- 쉬는 동안 계속 움직이는 것은 없어요.
- 자리 옮김은 판 폭과 모든 요소가 같은 시간 · 곡선을 써요(제자리인 것이 흔들리지 않게).

## 시안 값
- 시간: 빠름 160ms(기존 `motion.hover`), 보통 240ms(기존 `motion.spiritSwap`). 곡선: 호버 `.2,.7,.2,1`, 자리 옮김 `.2,.8,.2,1`, 넘침 `.3,1.5,.5,1`(새 턴 등장만).
- 모션 줄이기: 자리 옮김을 흐려짐으로 바꾸고 색 · 투명도 변화는 남겨요.

## 기각
- 끊김: 배지만 바뀜(약함, Lucy), 채움과 튀는 것을 함께 쓰기(Lucy), 보라로 물든 채 남기(0050), 보라 테(가리킬 때 흰 테와 겹침).
- 들기 · 놓기의 튀어나옴과 아래에서 올라옴, 늦춰질 때 적 토큰이 밀리는 모션.
- 재생 위치 선이 사라졌다 나타남 · 쉬지 않고 흐름, 토큰이 들림, 표가 옆으로 밀려옴.
- 빠져나가는 방향 모션(0074에서 이미 기각).

## 남은 것 (구현 스레드와)
- 브레이크 카드를 놓은 뒤에는 끊김 예정 배지가 차징으로 돌아가요. 남길지 미정.
- 든 자리는 흰 점선 테가 허점 노랑보다 먼저라, 허점인지는 놓은 뒤에야 테로 보여요.
- 빙결 카드를 든 동안 늦춰질 자리 미리보기가 없어요.
