# 0034. 성격 다시 뽑기를 뺐어요

- 날짜: 2026-11-06
- 단계: 코어 기획 / 정령 관리 화면
- 상태: 수락됨. 3화 보상과 재료 쓰임은 Lucy 확인 대기

## Lucy의 결정
> "성격 다시뽑기 넣을 생각도 없고 넣지도 않을거임 기능삭제하고"

성격은 부화할 때 정해지면 바뀌지 않아요. 0021의 "성격 다시 뽑기"(재료 5, 성체부터)를 대체해요.

## 한 일
- 규칙: `canReroll`, `rerollChoices`, `reroll`을 지웠어요. 세션의 `reroll` 명령과 난수 생성기도 함께 지웠어요.
- 데이터: `growth.json`의 `reroll`, 유대 3화의 `reroll_choices`를 지웠어요.
- 화면: 개요 탭의 `다시 뽑기 · 재료 5` 버튼을 지웠어요.
- 저장 형식은 그대로예요. 다시 뽑기는 저장 값이 없었어요.
- 전투 규칙은 그대로예요. 판에 쓰는 코드는 다시 뽑기를 부르지 않았어요.

## 남은 것 (Lucy 확인 대기)
- **유대 3화 보상:** 3화의 보상이 "다시 뽑을 때 둘 중 고르기"였어요. 지금은 호감도 150 + 각성체로 열리지만 보상이 없어요.
- **재료 쓰임:** 정원에서 재료를 쓰는 곳은 이제 먹이기뿐이에요.

## 함께 달라지는 것
