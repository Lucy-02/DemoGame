## 결과와 후속 작업
- 상태 6종: 기본 · 누를 수 있음(빛 넓어짐 + 빛줄) · 누름(살짝 작게) · 집어 끌기(카드 표식) · 못 함(어둡게, 빛 꺼짐, 금지 표식) · 잠깐 대기(고리). 핫스팟 (6,4) 모두 같음.
- 파일: `public/assets/ui/cursors/cursor-<상태>-{32,64}.png` + 원본 SVG. 원본 스크립트는 UI 에셋 폴더 `src/cursors.mjs`.
- 코드: `src/presentation/style/cursor.ts`. 게임 부트 때 붙어요. `useHandCursor` 오브젝트 위에서 hover, 누르는 동안 press. 끌기·못 함·대기는 `game.registry.get("cursor").push/pop` 으로 (아직 이걸 부르는 화면은 없음).
- 남은 일: 전투 카드처럼 `useHandCursor` 없이 직접 히트 판정하는 곳의 hover·grab 연결, 못 하는 카드 위 blocked, 커서 크기 설정(32/48/64), 색 토큰.
