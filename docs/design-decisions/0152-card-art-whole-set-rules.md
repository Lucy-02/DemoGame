# 0152. 카드 그림 전체 규칙: 바탕 밝기 · 그리는 방식 · 덮개 자리

- 날짜: 2026-11-18
- 단계: P6 엔진 구현 / 에셋
- 라운드: 전문가 평가 묶음 H(그림 일관성) 중 카드 몫, P5-06 · P5-07 · P5-10
- 상태: **임시 규칙. Lucy가 컨펌하지 않았고 나중에 바뀔 수 있어요.**

## 결정 (임시)
- **바탕 밝기**: 그림 창 바탕은 어둡게 둬요(가장자리 12% 띠의 평균 밝기 96/255 미만). 정령마다 색조만 달리해요.
- **그리는 방식**: 선 있는 셀 셰이딩 그림 하나로 그려요(clean lineart, cel shading, limited palette). 픽셀 · 망점 · 실루엣 판화 · 사실 렌더는 쓰지 않아요.
- **덮개 자리**: 네 모서리(비용 동전 · 속성 기호 · 초상 홈 · 수치판), 위 11px 톱니, 오른쪽 가운데 준비 표식 자리에는 주제를 두지 않아요. 주제는 가운데보다 조금 위의 원 안에 둬요(PIPELINE §1). 생성 프롬프트 구도 문구에 "네 모서리는 빈 바탕"을 넣어요.
- 작가 이름 태그는 Lucy 결정 대기라 이 규칙에 넣지 않아요(P5-05).
