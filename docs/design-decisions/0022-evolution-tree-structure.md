# 0022. 진화 나무 구조: 성체에서 한 번 갈림, 배운 카드가 갈래를 열고 플레이어가 고른다

- 날짜: 2026-10-30
- 단계: 코어 기획 (S1~S2)
- 라운드: 코어 기획 스레드, 시안 문서 [진화 분기 구조 시안 R1](https://claude.ai/artifact/YY1nrDCj31f8nXJgDojwtA)
- 상태: **추천안 채택** (Lucy 포괄 승인 "머지하고 쭉쭉 진행해", 2026-10-30). 0015의 "구조는 시안 라운드 중"을 닫아요.

## 맥락
0015에서 분기 진화를 코어에 넣었고, 구조(분기 수·시점·조건 유형·자동/선택)는 시안 라운드로 넘겼어요. 각 정령은 독립된 한 줄이에요(0016).

## 고려한 선택지
### 나무 모양
| | 시안 1 한 번 갈림 | 시안 2 두 번 갈림 | 시안 3 계열이 섞임 |
| --- | --- | --- | --- |
| 분기 시점 | 유체 → 성체에서 한 번 | 성체에서 한 번, 각성체에서 또 한 번 | 성체에서 한 번. 갈래는 "순수" 하나 + 다른 계열과 섞인 형태 |
| 계열당 끝 점 | 2 | 4 | 1 + 섞인 계열 수 |
| 3계열 스킨 | 15 | 21 | 24 이상 |
| 전투 규칙과 충돌 | 없음 | 없음 | 상성·속성 2개 규칙을 정해야 함 |
| 위험 | 선택 한 번이라 금방 다 본 느낌 | 콘텐츠 비용, 각성체 갈림은 리그까지 | 섞인 형태는 정체성이 흐림 |

### 조건 유형
가 배운 카드("무엇을 배웠나") / 나 전투에서 한 일("어떻게 싸웠나") / 다 정원 재료("무엇을 주었나") / 라 성격("어떤 아이였나")

### 자동인지 고르는지
1 조건이 차면 자동 / 2 조건이 갈래를 열고 열린 갈래 중 고름 / 3 항상 고름, 조건 없음

## 채택한 안
- **나무: 시안 1.** 유체 → 성체에서 한 번 갈려요. 계열당 성체 2. 각성체는 갈리지 않고 성체 갈래를 따라가요. 각성체 갈림(시안 2)은 출시 후 확장.
- **조건: 주 = 가 배운 카드, 보조 = 다 정원 재료.** 이번 탐험에서 배운 카드가 갈래를 열고, 정원 재료로 갈래 하나를 강제로 열 수 있어요(운이 나쁠 때의 보정, 보조로만).
- **방식: 2. 조건이 갈래를 열고, 열린 갈래 중 플레이어가 골라요.** 조건은 정령 화면의 "성장 길" 탭에 항상 보여요(숨김 금지, 0015).
- **순서 고정: 갈래 선택 → 진화 연출 → 성격 공개.** 진화는 "고르는 것", 성격은 "드러나는 것"으로 역할을 나눠요. 성장 오버레이(0012)의 박자에 "갈래" 한 박자만 더해요.
- **갈래 차이는 능력치 배분·역할·갈래별 고유 카드 1~2장(성체 해금 자리)으로.** 기존 카드 수치는 그대로(0011). "같은 카드 다른 손"이 갈래 차이를 대신 보여 줘요.
- **한 계열의 성체 갈래들은 같은 체형(리그)을 써요.** 차이는 스킨·색·파츠로.
- 안 간 갈래는 도감 대신 "성장 길" 탭에서 조건만 보여요(도감 빈칸·실루엣 기각 LEDGER 3-4와 충돌하지 않음).

## 근거
- 콘텐츠가 한 번의 추가(계열당 성체 하나 더)로 끝나요. MVP 3종이면 성체 6.
- "누가 배울까"가 육성 선택이 돼서 코어 기믹이 두꺼워져요. 메인 포인트 C(0021)와 한 몸.
- 시안 2·3으로 확장할 길이 열려 있어요(각성체 갈림, 갈래 B를 섞임으로).

## 기각한 것과 이유
- 시안 2 지금 적용: 각성체는 인간형(브랜드 브리프)이라 갈리면 리그·일러스트가 계열당 4개. 출시 후로.
- 시안 3: 사실상 속성 2개라 상성 규칙을 다시 짜야 하고, 섞인 형태는 정체성이 흐려요. 섞임은 나중에 갈래 하나를 섞임으로 바꾸는 식으로 넣을 수 있음.
- 조건 나(전투에서 한 일): 통계 추적이 필요하고 일부러 이상하게 플레이하게 만들어요.
- 조건 라(성격): 성격이 랜덤이라 육성 선택이 사라지고, 정원 리롤 노가다가 돼요. 성격은 공개 순간으로만.
- 자동(1): 원하는 갈래를 못 가면 좌절. 항상 고름(3): 육성감이 가장 약함.
