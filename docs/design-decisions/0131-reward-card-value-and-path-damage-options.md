# 0131. 보상 카드 값과 길 전투 피해: 5층 기준으로 다시 잰 값과 후보

- 날짜: 2026-11-18
- 단계: 코어 기획 (균형)
- 라운드: 프로젝트 스레드 "판 안에서 덱 짓는 이유 세우기"
- 상태: 제안 (Lucy 고르기 대기). 규칙 값은 바꾸지 않았어요. 0130의 후보 표 둘을 이 문서가 대체해요
- 앞 결정: 0130 (재는 표), 막마다 5층 (Lucy 2026-11-18)
- Lucy 2026-11-18: "기본 덱이 너무 세고 보상 카드가 너무 약하게 설계된 것이랑 적 난이도가 높은 것 아니냐"

## 확인한 것 (smart, 불여우 · 도롱뇽 · 산양 유체, 2막까지, 막마다 5층, 400판씩)
- **보상 카드가 시작 카드와 같은 값이에요.** 1칸 기준 할퀴기 피해 6 · 유리 벽 5인데 일반 보상은 꼬리 쓸기 피해 3 + 벽 3, 버팀목 방어 6, 뿔 찍기 피해 7이에요. 20장 가운데 "전부 넘기기"(78.3%)를 구간 밖으로 넘는 카드가 0장이에요.
- **길 전투가 깎는 HP가 값보다 커요.** 전투 먼저 64.3% · 기본 72.3% · 전투 피하기 78.8%. 정예 먼저 66.5% · 정예 피하기 74.3%.
- 각성체 다섯 막: 가려 받기 + 전투 먼저 34.7%, 전부 넘기기 + 전투 피하기 71.3%.

## 고를 것: 보상 카드 값 × 길 전투 피해
`--whatif cards:M`(보상 카드 숫자 M배) · `foe:M`(잡몹 · 정예 피해 M배, 보스 그대로)로 쟀어요. 칸 안은 가려 받기 / 전부 넘기기(기본 길).

| 후보 | 가려 받기 | 전부 넘기기 | 의도한 플레이(받기 + 전투 먼저) | 가장 잘 이기는 버릇 | 버릇 폭 |
| --- | --- | --- | --- | --- | --- |
| 지금 | 72.3% | 78.3% | 64.3% | 넘기기 + 피하기 84.8% | 31%p |
| 가. 길 전투 피해 ×0.8 | 85.3% | 87.8% | 81.5% | 넘기기 + 피하기 91.3% | 21%p |
| 나. 보상 카드 ×1.5 | 80.3% | 78.3% | 77.0% | 받기 + 피하기 85.5% | 25%p |
| 다. 나 + 가 | 89.8% | 87.8% | 87.3% | 받기 + 피하기 92.5% | 16%p |
| 라. 보상 카드 ×2 + 가 | 91.3% | 87.8% | 90.3% | 받기 + 피하기 95.5% | 14%p |

- 추천: **다**. 받는 쪽이 넘기는 쪽을 넘고, 의도한 플레이가 가장 잘 이기는 버릇과 5%p 안이에요. 보상 카드만 올리면(나) 전투를 피하는 쪽이 여전히 8%p 나아요.
- 각성체 다섯 막에서 라는 가려 받기 + 전투 먼저 90.7% 대 넘기기 + 피하기 83.3%예요.
- 승률이 목표 띠(60 ~ 80%) 위로 올라가요. 보스와 막별 세기는 값이 정해진 뒤 "적과 스테이지" 스레드가 다시 맞춰요.
- ×1.5 · ×0.8은 한꺼번에 곱한 시험 값이에요. 고르면 보상 카드는 카드마다 숫자를 다시 정하고(시작 카드는 그대로), 길 전투는 적 데이터의 피해를 낮춰요. 골든 스냅샷이 바뀌어요.
- 0130의 땜질 후보(강화된 채로 주기 · 전투 뒤 회복 10%)는 5층에서 90.5% / 88.3%로 다와 비슷하지만 원인(카드 값 · 적 피해)을 그대로 둬요.
