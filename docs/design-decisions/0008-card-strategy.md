# 0008. 카드 디자인 전략 R1: 구분 체계 · 기믹 준비 표시 · 카드 사용 모션

## 맥락
카드 구조(그림 창 + 얇은 이름 띠, 5:7, SD 초상 홈, 정령별 윗선, 기호+숫자판, 속성 재질)는 0005에서, 사용 불가 표시와 호버 H1은 0007에서 확정. 비어 있던 것: 역할·희귀도·성질(지속·소멸·보존)을 어디에 싣나, 기믹 활성(연속·점화·고집·장난·각성·쓰러짐)을 어떻게 보이나, 카드를 낼 때 카드가 어떻게 움직이나. 연구 3편(design/card/research), 리뷰어 5명 1회(design/card/reviews).

## 범위 (Lucy)
카드 자체에 표기되는 디자인과 카드 자체의 애니메이션·효과까지. 스킬 이펙트(대상 타격, 점화·빙결 같은 필드 연출, 각성 화면 연출)는 이 스레드 범위 밖.

## 고려한 선택지
- 구분 체계: A 최소 표시 / B 성질은 모양으로(1차: 아래 받침 + 기호 + 이름 띠 희귀도 점, 리뷰 후 수정) / C 역할은 숫자판 모양
- 기믹 활성: A 칸 채우기만 / B 숫자판 밝게 / C 준비 표식(리뷰 후 새 안)
- 카드 사용 모션: A 대상까지 날아감 / B 주인 정령에게 돌아감 / C 이름 띠 재질이 풀려 나감
- 쓰러진 정령 카드: a 규칙 그대로 / b 얼굴도 회색 / c 묶음 띠 하나

## Lucy의 결정 (추천안 수락)
- **구분 체계 B 수정안**: 지속·소멸·보존만 숫자판 맨 앞의 작은 단색 기호. 카드 윤곽·그림 창은 그대로. 희귀도는 손패에 없음, 보상·상점·덱 보기에서 카드 아래 점 개수. 역할은 카드에 표시하지 않음(효과 기호가 대신, 호버에 이름).
- **기믹 활성 C 준비 표식**: 조건이 채워진 카드에만 숫자판 모서리에 모양 표식. 색·밝기를 쓰지 않음. 켜지는 순간 한 번만 움직임(모션 줄이기면 없음). 연속이 다 차면 숫자판에 추가 횟수. 정령 단위 상태(고집·각성·쓰러짐)는 묶음 머리표와 초상 홈에, 카드 단위 상태(연속·성장·장난·점화)는 숫자판과 비용 동전에.
- **카드 사용 모션 B**: 카드가 주인 정령에게 돌아가고 정령이 시전. 빠르게 모드에서 첫 박자를 줄임.
- **쓰러진 정령 c 수정안**: 묶음 위 "쓰러짐" 띠 하나, 얼굴은 컬러 유지, 포커스(호버)한 카드에만 글 띠로 사유.
- "낼 수 있음"은 표시하지 않음(기본 상태). 상태 층 L0 신원 ~ L4 일시 상태, 판단 정보는 가라앉아도 읽힘.

## 근거
리뷰어 다섯 의견의 교집합(구분 체계), 색약에서도 구분되는 모양 단서(기믹), 브랜드 훅을 매번 보여 주고 Spine 시전 애니를 재사용(모션), 정령 단위 상태는 묶음에 + 얼굴 컬러 규칙 유지(쓰러짐).

## 기각한 것과 이유
- 구분 체계 C(역할 = 숫자판 모양): 효과 기호와 같은 말 반복, 리뷰어 지지 없음, 역할 참조 규칙 없음.
- 1차 B의 아래 받침(윤곽 변경)과 이름 띠 끝 희귀도 점: 말줄임표로 읽힘, 그림 창 안전 영역 침범.
- 기믹 B(숫자판 밝게): 색·밝기뿐이라 색약이면 A와 같고, 강조색 하나 원칙을 깸.
- 희귀도에 재질·색·반짝임: 재질은 속성 전용, 색 강조 낮게, 반짝임 보류(0005).
- 희귀도에 따른 연출 등급(Marvel Snap·HS식): 반짝임·등급 시안 기각과 같은 방향.
- 쓰러짐 b(얼굴 회색): 0007의 "정령 얼굴은 컬러"를 깨고 애착 톤에 어긋남.
