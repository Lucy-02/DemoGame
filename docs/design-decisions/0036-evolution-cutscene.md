# 0036. 진화(유체 → 성체) 컷신 연출

- 날짜: 2026-11-06
- 단계: 진화 연출 / 움직임
- 상태: 수락됨 (Lucy "나쁘지 않네. 일단 마무리"). 시간·크기·흐림 값은 모두 임시(`tools/evolution-preview/main.ts` 상단). 게임 화면에는 아직 연결하지 않았어요.
- 미리보기: `pnpm dev:web` → `/evolution-preview.html` (`?beat=5` 정지 화면, `&stage=none` 배경 끄기, `&feather=` `&choke=` `&matte=0` `&bandblur=` 값 바꿔 보기)
- 기획 문서: Claude Doc "진화·각성 연출 기획" (업계 사례·원칙)

## 맥락
진화는 의도적으로 키웠을 때(전투 밖) 보는 긴 연출이에요. 전투 중 각성은 컷인 없이 약식으로 들어가요(Lucy 11/04). 처음 판(빛줄기·폭발·고리·흔들림·블룸)은 "이펙트가 덕지덕지 과하다"는 평이라 빛 하나·움직임 하나만 남긴 덜어낸 판(A)으로 갔어요. Phaser 4 필터·트윈으로 엔진 안에서 만들어요.

## 정한 것
- **순서(정보 먼저, A):** 대기 → 유체 희미해짐 0.7초 → 가운데 그림자 영역 0.8초 → 가운데 속성·역할 1.3초 → 성체 실루엣 1.0초 → 공개 1.5초 → 정리(정보 패널).
- **유체는 사라지지 않아요.** 희미하게 남았다가 성체 실루엣으로 바뀌어요.
- **유체 정보는 띄우지 않아요.** 이미 아는 정보라서요. 무엇으로 자라는지와 성체 정보만 보여요. 유체도 역할은 있어요(규칙 그대로).
- **속성·역할:** 아이콘 둘(확정본 el-·role-) 아래에 한글 이름. 글자 테두리 없음. 역할 아이콘은 나타날 때만 살짝 늦게 오고, 사라질 땐 넷이 함께 사라져요. 아이콘·글자는 실루엣보다 위에 그려요.
- **배경 무대:** 진화 전엔 없어요. 공개 때 정령별 `background.webp`가 성체와 같은 크기·자리·곡선으로 함께 밀려 들어오고, 성체 발이 발판에 오게 놓여요. 화면 밖으로 잘려도 돼요. 살짝 어둡게 눌러 성체가 앞에 서 보이게 해요.
- **배경 가장자리:** 흰 매트 제거 → 1px 깎기 → 1px 번짐(Photoshop Remove White Matte + Choke + Feather와 같은 순서). 흐림만으로는 2px까지도 점선 테두리가 남았어요.
- **이름 띠:** "○○ 성체" 글자 테두리 없음. 뒤에 왼쪽 아래 모서리부터 가운데로 갈수록 옅어지는 사선 흐림(세기 1.5, 2부터 성체 선이 겹쳐 보여요). 공개 박자에만.
- **움직임 곡선:** 나타남은 out, 사라짐은 in·inOut. 공개 때 성체·배경 Cubic.out(밀려 들어와 멈춤), 정리 때 Quart.inOut(옆으로 비켜섬), 패널 Cubic.out.

## 기각한 것
- 처음 판(look=full): 빛줄기·폭발·고리·흔들림·블룸이 과함. 미리보기에 `?look=full`로만 남아 있어요.
- 유체가 완전히 사라지는 판.
- 유체 정보 띠를 띄우는 판, 유체는 역할이 없다는 해석.
- 배경이 처음부터 깔린 판, 마법 없는 판 → 마법 판으로 바뀌는 판.
- 배경 가장자리 흐림 6px·2px(너무 흐리거나 테두리가 남음), 이름 띠 흐림 2.5(선이 겹침).

## 남은 것
- 사운드는 지금 고르지 않아요(Lucy 11/05). 사운드 스레드 후보는 보류.
- 각성 연출(전투 중 약식)은 아직이에요.
- 발판 높이(0.88)·성체 키 비율(0.75)은 안개 고양이·유리 도롱뇽에 맞춘 값이라, 다른 정령은 정령별 값이 필요할 수 있어요.
- 게임 화면에 붙일 때 프리멀티플라이드 알파·알파 블리드로 축소 테두리를 막아요. 값은 그때 토큰으로 옮겨요.
- 배경 원본 선이 1024를 2배로 키운 거라 무른 편이에요. 업스케일 원본으로 다시 누끼 따면 더 깔끔해져요.
