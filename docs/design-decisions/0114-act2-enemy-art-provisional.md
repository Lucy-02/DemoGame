# 0114. 2막 적 그림: 1막과 같은 방향으로 임시 선택 연결

- 날짜: 2026-11-18
- 단계: P6 엔진 구현 / 에셋
- 라운드: 프로젝트 스레드 "1막 적 그림 뽑기" (총괄 요청)
- 상태: **임시 선택, Lucy 확인 대기.** 방향은 0100과 함께 바뀌어요
- 후보 시트: https://claude.ai/artifact/S4vDobYCAuUKrCaRtX6HUo

## 맥락
1막 적(0100)이 들어간 뒤 2막 적 열셋(잡몹 일곱, 정예 셋, 보스 셋)은 빈 상자였어요. 한 판이 2막까지 가요.

## 결정 (임시)
- 0100의 방향 가(사나운 짐승, 정령과 같은 그림체 묶음)와 같은 프롬프트 틀로 13종을 뽑아 연결했어요. Lucy가 방향을 바꾸면 1 · 2막을 같은 틀에서 한꺼번에 다시 뽑아요.
- 이름만 있고 생김새가 정해지지 않은 적은 제가 해석을 정했어요: 돌무더기 = 바위가 뭉친 골렘, 피뢰침 = 세 다리 쇠 첨탑, 등불지기 = 등불 머리에 누더기, 산사태 = 바위와 흙으로 된 멧돼지, 뇌우 = 먹구름 뱀, 한낮 = 햇살 갈기의 흰 사자. 2막 이름 · 모티프는 아직 임시라(0085) 그림도 같이 바뀔 수 있어요.
- 돌무더기는 첫 묶음이 픽셀 그림으로 나와 묘사를 고쳐 다시 뽑았어요.
- 크기 · 발 위치 · 순서표 얼굴은 `enemyFit.json`의 임시 값이에요(1막과 같은 틀).

## 남은 것 (Lucy 확인)
- 종별 칸과 위 해석.
- 피뢰침은 몸이 가늘어 작은 크기에서 덜 읽혀요.
- 보스 크기는 0100의 세 안이 정해지면 같이 맞춰요.

## 결과와 후속 작업
- `public/assets/enemies/*.webp` 13장 추가(`assets/provenance.jsonl`에 placeholder), `enemyFit.json` 13줄, 보는 장면 `?scene=act2-mobs-a` (`-b` · `-c`, `act2-turtle` · `bird` · `lantern`, `act2-landslide` · `thunderstorm` · `high-noon`).
- 프롬프트 시트 `design/concepts/enemies/prompt-sheet-act2-r1.py` · `r2.py`. `tools/art/import-enemies.py`는 앞 막의 칸 기록을 남기고 더해요.
- 3~5막은 게임에 켜지면 같은 방식으로 이어요.
