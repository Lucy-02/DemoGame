# 0080. 휴식 · 이벤트 · 판 결과 새 화면과 카드 강화

- 날짜: 2026-11-16
- 상태: 수락됨 (디렉터 위임, Lucy 2026-11-16 밤샘 추진)
- 관련: 0043, 0046, 0050, 0076

## 결정
1. **카드 강화 규칙**: 숫자 효과마다 +30%(올림, 최소 +1), 카드마다 한 번. 카드 데이터에 `upgrade` 덮어쓰기 자리를 둬요. 숫자 효과가 없는 카드는 강화 후보에서 빠지고 회색이에요(0043). 값은 `constants.json card_upgrade`.
2. **강화 표시**: 오른 숫자 옆 ▲만. 이름 · 테두리는 그대로예요. ▲는 "인쇄값보다 높음"을 뜻해요(능력치로 오른 값과 같은 표시).
3. **휴식**: 0046 세 갈래 뼈대. 쉬기 · 카드 강화 중 꼭 하나. 둘 다 할 것이 없을 때만 `떠나기`.
4. **이벤트**: 이름 줄 + 상황 글 + 선택지 판, 장면 그림 없음. 올리면 대가가 전부 미리 보여요. 덱에서 고르는 결과(빼기 · 강화 · 복제)는 덱을 펴서 고르고 확인해야 선택지 전체가 적용돼요.
5. **판 결과**: 라벨 없이 부품으로(0050). 기록 한 줄(`1막 · N층 · 승리`), 정령 줄은 달라진 것만(Lv 배지 · 경험 링 · 최대 HP a→b · 열린 카드), 이번 판에서만 남는 골드 · 카드는 점선 상자. 버튼 둘은 같은 자리, 이기면 `정원으로`, 지면 `다시 떠나기`를 강조.
6. 판의 이벤트 자리는 고른 이벤트 id를 저장해, 이어 하면 같은 이벤트가 나와요.
