# 0140. 위시리스트 자리: 데모 끝 + 데모의 진 판 결과

- 날짜: 2026-11-24
- 단계: P6 엔진 구현
- 라운드: 프로젝트 스레드 "출시 준비 채우기" (평가 P9-09), 확인 묶음 14번
- 상태: 수락됨 (Lucy 2026-11-24 "추천대로"). 자리의 모양 · 낱말은 Lucy 확인 대기
- 앞 결정: 0101 (데모 끝 화면), 0139 (출시 준비), 0046 (판 결과 틀)

## 맥락
위시리스트 자리가 데모 끝 화면에만 있었고, 그 화면은 2막 보스를 이겨야 떠요. 대부분의 데모 판은 그 전에 져서 끝나요.

## 고려한 선택지
- 가. 데모 끝 + 진 판의 판 결과
- 나. 데모 끝만
- 다. 가 + 메인 메뉴
- 라. 다 + 판 안 메뉴

## Lucy의 결정
가. 데모 빌드에서 진 판(포기 포함)의 판 결과에도 위시리스트 자리를 둬요.

## 구현
- 판 결과 왼쪽 열, 버튼 둘 바로 위에 버튼 크기의 점선 칸 하나(`[위시리스트]`). 데모 끝 화면의 링크 자리와 같은 부품이에요(`src/presentation/run/linkSlot.ts`).
- 버튼과 한 덩어리로 나타나요. 따로 연출은 없어요.
- 데모 빌드에서만, 진 판에서만 보여요. 이긴 판은 데모 끝 화면이 맡아요.
- 링크 주소는 스팀 앱 ID가 생긴 뒤에 연결해요. 지금은 빈 자리예요.

## 기각한 것과 이유
- 메인 메뉴 줄: 메뉴 줄이 늘어요 (0054).
- 판 안 메뉴: 하던 판을 떠나게 해요.

## 남은 것
- 자리의 모양과 버튼 낱말 (데모 끝 화면과 같이, 0101).
- 스토어 페이지 주소 연결.
