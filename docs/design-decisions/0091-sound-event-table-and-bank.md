# 0091. 소리 사건 표와 은행 칸

- 날짜: 2026-11-17
- 단계: P6 엔진 구현
- 라운드: 프로젝트 스레드 "소리 기본 세트 정하고 넣기" (전문가 평가 1라운드 P6-01 ③ · P6-09 · P6-10)
- 상태: 수락됨 (Claude 판단, Lucy 위임). Lucy가 번호로 뒤집을 수 있어요. 값은 임시예요. 어떤 소리를 쓸지는 듣기 라운드에서 Lucy가 골라요
- 앞 결정: 0087 (2번 소리 목록과 3번 은행을 여기서 대체), 0086 (모션에 있고 소리에 없던 사건)

## 판단
1. **소리 사건은 스물아홉 + 음악 넷.** 표의 차례가 사건의 크기 차례예요.

| 사건 | 이름 | 나는 때 |
| --- | --- | --- |
| 해방 | `release` | 해방이 켜질 때 |
| 판 승리 · 패배 | `victory` · `defeat` | 판 결과가 뜰 때 (전투 하나를 이긴 것은 `reward`) |
| 진화 · 깃들기 | `evolve` · `join` | 키우기를 확정할 때, 깃들 정령을 고를 때 |
| 쓰러짐 | `down.ally` · `down.enemy` | 아군이 쓰러질 때, 적을 처치할 때 |
| 브레이크 · 적 차징 | `break` · `charge` | 차징이 끊길 때, 차징을 시작할 때 |
| 타격 셋 · 방어 | `hit.heavy` · `hit.medium` · `hit.light` · `block` | 0087 4번 그대로 |
| 회복 · 상태 | `heal` · `status` | 회복은 제 소리, 상태 · 빙결은 한 소리 |
| 보상 · 장비 · 강화 · 사기 · 쉬기 | `reward` · `equip` · `upgrade` · `buy` · `rest` | 그 행동이 받아들여졌을 때 |
| 카드 사용 · 턴 종료 · 새 손패 · 지도 이동 | `card.play` · `turn.end` · `hand.new` · `map.move` | 새 손패는 턴 재생이 끝날 때 |
| 낼 수 없는 카드 | `card.deny` | 낼 수 없는 카드를 누를 때 |
| 카드 집기 · 놓기, 버튼 | `card.pick` · `card.place` · `ui.click` · `ui.hover` | 0087 5번 그대로 |
| 화면 전환 · 창 뜸 | 소리 없음 | 누른 버튼의 소리가 이미 나요 |

2. **은행에 사건별 칸.** `bank.json`의 사건마다 `files`(번갈아 남) · `gain`(0 ~ 1, 없으면 1) · `detune`(음높이 흔들기, 센트, 없으면 안 흔듦). 지금은 비어 있고, 값은 소리를 넣을 때 들으면서 채워요.
3. **동시 수.** 효과음은 한꺼번에 여덟까지(`voices`, 임시). 넘으면 표에서 뒤에 있는 사건부터 빠져요. 한 걸음에 같은 소리는 한 번만 나요.
4. **파일 규격.** 효과음은 mono 44.1kHz ogg, 음악은 stereo ogg 루프. 파일은 같은 기준 음량(-18 LUFS, 임시)으로 맞춰 넣고 사건의 크기 차이는 `gain`으로 줘요. 효과음은 2.5초까지, 판 승리 · 패배 · 해방 · 진화는 6초까지.

## 건드리지 않은 것 (Lucy에게 물을 것으로 남음)
- 사건의 크기와 연출 크기의 차례 (P6-03), 음악을 멈춘 자리에서 이어 틀지와 정예 · 막별 곡 (P6-11).

## 후속
- 해방 소리의 맞는 때는 해방 연출이 정해지면 모션 스레드와 맞춰요. 카드별 연출의 소리 자리는 "카드별 VFX와 상호작용 정의하기" 스레드와 맞춰요.
