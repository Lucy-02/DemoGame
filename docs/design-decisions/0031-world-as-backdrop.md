# 0031. 세계관은 배경 한 장, 스토리는 두지 않는다 (서사 범위 0단계)

- 날짜: 2026-11-03
- 단계: 코어 기획 (S3)
- 상태: 수락됨 (Lucy, 2026-11-03 05:30 "로그라이크에다가 슬더슬뽀이한 게임인데 스토리가 지배하면 이상하잖아")

## 맥락
세계관 시안 W1~W4(`design/concepts/world/`)는 전제·화자·바크·도감까지 담은 "서사 범위 1단계"로 만들었어요. Lucy가 게임의 앵커가 덱빌딩 로그라이트(Slay the Spire 문법)라서 스토리가 게임을 지배하면 이상하다고 했어요.

## Lucy의 결정
세계관은 **배경**이에요. 스토리(화자·대사·플롯·엔딩)는 두지 않아요. 서사 범위는 사다리 **0단계**(이름, 카드·유물 문구, 짧은 시작 문장. R2 §7.4, Balatro·슬더슬 수준)예요.

## 그래서 정하는 것 / 정하지 않는 것
- 정해요: 세계 한 문단, 조율사 한 줄, 아홉 기운과 상성을 설명하는 한 줄, 막 = 지역의 이름·모티프, 적은 무엇인가 한 줄, 희귀 카드·각성·성체 갈래 이름의 어휘 출처. → `docs/design/05-world.md` 한 장.
- 정하지 않아요: 화자, 정령의 대사, 플레이어의 과거, 플롯·엔딩, 월드 바이블, 연표·세력. 정령은 말하지 않아요(소리·몸짓만). 이벤트 텍스트는 슬더슬처럼 상황 두세 문장이면 돼요.
- 도감 문구는 종당 한두 문장(있어도 되고 없어도 됨), 바크는 몸짓·소리만(0019와도 맞음).

## 시안 W1~W4의 처리
전제·화자·바크는 **폐기**. 배경으로 쓸 조각만 가져와요: W1 "세계는 고장 나지 않았고, 적은 곁이 없어 거친 들정령"(악당 없음) / W3 "내 다음 기운이 내 약점" 상성 한 줄 / 넷 공통 "적은 흩어져 돌아간다". W4의 "이름을 되찾는다"는 스토리라 배경에 넣지 않되, 성체·각성 이름이 희귀 카드 이름과 같은 어휘에서 나온다는 네이밍 규칙으로만 남겨요.

## 결과와 후속 작업
- `docs/design/05-world.md` 초안 (Claude 추천, Lucy가 고치면 그대로 반영).
- `design/concepts/world/` 시안 4개는 기록으로 남기고 README에 폐기 표시.
- 이름 라운드(적·각성·갈래·희귀 카드)는 이 한 장의 어휘로 진행.

## 추기 (2026-11-03 05:40, Lucy)
"그래도 배경 / 거점 / 싸우는 이유(목표) 정도랑 최종보스·중간보스 스토리는 있어야 하지 않나." → 0단계에 **뼈대 네 가지**를 더해요: 배경 한 문단, 거점 한 줄, 싸우는 이유(목표) 한 줄, 보스 스토리(막 보스 한 줄씩 + 최종 보스 한 문단). 화자·대사·플롯은 여전히 없어요. 뼈대 시안은 `docs/design/05-world.md` §목표와 보스.
