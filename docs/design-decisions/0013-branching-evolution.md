# 0013. 계열별 분기 진화를 코어 기획에 포함

- 날짜: 2026-10-30
- 단계: 코어 기획 (S1 비전·필러)
- 라운드: 코어 기획 스레드 "코어 기획과 세계관 설계"
- 상태: 수락됨 (Lucy, 2026-10-30 12:10). 구조(분기 수·시점·조건 유형)는 아직 미정 → 시안 라운드 진행 중

## 맥락
기획서 v0.2는 성장을 유체 → 성체 → 각성체 3단계로 두고, "각성체와 사용 속성에 따른 진화 분기"는 MVP 이후로 미뤄 뒀어요. 코어 기획 단계에 들어오면서 Lucy가 "정령을 키우는 느낌을 극대화"하기 위해 계열별 기본 정령이 조건·기믹에 따라 여러 갈래로 진화하는 구조(예시: 불씨의 정령 → 불의 정령 / 열기의 정령 / 증기의 정령)를 코어로 올리자고 제안했어요.

## Lucy의 결정
분기 진화를 코어 기획에 넣어요. Lucy가 든 이름(불씨·열기·증기)은 단순 예시이고 네이밍 결정이 아니에요.

## 근거 (Claude 검토, Lucy 동의)
- 추천 중인 메인 게임 포인트 C(발견)와 같은 방향이고, 브랜드 "함께 자라는 동료"를 모습·이름 변화로 한 장면에 담아요.
- 분기 조건을 런에서 한 일(배운 카드 등)에 묶으면 "누가 배울까" 선택이 덱 방향이자 육성 방향이 돼서, 한 기믹이 육성감·덱 정체성·수집 목표·재플레이를 한 번에 풀어요.
- 성격 공개와 합치면 진화 순간이 발견의 클라이맥스가 돼요.

## 조건 (함께 확인한 주의점)
- 콘텐츠가 곱으로 늘어요. 체형 템플릿은 분기끼리 공유(스킨만 교체)하고, MVP 분기 수는 시안 라운드에서 정해요.
- 분기 조건은 보이게 둬요(숨은 조건 금지).
- 분기 자체는 훅이 아니에요(같은 구조의 Montabi, 리뷰 133건). "같은 카드 다른 손"·"성격 공개"와 합쳐질 때 우리 것이 돼요.
- 계열을 섞는 분기(불+물 등)는 "정령 속성 2개"와 상성 규칙에 영향을 주니 세계 규칙으로 한 번에 정해요.

## 결과와 후속 작업
- 기획서 v0.2의 "나중에 다룰 것: 각성체와 사용 속성에 따른 진화 분기"는 코어로 이동. MVP 범위 표의 "진화 분기 없음"은 시안 라운드 결과로 갱신해요.
- 다음: 진화 트리 구조 시안 2~3안(분기 수·시점·조건 유형) → Lucy 선택 → 0014.
- 근거 조사: `docs/research/core-design/`
