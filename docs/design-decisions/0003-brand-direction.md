# 0003. 브랜드 방향: 함께 자라는 동료

- 날짜: 2026-10-28
- 단계: P0 브랜드 전략
- 라운드: R01 (시안 3개), R02 (A 수정)
- 상태: 수락됨

## 맥락
기존 훅 "키운 정령이 배운 마법이 곧 내 덱"은 수식어가 이어져 어색해서 Lucy가 버렸어요. 주 타깃은 수집·육성 층, 보조는 덱빌더 입문자와 전략을 조금 즐기는 슬더슬 경험자. 과하게 화려한 장식은 피함.

## 고려한 선택지
- A 함께 자라는 동료: "정령을 키우면, 덱이 자란다". 애착·성장 중심
- B 조합을 설계하는 지휘자: "세 정령, 하나의 덱". 전략 중심
- C 작은 정원에서 떠나는 모험: "정원에서 기르고, 탐험에서 싸운다". 여정 중심

## Lucy의 결정
A. 리뷰 후 수락한 지적을 반영한 수정본(R02)을 확정. 내용은 `design/BRAND_BRIEF.md`.

## 기각한 것과 이유
- B, C: Lucy가 A를 고름. 새 근거 없이 다시 제안하지 않아요. 다만 C의 "기르고 → 싸운다" 구조는 반론 카드로 보류 중이라 플레이 테스트 때 다시 볼 수 있어요.

## 리뷰 지적 처리 (R01, 리뷰어: 브랜드 전략가, 플레이어+반대자, 접근성)
- 수락: 01 "덱"이 입문자에게 안 통함 → 훅 아래 풀이 문장 / 03 차별점 없음·캡슐 순간 → 캡슐·트레일러 분리 / 05 슬라이더가 전부 같은 칸 → 이유와 겉인상·플레이 분리 / 06 비교작이 연결점이 아님 → 연결점과 타깃 표시
- 보류: 02 훅에 고유 요소 넣기 / 08 반론(C 훅이 더 잘 전달)
- 기각: 04 보조 타깃에 슬더슬 경험자 추가 / 07 성격 공개를 색·섬광에만 의존하지 않는 조건 미리 기록

## 결과와 후속 작업
