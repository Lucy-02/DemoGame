# 0149. 배경 그림 2배 업스케일

- 날짜: 2026-11-18
- 단계: P6 엔진 구현 / 에셋
- 라운드: 배경 후처리
- 상태: 수락됨 (Lucy 2026-11-18: 배경은 업스케일러를 돌린다). 업스케일러는 0150에서 JaNai로 바뀌었어요. 어느 그림을 쓰는지는 그대로 임시예요(0103, 0110~0113, 0122).

## 맥락
배경 그림이 화면과 같은 1280×800이라 창을 키우면 가장 먼저 흐려져요.

## 고려한 선택지
- 그대로 두기
- 원본을 2배로 키워 2560×1600 그림으로 바꾸기

## 결정
- **1~5막 전투 배경과 상점 배경을 2560×1600으로 바꿔요.** 이벤트 · 휴식 · 판 결과는 막 그림을 같이 써요.
- 공정은 정령 그림과 같아요: 원본(1216×768)을 RealESRGAN anime_6B로 4배 키운 뒤 LANCZOS로 2배 크기까지 줄여요. 그다음 후처리는 전과 같고 숫자만 2배예요(`--scale 2`).
- 화면은 그림을 화면 너비에 맞춰 놓아요. 1280×800에서 보이는 모습은 전과 같아요.

## 근거
Lucy의 지시예요.

## 기각한 것과 이유
- 없어요. 붓 질감을 더 살리는 다른 업스케일러(IllustrationJaNai, UltraSharp)는 비교해 보지 않았어요.

## 결과와 후속 작업
- `tools/art/stage-bg.py` · `tools/art/place-bg.py`의 `--scale`, `src/presentation/stage.ts`의 `stageImage`.
- 키운 원본: 프로젝트 파일 `stage-bg/up2x/`, Drive `jjal-handoff/stage-bg-up2x`.
- 남은 것: 게임 캔버스가 1280×800 고정이라 창을 키우면 화면 전체가 늘어나요. 선명해지려면 렌더 해상도 작업이 필요해요(다른 스레드가 맡음).
