# 0011. 카드: 각성 재질 예외 확인 · 카드 동사 "사용" · 성장과 카드 수치 · 연쇄 표식

## 결정
1. **각성 중 카드 c 유지**(0009): 각성한 정령의 손패 묶음 바탕에 그 정령의 속성 재질을 쓰는 재질 규칙 예외를 Lucy가 확인.
2. **카드 동사는 "사용"**: 플레이어에게 보이는 문구에서 카드를 내는 행위는 "사용"으로 통일. "낸다/쓴다"는 쓰지 않음(예: "사용할 수 있는 카드 N", "사용 불가"). 디자인 문서 안의 서술은 바꾸지 않음.
3. **성장과 카드 수치**: 레벨업·성체가 카드 수치를 바꾸지 않음(업계 표준 아님, Lucy 10/30 화면 스레드). 카드 숫자로 성장을 보이지 않고, 카드 쪽 성장 신호는 초상 홈(0008 D1)과 보상·덱 보기의 "이 정령이 배우면 N"(D3). 0008의 D6(성장 순간 바뀐 카드 알림)은 내림.
4. **연쇄 표식 = 사슬 고리** (Lucy 2026-10-30 00:30): 지속 성질 기호(∞, 0008)와 전투 정본의 연쇄 미리보기 표식이 둘 다 ∞ 꼴이라 덱 보기에서 헷갈림(화면 스레드 덱 보기 R2). 지속은 ∞ 유지, 연쇄 표식만 사슬 고리 모양으로 바꿈. 정확한 그림은 시안 단계에서.
