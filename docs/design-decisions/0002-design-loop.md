# 0002. 디자인 작업 루프와 리뷰어 구성

- 날짜: 2026-10-28
- 단계: 작업 방식
- 상태: 수락됨 (리뷰어 구성 Lucy 확정, 2026-10-28)

## 맥락
기존 핸드오프 번들은 원칙(값 지어내지 않기, 회색 박스 먼저, 2~3개 방향)은 좋았지만 리뷰 루프, 게이트, 결정 기록, 토큰 강제, TTI 출처 기록이 없었어요. 근거와 비교는 `docs/design-workflow-report.md`.

## 제안
- 단계 P0~P7, 단계마다 Lucy가 고르는 게이트 하나
- 라운드: 시안 2~3개 → 선택 → 리뷰어 독립 리뷰 → 종합 → 핀 카드 → 스레드 토론 → 결정 기록. 한 단계에 라운드 3회 정도가 상한
- 리뷰어 5명(게임 UX·가독성, 아트 디렉터, 브랜드 전략가, 접근성, 플레이어) + 돌아가며 맡는 반대자 역할. 정의는 `.claude/agents/`
