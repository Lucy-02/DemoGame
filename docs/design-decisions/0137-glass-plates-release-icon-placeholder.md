# 0137. 오른쪽 위 기호의 유리 판, 해방 표지 기호, 아직 없는 기호 자리

- 평가 지적: P7-05(밝은 배경 위 기호), P7-06(번들 글꼴에 없는 글자), P5-10(임시와 빈 칸이 같은 모양).

## 고려한 선택지
1. 오른쪽 위 기호 셋: A 그대로 · B 기호마다 둥근 유리 판 · C 셋을 한 줄 유리 판
3. 순서표 해방 표지: A 글자 `✦` · B 정본 기호 `i-spark` · C 정본 기호 `i-burst`
5. 아직 없는 기호와 빈 장비 칸: A 없는 기호는 그림 자리표시(X 상자), 빈 칸은 점선 · B 없는 기호는 비우고 이름만 · C 그대로

## 결정
1. **덱 · 기록 · 설정 기호는 저마다 둥근 유리 판 위에 놓아요.** 판은 34px 버튼 자리, 순서표 판과 같은 유리와 테. 같은 줄을 쓰는 지도 · 이벤트 · 휴식 · 덱 고르기도 같아요.
2. **해방 표지는 정본 기호 `i-spark`.** 순서표 토큰의 왼쪽 위 배지와 용어 모음의 해방 칸이 같은 기호를 써요. 색은 그대로 밝은 자두빛.
3. **아직 없는 기호 자리는 X 상자, 점선 네모는 빈 칸에만.** 메인 메뉴 · 용어 모음 · 출전 준비의 센 기운 · 보상 넘기기 · 갈래 표지가 그림 없는 칸과 같은 X 상자를 써요. 색은 자리마다 쓰던 색 그대로.

## 기각한 것과 이유
- 1 C 한 줄 유리 판: 순서표 판과 같은 모양이 하나 더 생겨요.
- 3 A 글자 `✦`: 번들 글꼴에 없어 기기마다 다르게 그려져요.
- 5 B 이름만: 용어 모음 줄 맞춤이 어긋나요.

## 남은 것
- `i-spark`는 능력치 집중의 기호로도 쓰여요. 해방 전용 기호가 생기면 `RELEASE_ICON`만 바꿔요.
- 시안 2번(카드의 속성 기호)은 카드 리디자인으로 넘겼어요. 4번(흐린 글자 대비) · 6번(낱말) · 7번(글자 크기)은 0138.
