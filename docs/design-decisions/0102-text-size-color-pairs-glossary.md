### 2. 의미색과 기호 짝
색만으로 뜻을 전하는 곳은 하나예요. 나머지는 기호 · 모양 · 숫자가 같이 있어요.
| 색 | 짝 | 판정 |
|---|---|---|
| 위험(빨강): 받을 피해 · 포기 · 빼기 | 충격 기호 · 가시 테 · 빗금 막대 · 낱말 | 짝 있음 |
| 위험(빨강): **상점에서 골드가 모자란 카드 값** | 동전과 숫자 색만 바뀜 | **색만** (아래 남은 것 1) |
| 위험(빨강): 낮은 HP 숫자 · a→b 내림 | 숫자와 막대 길이 | 짝 있음 |
| 좋음(연두): 치료 · 단계 보정 · a→b 오름 | 하트 기호 · 범례 · 숫자 | 짝 있음 |
| 주의(노랑): 허점 | 토큰 테 + 풀이 칩 `허점` | 짝 있음 |
| 강조(보라): 차징 · 브레이크 · 미리보기 · 해방 | 모래시계 · 깨짐 배지 · 빗금 · `✦` | 짝 있음 |
| 능력치 색(파워 · 가드 · 포커스) | 능력치 기호 | 짝 있음 |
| 희귀도 색 | 보석 모양 · 점 수 | 짝 있음 |
| 속성 틴트 | 속성 기호 | 짝 있음 |

### 3. 호버 풀이가 없던 용어
- 효과문에서 밑줄만 있고 풀이가 없던 것: 화상 · 냉기 · 빙결 · 취약 · 약화 · 반격 · 도발 · 소멸 · 브레이크.
- 전투 기호를 가리켜도 이름과 수만 뜨던 것: 상태 칩 전부, 방어도, 약점, 앞열. `강화` 칩은 풀이가 아예 안 떴어요.
- 어디에도 풀이가 없던 것: 벽 · 지속 · 품기 · 낙하 · 차징 · 허점 · 틈 · 해방 · 쓰러짐.

## 결정
1. **12px 아래 글자는 12px로.** 1280×800에서 가장 작은 글자는 12px이에요.
2. **용어 사전 한 곳.** `src/presentation/glossary/terms.ts`에 이름 · 기호 · 풀이(합니다체 한두 문장, 숫자는 규칙 데이터에서 읽음) 22개가 있어요. 효과문 밑줄, 전투 기호 호버, 용어 모음 창이 같은 문구를 써요.
3. **전투 기호 호버에 풀이 첫 문장.** 상태 칩 · 방어도 · 약점 · 앞열을 가리키면 `이름 수 · 풀이 첫 문장`이 한 줄로 떠요.
4. **용어 모음은 기호 격자 + 호버 풀이(B).** 설정 창과 같은 틀 · 같은 머리. 칸은 기호 + 이름뿐이고 세 줄 격자, 묶음(상태 · 카드 · 전투)은 가는 선으로만 나눠요. 칸에 올리면 창 오른쪽에 유리 말풍선(이름 + 풀이)이 떠요. 기호가 없는 용어는 점선 칸이에요.
5. **메인 화면과 판 안 메뉴에서 열어요.** 둘 다 `설정` 바로 위 줄 `용어 모음`(책 기호). Esc · 창 밖 · `닫기`로 닫고, 판 안에서는 메뉴로 돌아와요.

## 기각한 것과 이유
- A 한 장 목록(풀이를 모두 펼친 세 열): 글이 화면을 채워 웹 문서처럼 읽혀요 (LUCY_CRITERIA 8, 0050).
- C 목록 + 오른쪽 풀이 판: 창이 넓어지고 풀이 판이 대부분 비어요. 풀이가 한두 문장이라 말풍선으로 충분해요.
- 묶음 제목(`상태` · `카드` · `전투`): 라벨이라 선으로만 나눴어요 (0090과 같음).
- 카드 말풍선 안에 용어 풀이 덧붙이기: 카드 말풍선 정본을 바꾸는 일이라 따로 물어요.

1. 상점에서 모자란 카드 값의 색 짝. 후보: 서비스 칸처럼 값만 흐리게 / 카드째 회색(손패의 못 내는 카드와 같은 모양).

3. 기호가 없는 용어 여덟(벽 · 품기 · 낙하 · 허점 · 틈 · 약점 · 해방 · 쓰러짐).
