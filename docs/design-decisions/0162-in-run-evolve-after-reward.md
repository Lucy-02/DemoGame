# 0162. 판 안 진화는 전투 보상 뒤 정령 화면에서

- 날짜: 2026-11-21
- 단계: 코어 기획 (성장 메타 · 런 흐름)
- 라운드: 프로젝트 스레드 "육성과 런 구조 코어 기획 다시 잡기"
- 상태: 수락됨 (Lucy 2026-11-21 결정 카드 "보상 뒤 정령 화면"). 돌아가기 버튼 글자와 미루기 규칙은 작업 가정이에요.
- 앞 결정: 0157 (성장은 판 안에), 0037 (진화 컷신), 0058 (갈래 고르기)

## 맥락
0157로 진화가 판 안으로 들어와서, 판 안 어디에서 키울지 정해야 했어요.

## 고려한 선택지
- 보상 뒤 정령 화면
- 전투 결과 창의 정령 줄에서 바로
- 휴식 칸에서

## Lucy의 결정
1. **전투 보상을 고르고 지도로 돌아올 때, 키울 수 있는 정령이 있으면 정령 화면이 열려요.**
2. 정령 화면의 성장 길 탭 · 갈래 창 · 진화 컷신을 그대로 써요.

## 근거
- 확정된 화면을 그대로 써서 새 시안 없이 바로 해 볼 수 있어요.

## 기각한 것과 이유
- 전투 결과 창에서 바로, 휴식 칸에서: Lucy가 고르지 않았어요.

## 작업 가정 (Lucy 확인 대기)
- 판 안에서 연 정령 화면의 돌아가기 버튼은 `지도`예요.
- 키우지 않고 돌아가면 다음 칸을 마친 뒤 다시 열려요.
- 판 안에서 정령 화면을 따로 여는 길은 아직 없어요.
