# 0035. 정령을 바꿀 때 전환

- 날짜: 2026-11-06
- 단계: 정령 관리 화면 / 움직임
- 상태: 수락됨 (Lucy가 시안에서 "보통"을 고름). 값은 임시 토큰(`provisional.motion.spiritSwap`)

## 맥락
다른 정령을 고르면 화면 전체를 지우고 다시 그려서, 아무 전환 없이 한 번에 바뀌었어요. 후보는 A 그림만 살짝 교차, B 띠 방향으로 밀기, C 등장 연출이었어요. 정비할 때는 여러 정령을 빠르게 넘겨 보니까 판단을 막지 않는 A를 골랐어요.

## 정한 것
- **그림:** 전체 240ms. 이전 그림은 제자리에서 앞 40% 동안 옅어지고, 새 그림은 25% 늦게 나타나요.
- **방향:** 새 그림은 띠에서 고른 쪽에서 24px 밀려 들어와요. A에 B의 방향감만 더했어요.
- **숫자와 패널:** 바로 바뀌어요.
- **능력치 막대:** 개요 탭끼리 넘어갈 때 이전 정령의 값에서 새 값으로 240ms 동안 움직여요. Lucy: "막대 움직이는건 어때 비용이 높으면 말고". 그려 둔 막대만 다시 그려서 비용이 낮아요.
- **퍼핏:** 각성체 퍼핏과 색 번짐도 그림과 같이 움직여요.
- **전환이 없는 때:** 탭을 바꾸거나 패널을 여닫거나 같은 정령에서 키울 때는 전환하지 않아요.
- **연달아 누를 때:** 지금 보이는 투명도와 자리에서 다음 전환을 이어 가요.

## 기각한 것
- 완전 교차(240ms 내내 겹침): 두 정령이 이중 노출처럼 비쳐요.
- 빠름(160ms / 16px), 느림(360ms / 32px): 시안에서 비교했고 보통을 골랐어요.

## 남은 것
- 동작 줄이기 옵션이 아직 게임에 없어요. 생기면 이 전환도 끄거나 줄여요(0012).
- 막대는 지금 표기(`value / 40`)에 붙어 있어요. 표기 A·B·C를 정하면 막대가 있는 안에 옮기고, A면 빼요.
