## 먼저 할 것 (밖의 사람이 처음 해 볼 때 막히는 것)
1. **소리 기본 세트.** 효과음(버튼 · 카드 집기/놓기/사용 · 타격 세 무게 · 방어 · 상태 · 적 차징 · 브레이크 · 보상 · 지도 이동 · 승리/패배)과 음악 루프(메인 · 지도 · 전투 · 보스). 상용 배포가 되는 라이선스만 쓰고 출처를 `assets/provenance.jsonl`에 적어요. 예전 후보(R1~R3, 무료 녹음 모음)는 Lucy가 2026-11-05에 폐기했으니 다시 쓰지 않고, 게임용으로 만든 한 제작자 세트(유료 포함)에서 새로 골라요. 기능(타격이 타격처럼 들리기)이 컨셉보다 먼저예요. 볼륨 묶음은 전체 · 음악 · 효과음 셋.
2. **첫 판 안내.** 첫 전투는 고정 조우(적 하나, 브레이크할 차징 한 번). 개념(순서표에 놓기 · 차징 끊기 · 턴 종료)은 처음 한 번만 짚고, 풀이는 호버에 둬요(0019 · 0050). 대사 · 화자는 없어요(0031). 짚는 모양은 시안 라운드에서 정해요.
3. **설정 화면과 판 안 메뉴.** 설정: 볼륨 셋, 창/전체화면, 게임 속도, 화면 흔들림 · 번쩍임 끄기. 값은 저장해요. 판 안 메뉴(Esc와 톱니): `계속` · `설정` · `메인으로`(저장하고 나감) · `탐험 포기`. 메인 화면의 설정도 같은 화면을 열어요.
4. **창 크기 맞춤.** 기준은 1280×800 그대로, 창에 맞춰 비율을 지키며 늘이고 남는 곳은 바닥색. 전체화면 전환을 둬요.
