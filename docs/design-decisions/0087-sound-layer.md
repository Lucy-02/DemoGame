# 0087. 소리 재생 층과 소리 붙는 자리

- 날짜: 2026-11-17
- 단계: P6 엔진 구현
- 라운드: 프로젝트 스레드 "소리 기본 세트 정하고 넣기"
- 상태: 수락됨 (Claude 판단, Lucy 위임 2026-11-17). Lucy가 번호로 뒤집을 수 있어요. 어떤 소리를 쓸지는 여기서 정하지 않아요 (듣기 라운드에서 Lucy가 골라요)
- 앞 결정: 0084 1번

## 판단
1. **묶음 셋.** 전체 · 음악 · 효과음. 실제 음량 = 전체 × (음악 또는 효과음). 값은 platform 저장 키 `settings`의 `volume`에 0 ~ 1로 둬요. 기본값 전체 1 · 음악 0.6 · 효과음 0.8은 임시예요.
2. **소리 목록은 열여섯 + 음악 넷.** `ui.click` · `ui.hover` · `card.pick` · `card.place` · `card.play` · `hit.light` · `hit.medium` · `hit.heavy` · `block` · `status` · `charge` · `break` · `reward` · `map.move` · `victory` · `defeat`, 음악 `menu` · `map` · `battle` · `boss`.
3. **사건과 파일은 `src/presentation/audio/bank.json` 한 곳에서 이어요.** 한 사건에 파일이 여럿이면 번갈아 나요. 비어 있으면 소리가 없어요. 소리를 바꿀 때는 이 파일과 `public/assets/audio/`만 고쳐요.
4. **타격 세 무게는 규칙의 결과로 갈라요.** 치명 · 약점은 무겁게, 저항했거나 방어가 절반 넘게 받아 냈으면 가볍게, 나머지는 보통. 방어가 다 받아 냈으면 방어 소리. 피해량 기준 숫자는 두지 않아요.
5. **버튼 소리는 한 곳에서 달아요.** 누를 수 있는 것에 올리면 `ui.hover`, 누르면 `ui.click`. 화면은 예외만 표시해요 (손패 카드는 집기 · 놓기 · 사용 소리, 지도 칸은 `map.move`).
6. **음악은 화면이 정해요.** 판 밖은 `menu`, 지도 · 이벤트 · 휴식 · 상점 · 보상은 `map`, 전투는 `battle`, 보스 칸은 `boss`. 같은 곡이면 끊지 않고, 바뀔 때는 서로 잦아들고 올라와요 (600ms, 임시).
7. **소리는 정보를 대신하지 않아요.** 소리로만 알리는 것은 없어요 (0019). 창이 가려지면 멈춰요.
8. **출처.** 소리 파일도 `assets/provenance.jsonl`에 적고 `pnpm check:assets`가 봐요. 저장소가 공개라서, 원본 재배포를 막는 라이선스의 파일은 저장소에 넣지 않아요 (CC0만 넣거나, 저장소를 비공개로 돌린 뒤에 넣어요).

## 기각
- 피해량으로 타격 무게 가르기: 기준 숫자를 지어내야 하고 막마다 달라져요.
- 화면마다 버튼 소리 달기: 화면이 늘 때마다 빠져요.

## 후속
- 소리 고르기 (듣기 라운드), 설정 화면의 슬라이더 연결 ("설정과 판 안 메뉴" 스레드), 드로우 · 진화 · 장비 같은 목록 밖 소리.
