# 0073. 문서 정리에서 나온 질문 넷

- 날짜: 2026-11-16
- 상태: 수락됨 (Lucy, 2026-11-16)

## Lucy의 결정
1. 문구 규칙 13절(이야기 서술)·14절(대사)은 지우지 않고 지금은 쓰지 않는 절로 둬요 (0031과 맞춤).
2. 적이 큰 행동을 모으는 것은 **차징**으로 불러요. "캐스팅"은 쓰지 않아요 (0022 열린 용어 하나 닫음).
3. 문구 규칙 숫자 표의 `끊기까지 3칸` 예시는 지워요 (0019 F6).
4. "모든 정령은 기본 피해 / 기본 방어 / 기본 기술 3칸 틀을 공유"는 0040의 시작 덱(할퀴기 · 막기 · 대표 카드 2)으로 대체됐어요.
