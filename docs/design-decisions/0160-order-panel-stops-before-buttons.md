# 0160. 순서표 판은 버튼 앞에서 멈추고, 넘치면 빈 자리부터 줄여요

- 날짜: 2026-11-21
- 단계: P4 화면 디자인
- 라운드: 평가 1라운드 적용 (P5-12), 시안 https://claude.ai/artifact/RbpU81DKzoBQkKcENWgpqk
- 상태: 수락됨 (Lucy 2026-11-21 "마. 작게 + 자리 줄이기"). 토큰 크기는 고르는 중.

## 맥락
적 행동이 다섯이면 순서표 판이 덱 버튼을 덮고, 일곱이면 화면 밖으로 나갔어요. 칸마다 카드 두 장 자리를 미리 잡아 두기 때문이에요 (0077 0번).

## 결정
- **판은 가운데에서 자라다 오른쪽 위 버튼 앞에서 멈춰요.** 버튼과의 틈은 버튼의 화면 여백과 같아요.
- **넘치면 차례로 줄여요**: 모든 칸을 가장 긴 묶음에 맞추던 것을 풀고(칸마다 제 묶음만큼) → 빈 칸에 잡아 둔 카드 자리를 둘에서 하나, 없음으로 → 토큰 사이 선.
- 꽉 찬 전투에서는 카드를 놓을 때 적 토큰이 옆으로 밀려요 (0077 0번의 예외).
- **토큰은 지금보다 작게 가요.** 토큰은 누구의 무슨 행동인지만 가리고, 내용은 가리켜서 읽어요. 크기 값은 Lucy가 고른 뒤 넣어요 (TODO_TOKEN, 지금은 얼굴 40 그대로).

## 기각한 것과 이유
- 두 줄 판: 순서를 지그재그로 읽고 재생 위치 선이 줄을 건너뛰어요.
- 버튼을 판 아래로 내리기, 뒤 행동을 +n으로 접기 (Lucy가 고르지 않음).
