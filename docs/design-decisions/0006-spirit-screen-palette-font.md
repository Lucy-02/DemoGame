# 0006. 정령 관리 화면 뼈대·팔레트·글꼴·정본

- 상태: 수락됨 (Lucy, 2026-10-29)
- 방식: 0004 (병렬 컨셉 → 체리피킹). 기준 장부 `design/concepts/LEDGER.md`, 정본 페이지 https://claude.ai/artifact/6mauUwAoRT9KSmGidBnWx3, 캡처 `design-concepts/archive/` (공유 폴더)

## 결정
- 정령 관리 뼈대: R2 "캐릭터 선택" 레이아웃 + R3 "C 전면 일러스트 + 유리 패널" + R2 "목록과 무대"의 탭(개요 · 성장 길 · 카드 n/m · 유대 n/3, 탭에 숫자). 키우기는 성장 길 안.
- 오른쪽 패널은 "닫기"로 세로 탭 레일로 접힘. 접힌 상태엔 필요한 정보만 담은 요약 카드(다음 단계 · 덱에 보태는 카드 · 할 일은 있을 때만).
- 아래 띠: 원형 얼굴 + 다음 단계 링 + 단계 칩 + 할 일 배지 + 출전 깃발, 타일 사이 디바이더. 이름 카드에 능력치 한 줄 + 성격.
- 잠긴 카드는 한쪽에 겹친 더미 + 장수. 위쪽 돌보기·편성 전환은 빼고 편성은 띠 왼쪽 버튼.
- 목록엔 보유 정령만. 유대는 상시 노출 X.
- 브랜드 톤: 단계별로 다르게 (유체·성체 아늑, 각성체 우아·장엄). `design/BRAND_BRIEF.md`
- 팔레트: 다크 기본, "무채 유리 + 한 가지 강조". "정원의 아침"은 라이트 후보로 보관. 값은 아직 토큰 아님.
- 글꼴: Orbit 단일, 빠진 글자는 Pretendard 대체. 라이선스 OFL.
- 작업 방식 보강: 모든 시안은 장부에서 시작하고 장부 대비 변경을 적음. 고친 것은 새로 만들지 않고 기존 시안을 수정.

## 폐기
도감 빈칸·실루엣, 40칸 그리드+다중 필터, 보관함과 편성, 오늘의 돌봄판, 좌측 리스트. 그림 아래 할 일 알림, 출전 편성 모드, 띠 범례, 띠 왼쪽 할 일 요약(복원하지 않음).

## 보류 · 열린 질문
개요 탭 존치. 탐험 밖 상태(HP), 별도 레벨, 먹이기·성격 다시 뽑기 위치, 편성 위치, 싱크로율 범위. R4 리뷰 고칠 거리: `design/concepts/reviews/r4-*.md`.
