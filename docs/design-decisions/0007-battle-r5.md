## 결정
- 뼈대: R4 C "판단 동선". 카드를 집어 조준하면 필드에 결과 미리보기. (대체됨: 0013 — 조준선 대신 끌어 대기 + 집고 클릭, 대상 강조·나머지 어둡게)
- 미리보기 예산: 필드엔 조준 대상 결과 + 아군별 받을 피해 a→b만. 연쇄·지연·다음 턴 효과는 카드 설명에.
- 받을 피해 합계는 쉬는 상태에도 상시. 결과는 조준 대상에만.
- 호버: 살짝 키우고 옆 카드 밀림 + 카드 위 짧은 말풍선(H1, 추천안으로 기록). 필드는 어둡게 하지 않음.
- 손패 ▲ 성장 표시 + 호버 계산 줄. 못 내는 카드도 정령 얼굴은 컬러. 마력 부족은 동전 테, 다른 사유는 글 띠.
- 차징: 남은 실드 칸 수 상시, "끊김" 한 곳. 비피해 의도는 다른 모양. 순서표는 상단 한 줄, 의도와 같은 번호.
