# 0018. 밸런스 기준선과 정령 한 장 템플릿

- 날짜: 2026-10-30
- 단계: 코어 기획
- 상태: 수락됨 (Lucy, 2026-10-30 14:40 "이대로 쭉 진행하자")

## 맥락
Lucy가 "밸런싱 규칙을 지금 잡아야 하나, 캐릭터 기믹·구성을 미리 봐야 하나, 기본 3캐릭이면 괜찮나"를 물었어요.

## Lucy의 결정 (Claude 제안 채택)
- 밸런싱은 숫자 튜닝 대신 **기준선 한 장**만 지금 잡아요. 숫자는 플레이테스트·시뮬 뒤에.
- 캐릭터는 **정령 한 장 템플릿**을 정하고 MVP 3종만 채워요. 나머지 40종은 필러·진화·상성 결정 뒤 정체성 한 문장부터.
- MVP 3캐릭으로 충분해요. 파티 선택("셋을 골라")은 6종쯤에서 처음 시험하고, 출시 줄 수 결정(가안 초기 12)에서 확정해요.

## 결과
- `design/canon/BALANCE_BASELINE.md`: 1마나 값표, 정령 폭, 희귀도 = 조건·복잡도 등급, 고정 규칙, 적 폭, 바꾸는 법.
- `design/canon/spirits/TEMPLATE.md`, `sheets/{fire-fox,glass-salamander,mist-cat}.md`.
- 템플릿을 채우다 보인 빈 칸: **유리 도롱뇽 성체(희귀) 전용 카드가 없음**. 카드 40장에 수호 희귀가 0장이에요. 다음 카드 라운드의 할 일.
