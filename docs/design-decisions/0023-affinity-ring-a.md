# 0023. 9속성 상성: 고리 A (물 > 불 > 숲 > 땅 > 전기 > 얼음 > 물), 바람 중립, 빛 ↔ 그림자

- 날짜: 2026-10-30
- 단계: 코어 기획 (S3 세계 하드 규칙)
- 라운드: 코어 기획 스레드, 시안 문서 [9속성 상성 구조 시안 R1](https://claude.ai/artifact/6s8DThkQxsXi1VjhEWpd4x)
- 상태: **추천안 채택** (Lucy 포괄 승인 "머지하고 쭉쭉 진행해", 2026-10-30). 빛·그림자 "희귀" 여부는 열린 질문.

## 맥락
속성이 9종으로 늘어(0016) 기획서의 상성(물>불>숲, 바람 중립, 빛↔그림자)을 다시 짜야 했어요. 모양만 다뤘고, 배율(×1.5 / ×0.75)과 실드 규칙은 그대로예요.

## 고려한 선택지
| | 고리 A | 고리 B | 삼각형 둘 |
| --- | --- | --- | --- |
| 고리 | 물>불>숲>땅>전기>얼음>물 | 불>얼음>숲>땅>전기>물>불 | 물>불>숲>물 + 얼음>땅>전기>얼음 |
| 외울 것 | 고리 하나 | 고리 하나 | 삼각형 둘 + "서로 닿지 않는다" |
| 직관이 약한 고리 | 전기 > 얼음 하나 | 없음 | 전기 > 얼음 하나 |
| 기획서의 물>불>숲 | 유지 | 물>불만 유지 | 유지 |
| MVP 데이터 | 그대로 | 불 정령이 숲 적을 못 깨므로 수정 | 그대로 |
| 세계 설명 | 여섯 원소가 한 바퀴 | 같음 | 자연 셋 + 날씨·지질 셋, 두 계통 |

## 채택한 안
- **고리 A.** 물은 불을 끄고, 불은 숲을 태우고, 숲은 땅을 뿌리로 가르고, 땅은 전기를 흘리고, 전기는 얼음을 깨뜨리고, 얼음은 물을 얼려요. 속성당 약점 1 / 강점 1.
- **바람은 중립.** 바람 적은 약점·실드가 없는 대신 HP가 낮아요(기획서 그대로).
- **빛과 그림자는 서로가 서로의 약점.** 고리 밖.
- **막마다 나오는 적 속성을 제한해요.** 정령 셋으로 깨뜨릴 수 있는 적 속성은 최대 셋이므로, 막 = 세계의 지역이고 그 지역의 속성만 나와요. MVP 1막은 불·숲·바람(0017). 땅·전기·얼음 적은 2막 이후.
- 깨뜨릴 수 없는 적이 나오는 막의 안전장치 둘은 기획서에 이미 있어요: 실드 없는 저HP 적(바람형) 섞기, 상성 없이 캐스팅을 끊는 수단(빙결).

## 근거
- Lucy가 확정한 물>불>숲을 지키고, MVP 데이터를 건드리지 않고, 외울 건 고리 하나예요.
- 약한 고리 하나(전기가 얼음을 깨뜨린다)는 세계 설명 한 줄로 덮어요(S3 세계관 브리프의 할 일).
- 분기 진화(0022)와 엮이면 막의 속성 제한이 동기가 돼요: "2막에 얼음 적이 나오니 전기 갈래로 키워볼까".

## 기각한 것과 이유
- 고리 B: 더 예쁘지만 "불이 숲을 태운다"를 버리는 값이 커요(MVP 파티가 숲 적을 못 깸).
- 삼각형 둘: 안전하지만 여섯이 한 세계로 엮이지 않고, 두 삼각형 사이가 중립이라 파티 압력이 "어느 삼각형 막인가"로 바뀌어요.

## 열린 질문
- **빛·그림자를 계속 "희귀"로 둘지.** 정령 풀에 빛 5·그림자 6이 있고 초기 계보에도 둘씩 있어요. 추천안: 정령으로서는 희귀가 아니라 보통 줄(풀에 있는 대로)이고, **적으로서는 늦은 막에만** 나와요. 기획서 속성 표의 "이후 (희귀)"는 "이후 (늦은 막)"으로 읽어요. Lucy가 정하면 고쳐요.
