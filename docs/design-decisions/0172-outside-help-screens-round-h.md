# 0172. 판 밖 도움 화면: 다시 뽑기 버튼 · 공명 줄 · 열린 성격 고르기

- 날짜: 2026-11-27
- 단계: 화면 (전투 보상 · 정예 장비 차례 · 출전 준비 · 판 결과)
- 라운드: 판 밖 도움 라운드 H (세 안 → 섞기 → 정리안). 링크는 `design/concepts/LINKS.md`
- 상태: 수락됨 (Lucy 2026-11-27 결정 카드 세 장). 색 · 크기 · 간격은 임시 값이에요.
- 앞 결정: 0157 (다시 뽑기 · 열린 성격), 0170 (새 장비 또는 공명 +1), 0171 (이름), 0051 · 0064 (전투 결과 창 · 장비 줄), 0078 (출전 준비)

## 고려한 선택지
- 세 안: H1 버튼 줄에 / H2 바뀌는 것 곁에 / H3 물건 둘 가운데
- 정리안 ① 공명 줄 놓기: 가. 반 폭 둘 나란히 / 나. 온 폭 둘 위아래
- 정리안 ② 열린 성격 펼침: 가. 칩 아래 줄 / 나. 칩 옆으로

## Lucy의 결정
1. **다시 뽑기 = H1**: 전투 보상 카드 차례, `넘기기` 옆 같은 판의 버튼과 남은 수. 다시 뽑기를 받고 떠난 판에만 보이고, 다 쓰면 흐려진 채 남아요. 풀이는 버튼 호버.
2. **공명 올리기 = H3, 온 폭 둘 위아래**: 올릴 장비가 있으면 새 장비 줄 아래에 같은 판의 `공명 +1` 줄. 하나를 집어 정령에게 줘요. 올릴 칸은 실선 테, 오르는 공명 점은 자두빛, 달라지는 것은 장비 말풍선 그대로. 올릴 장비가 없으면 장비 줄 하나예요.
3. **성격 고르기 = H1, 칩 아래 줄**: 출전 준비 자리 칸의 성격 칩. 열린 성격이 있으면 화살표가 붙고, 누르면 칩 아래 줄에 펼쳐져요(고르는 동안 능력치 줄 자리를 써요). 풀이는 호버.
4. **판 결과 = H1**: 완주로 열린 성격은 정령 줄의 `[성격] 열림` 칩, 늘어난 다시 뽑기는 버튼 줄 옆 a→b.

## 근거
- 공명 줄 위아래: 지금 장비 줄(0064)을 그대로 써요.
- 칩 아래 줄: 성격이 여덟이라 열린 것이 늘어도 줄을 더할 수 있어요.

## 기각한 것과 이유
- H2 전부, H1의 `공명 올리기` 버튼, H3의 골드 옆 다시 뽑기 자원 · 가운데 성격 고르기 창: Lucy가 고르지 않았어요.
- 반 폭 둘 나란히, 칩 옆으로 펼침: Lucy가 고르지 않았어요.

## 결과와 후속 작업
- 구현: 고른 성격은 떠날 때 정원에 적용돼요. 떠나기 전에는 되돌릴 수 있어요.
- 🛠 작업 가정: 다시 뽑기 기호는 `TODO_ICON`, 버튼 호버 풀이 문구(`보상 카드를 모두 새로 받아요. 판마다 다시 채워져요.`).
- 남은 것: 기술 카드가 붙은 긴 장비 말풍선이 공명 줄을 덮는 자리, 열린 성격이 넷을 넘을 때 둘째 줄이 자리 칸 아래로 나오는 것.
