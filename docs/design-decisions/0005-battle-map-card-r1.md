# 0005. 지도·보상·전투 구조·카드 1차 확정

- 상태: 수락됨 (Lucy, 2026-10-28~29)
- 방식: 0004 (병렬 컨셉 → 체리피킹). 링크 전체는 `design/concepts/LINKS.md`

## 결정
- 지도: R2 C — 가까운 길 크게 + 전체 12층 미니맵 + 슬림 파티 패널, 절제된 글래스
- 보상: "정원 그림책" 컨셉의 보상 화면
- 전투: R2 B(주인 묶음 손패) 기반. 과밀 완화 중. 우상단 기록 자리를 아이콘식 해결 순서표로(규칙은 `TIMELINE_QUESTIONS.md`, 기획 필요)
- 마력·턴 종료: 관례형 분리 — 마력은 손패 왼쪽 끝, 턴 종료는 오른쪽 단독. 낼 카드가 남으면 차분, 없으면 강조, 남은 채 누르면 확인(설정에서 끔). 리뷰: `design/concepts/reviews/endturn-*.md`
- 카드: 그림 창 + 얇은 이름 띠, 5:7. SD 초상 홈, 정령별 창 윗선, 효과 기호+최종 수치, 손패 단색 속성 기호. 효과 설명은 손패에서 숨기고 호버로.
- 재질: 손패는 이름 띠만, 호버 시 카드 전체. 불=밝은 용암석, 물=유약, 숲=한지+잎맥, 바람=비단, 무속성=무지. 최종은 텍스처 이미지로 굽기. 리뷰: `design/concepts/reviews/card-material-*.md`
- 정보 원칙(전투 손패 한정, 잠정): 익히는 정보는 기호·호버, 판단 정보만 상시.

## 폐기
작전판, 테이블 위 카드 게임 컨셉. 카드 "효과가 곧 그림", 티켓, 책등. 구운 흙 불 재질.
