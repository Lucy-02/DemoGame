## 지금 상태
0084의 먼저 할 것 넷 가운데 소리 파일만 남았어요(재생 층 · 첫 판 안내 · 설정과 판 안 메뉴 · 창 크기는 main). 2막이 켜졌고(한 판 = 2막까지), 화면 자동 한 판 점검(`pnpm test:run`)이 있어요.

## 다음에 채울 것 (순서대로)
1. **적과 배경 그림.** 전투에서 적이 전부 빈 네모이고 배경이 없어요. 밖의 사람이 보는 첫 화면이라 가장 커요. 1막 적 열과 보스 셋부터, 그다음 1막 배경 한 장. 방식은 정령 그림과 같은 TTI 파이프라인(프롬프트 시트 → 후보 → 후처리 → `assets/provenance.jsonl`). 2막은 1막 방향이 서면 이어서.
2. **데모 빌드.** `pnpm dist`로 맥 · 윈도 빌드가 실제로 뜨는지, 데모 범위(1~2막, 시작 정령 넷, 깃들기 두 번), 데모 끝 화면, 저장 위치 · 버전 · 오류 기록 확인. 스팀 페이지 · 이름 · 로고는 Lucy 몫이라 넣지 않아요.
3. **글자 크기 · 색 짝 점검과 용어 모음.** 1280×800에서 가장 작은 글자, 의미색마다 기호가 짝지어 있는지, 호버 풀이가 없는 용어. 용어 모음 화면은 풀이 문구를 재사용해 메뉴에서 열어요.
4. **2막까지 도는 화면 자동 점검**과 휴식 두 번 눌림 같은 입력 안전(보고 넘어가는 동안 입력 막기).
5. 뒤로: 지난 판 기록, 정령 · 카드 확장(출시 15줄), 3~5막 켜기(원정 구조 Lucy 선택 뒤), 컨트롤러, 영어.

## 기각한 것과 이유
- 정령 · 카드 확장을 먼저: 지금 있는 한 판이 빈 네모와 무음인 채로 내용만 늘어나요.
- 3~5막 바로 켜기: 원정 구조(두 막씩 끊어 떠나기)가 Lucy 선택 대기예요.
