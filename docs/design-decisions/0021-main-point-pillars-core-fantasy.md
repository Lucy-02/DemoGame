# 0021. 메인 게임 포인트 C(발견) · 필러 세트 가 "동료" · 코어 판타지 가

- 날짜: 2026-10-30
- 단계: 코어 기획 (S1 비전·필러)
- 라운드: 코어 기획 스레드 "코어 기획과 세계관 설계"
- 상태: **추천안 채택** (Lucy 포괄 승인 "머지하고 쭉쭉 진행해", 2026-10-30). Lucy가 다른 안을 고르면 새 기록으로 대체해요.

## 맥락
조사(R1~R3)와 종합 문서([코어 기획 워크플로우](https://claude.ai/artifact/F8WGf2AitAzQ7QmTKy6CBx))에서 1단계 질문 세 개를 Lucy에게 올렸어요. 메인 게임 포인트 후보 A 육성 / B 조합 / C 발견 / D 각성, 필러 세트 가 "동료" / 나 "지휘", 코어 판타지 문장 가 / 나 / 다. Lucy는 개별 선택 대신 추천대로 진행하라고 했어요. 전제는 분기 진화가 코어에 들어간 것(0015)이에요.

## 고려한 선택지
### 메인 게임 포인트
| 후보 | 한 줄 | 위험 |
| --- | --- | --- |
| A 육성 | 카드가 아니라 정령을 키우는 덱빌더 | Montabi가 접은 축, 두 화면에 걸친 인과라 한 장면에 안 보임 |
| B 조합 | 세 정령의 조합이 곧 빌드, 같은 카드도 누가 쓰느냐에 따라 다르다 | 정원·육성의 존재 이유가 약해짐 |
| C 발견 | 키운 정령의 성격이 드러나고 그 개성대로 싸운다. 덱은 정령의 개성이다 | 성격 콘텐츠 분량, 아늑함과 로그라이트 관객 분리 |
| D 각성 | 싱크가 차오르는 순간 정령이 깨어나 적의 주문을 끊는다 | 익숙한 문법이라 훅보다 앵커 |

### 필러 세트
- 가 "동료": 카드마다 주인이 있다 / 키우면 넓어지지, 세지지 않는다 / 쓰러져도 돌아온다 / 한 번만 터진다
- 나 "지휘": 셋이 한 손이다 / 약점을 읽는 자가 이긴다 / 매 판 다른 셋 / 숫자는 정직하다

### 코어 판타지
- 가: 당신은 정령들의 보호자가 되어, 함께 자란 셋과 탐험을 떠난다. 정령이 자랄수록 손에 든 카드가 그 아이의 것이 된다. 그러면 애착과 뿌듯함을 느낀다 (판타지 + 발견)
- 나: 당신은 세 정령을 지휘하는 사람이 되어, 조합으로 적의 약점을 뚫는다. 그러면 영리함을 느낀다 (도전)
- 다: 당신은 정령과 호흡을 맞추는 동반자가 되어, 싱크가 차오르는 순간을 만든다. 그러면 고양감을 느낀다 (감각 + 판타지)

## 채택한 안
1. **메인 게임 포인트: C를 중심으로 B를 합치고, D는 보여주는 장면으로.** "같은 카드 다른 손"(B)은 C의 증거이고, 각성(D)은 트레일러·컷인에 쓰는 앵커예요.
2. **필러 세트 가 "동료" 네 문장.** 세트 나의 "숫자는 정직하다"는 전투 R5 "판단 동선"(0007)과 같은 뜻이라 필러가 아니라 전투 원칙으로 둬요. 다섯 번째 필러로 올릴지는 열린 질문.
3. **코어 판타지 가.** "보호자"는 자리표시예요. 플레이어가 세계 안에서 누구인지는 S3 세계관 라운드에서 정해요.

## 근거
- 경쟁작에 없다고 확인된 우리 조각 둘(같은 카드 다른 손, 진화 때 드러나는 성격)이 모두 C에 살아요 (R3).
- Lucy가 고른 브랜드 방향 "함께 자라는 동료"(0003)와 같은 방향이에요.
- 세트 가의 네 문장은 이미 내린 결정(각성만 연출, 해금 풀 확장, 레벨업은 카드 수치 안 바꿈 0011, 영구 사망 없음)을 그대로 묶어요. 걸리는 것이 두 개(공용 카드, 도전 모드 이탈)뿐이에요.

## 기각한 것과 이유
- A 육성 단독: Montabi가 접은 땅이고 정면 비교돼요. C 안에 흡수.
- B 조합 단독: 정원이 존재 이유를 잃고 "Cobalt Core의 크리처판"으로 읽혀요.
- D 각성 단독: 앵커이지 훅이 아니에요.
- 세트 나: "매 판 다른 셋"은 MVP 3종이면 조합이 하나뿐이라 지금 검증할 수 없고, "약점을 읽는 자"는 치명타 확률(운)과 걸려요.
- 판타지 나·다: 주 미학이 도전/감각이라 메인 포인트 C와 어긋나요.

## 필러로 거른 기존 결정 (Lucy "기존 결정에 매몰되지 말라")
| 기존 결정 | 필러와의 관계 | 채택한 처리 |
| --- | --- | --- |
| 정원의 무게 | "키우면 넓어진다" | 정원은 메뉴 한 화면으로 가볍게 유지. "키우기"의 무게중심은 탐험 안의 "누가 배울까"와 런 종료 진화(0012)에. 라이프심으로 키우지 않는다고 명시 |
| 공용 카드 10장 (바람·무속성) | "카드마다 주인이 있다" | 데이터 확인 결과 통과: 보상에서 배운 정령의 것이 되고(`run.ts` `addCard(cardId, owner)`), 시작 덱의 공용 카드도 `startOwner`로 주인이 있어요. 주인 없는 카드는 없음 |
| 도전 모드 "런 끝까지 이탈" | "쓰러져도 돌아온다" | 지금은 유지. 난이도 사다리 라운드에서 "다음 전투까지 부상"(Wildfrost식)과 비교 |
| 훅의 한 장면 | 메인 포인트 C | 후보 둘: "같은 카드가 정령마다 다른 값으로 놓인 손패" / "진화 순간 성격이 드러나며 카드가 바뀌는 장면". 시각 결정이라 Lucy 몫. 브랜드 브리프 "보여줄 순간"을 고칠 때 고름 |
| "정령" 용어 | — | 게임 안 용어는 유지. 영어 제목·태그는 S4 네이밍 라운드 |
