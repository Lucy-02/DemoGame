## 규칙으로 정리된 것 (제안)

- `탐험 떠나기`는 어디서나 같은 자리·아이콘·낱말이에요. 메인 화면에서는 늘 채움이고 첫 포커스예요.
- 뱃지 숫자는 눌러서 할 행동의 개수예요. `새`는 처음 본 것이고 첫 방문에 지워져요. 겹치면 숫자만 보여요.
- 새 정령이 기다리는 판의 런 결과에는 `다시 떠나기`를 숨겨요.
