## Lucy의 결정
- **C + 약점 표지만 상시.** 접힌 판에는 체력바·숫자, 방어도, 대표 상태 하나, 아군 받을 피해, 적 약점 표지. 속성·상태 전부·앞열은 가리키면 펼침.
- 유닛 85%, 간격 72%(각 편 가운데 유닛 기준).
- 기호화(직관적이면 진행): 받을 피해 = 체력바 미리 깎기 + 충격 기호 숫자, 치명 = 판 위험색 테. 약점 = 마름모 테 + 속성 기호(상태 칩과 다른 모양). 앞열 = 깃발. 전체 대상 = 점 셋. 조건 미달 = 카드 윗선 자물쇠 + 조건 기호.
- 적 설명판은 가리킨 적 바로 아래. 왼쪽 위 지역·층·턴 줄은 삭제.
- 적 설명판 문구 "브레이크로 끊을 수 있어요" → "브레이크 가능".

## 근거
