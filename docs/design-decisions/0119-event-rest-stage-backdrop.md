# 0119. 이벤트 · 휴식 배경: 지금 막의 전투 배경에 창 뒤 덮개

- 날짜: 2026-11-18
- 단계: P6 엔진 구현
- 라운드: 전투 밖 화면 배경
- 상태: 수락됨 (디렉터 판단, Lucy 위임 2026-11-17). Lucy 확인 대기.

## 맥락
이벤트 · 휴식은 '배경 + 왼쪽 판 + 오른쪽 얇은 정령 줄'로 정해져 있는데(0080 · 0082), 배경 자리가 어두운 민무늬 바닥이었어요. 다섯 막의 전투 배경이 생겼어요(0103, 0110~0113).

## 고려한 선택지
- 지금 막의 전투 배경 + 창 뒤 덮개
- 민무늬 바닥 그대로
- 이벤트 · 휴식마다 다른 그림

## 결정
- **이벤트 · 휴식의 배경 자리에 지금 막의 전투 배경을 깔고, 창 뒤 덮개(`scrim` 토큰 그대로)로 눌러요.** 새 값은 없어요.
- 그림을 못 부르면 민무늬 바닥 그대로.
- 상점 · 지도 · 판 결과 · 정원은 정하지 않아요. 시안으로 Lucy가 골라요.

## 근거
같은 막 안에서 싸우던 곳과 쉬는 곳이 이어져 보여요.

## 기각한 것과 이유
- 민무늬 바닥: 정해 둔 배경 자리가 비어 보여요.
- 화면마다 다른 그림: 새 그림은 Lucy가 고를 일이라 지금은 만들지 않아요.

## 결과와 후속 작업
- `src/presentation/stage.ts`(전투에서 옮김), `src/presentation/run/backdrop.ts`(막을 주면 그림 + 덮개), 이벤트 · 휴식 장면.
- 남은 것: 상점 · 지도 · 판 결과 · 정원 배경.
