# 0164. 메인 배경은 움직이는 전용 배경

- 날짜: 2026-11-22
- 단계: P6 엔진 구현 / 에셋
- 라운드: 메인 배경 1
- 상태: 종류는 수락됨 (Lucy 2026-11-22). 그림 · 움직임 정의는 디렉터 판단, Lucy 확인 대기

## 맥락
0121에서 메인 배경은 "전용 또는 움직이는 전용"으로 미정이었어요. 여정을 따라 필요한 배경을 다시 세어 보니 새로 만들 그림은 메인 한 장이에요.

## 결정
- **메인 배경은 움직여요** (Lucy). NAI 5 투명 배경으로 요소 · 텍스처를 따로 만들어도 돼요 (Lucy).
- 아래는 디렉터 판단이에요. 정의 전문: `design/concepts/main-bg/BRIEF.md`
  - 움직임 네 층: 시차 / 흐름(구름 · 연기) / 바람(잎 · 풀 · 천 · 등불, 정령 퍼핏과 같은 메시) / 빛 · 입자(화면이 그림). 집 · 울타리 · 땅은 안 움직여요.
  - 움직일 것은 투명 배경으로 따로 뽑아 얹고, 바탕은 그것들을 뺀 한 장이에요.
  - 리깅 정밀도는 대상별 네 등급, 통과 조건 일곱, 검수는 화면 12칸을 차례로 확대해요.
  - 수치(진폭 · 주기 · 격자)는 `TODO_TOKEN`. 파일럿에서 재고 Lucy가 고른 뒤 넣어요.
