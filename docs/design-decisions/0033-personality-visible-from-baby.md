# 0033. 성격은 유체부터 보여요

- 날짜: 2026-11-05 (Lucy의 결정은 2026-11-03)
- 단계: 코어 기획 / 정령 관리 화면
- 상태: 수락됨. 효과가 켜지는 시점은 Lucy 확인 대기

## 맥락
0021과 0027은 유체 때 성격을 `???`로 숨겼다가 성체로 진화할 때 공개했어요. 진화 순간을 발견의 클라이맥스로 삼는 안이었어요(0015).

## Lucy의 결정
성격은 유체부터 보여요.

> "성격 기믹 보고 이건 이렇게 키워야지 하는 흐름도 닫아버리는거잖아 원래대로라면"

숨기면 성격을 보고 키울 방향을 정하는 흐름이 막혀요. 그 흐름을 여는 쪽을 골랐어요.

## 한 일
- 정령 관리 화면: 유체의 이름 카드와 개요 탭에 성격 이름·설명이 나와요. 유체에는 `성체가 되면 효과가 나요`를 덧붙여요.
- 성장 길의 성체 줄: `성격 공개` → `성격 효과 시작`.
- 목업 정령은 성격을 아직 정하지 않아서 `???`와 `아직 정하지 않았어요`를 그대로 보여요.
- 규칙(`src/core`)은 바꾸지 않았어요. 골든 스냅샷도 그대로예요.

## 그대로 둔 것
- 성격 효과는 성체부터 켜져요(`activePersonality`).
- 성격 다시 뽑기는 성체부터예요(`growth.json`, 0021).
- 갈래 조건에 성격을 쓰지 않아요(0027).

## 남은 것 (Lucy 확인 대기)
- 유체 때 효과도 켤지, 다시 뽑기를 유체부터 열지. 효과를 켜면 전투 규칙과 골든 스냅샷이 바뀌어요.
- 비전의 메인 포인트 "발견(C): 키운 정령의 성격이 드러나고"(0026, `docs/design/01-vision.md`)와 훅 후보 "진화 순간 성격이 드러나는 장면": 성격이 처음부터 보이니 문장을 다시 정해야 해요.
