- 수락된 기록은 고치지 않아요. 바꿀 때는 새 기록을 쓰고 옛 기록에 "대체됨: NNNN"을 적어요.
- 기각된 선택지와 이유도 꼭 적어요. 다음 세션이 같은 안을 다시 꺼내지 않게 하려고요.
