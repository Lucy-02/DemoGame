## 결정
1. **상점에서 골드가 모자란 카드는 카드째 회색.** 손패의 못 내는 카드(0043 · 0050)와 같은 모양이에요. 값은 붉은 그대로 흐리지 않아요. 예전의 옅은 회색조(60%)는 지웠어요.
2. **카드 말풍선에 밑줄 용어의 풀이가 이어 떠요.** 효과문 아래, 주인 줄 위에 용어마다 한 문단(`이름` 강조 + 풀이). 글자는 계산 줄과 같고 문구는 용어 사전에서 읽어요. 손패 · 보상 · 상점 · 고르기 창의 말풍선이 모두 같아요.
3. **기호가 없는 용어는 전투에서 쓰는 표지를 그대로.** 허점 = 순서표 토큰의 노란 테, 약점 = 조준 테, 해방 = 순서표 `✦`, 쓰러짐 = 쓰러진 정령 얼굴의 붉은 점선 테.
4. **표지가 없는 넷(벽 · 품기 · 낙하 · 틈)은 후보만 냈어요.** 용어마다 세 개(정본 세트 하나 + 새 초안 둘). Lucy가 고르기 전에는 점선 빈 칸 그대로예요.
5. **켜진 약점 배지는 옆 칩을 덮지 않아요.** 배지 양옆에 늘 3px 자리를 둬요. 켜져도 옆 칩이 밀리지 않아요.

## 기각한 것과 이유
- 모자란 카드의 값만 흐리게: 색만 바뀌는 문제가 그대로예요.
- 틈 칩 · 품었던 카드 표식 재사용: 결정(0072 · 0075)에는 있지만 지금 전투 화면 코드에 그 표지가 없어요. 생기면 용어 모음이 그대로 가져다 써요.

## 남은 것 (Lucy 확인 대기)
- 기호 후보 고르기(벽 · 품기 · 낙하 · 틈). 새 초안을 고르면 정본 세트(`public/assets/ui/icons/`)에 넣어요.
- 용어가 셋 이상인 카드는 말풍선이 길어져요. 길이 상한은 실제 카드에서 보고 정해요.
