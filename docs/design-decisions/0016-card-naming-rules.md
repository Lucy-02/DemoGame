# 0016. 카드 네이밍 규칙: 기본은 "~기", 올라갈수록 고유명사

- 날짜: 2026-10-30
- 단계: 코어 기획 (네이밍)
- 상태: 수락됨 (Lucy, 2026-10-30 14:13). 8절 기본값 4개와 음차 금지는 Claude 제안 → Lucy 확인 대기

## 맥락
카드 40장의 이름이 한국어 동사구(기본·일반)와 라틴어·영어 음차(고급·희귀)로 섞여 있었고, 네이밍 결정은 없었어요. Lucy 요청으로 Opus 에이전트가 성공작 카드명 표본 약 900개, 한국어 현지화 기풍, 실패 사례를 조사했어요(`docs/research/core-design/R4-card-naming.md`).

## 고려한 선택지
- A 몸짓 이름: 기능 우선, 고유어 동사형 전 등급.
- B 정령 말버릇: 주인 우선, Hades식 [어휘 + 슬롯] 명사구.
- C 자라는 말씨: 성장 우선, 등급이 오를수록 고유어 → 한자어·문어.
- Claude 추천: 기본·일반 A, 전용 카드에만 B 어휘, 희귀 C.

## Lucy의 결정
"~기"는 하위·기본 기술에 좋고, 강해질수록 고유명사나 간지 나는 이름으로. 조사 내용은 스쿼시·증류해서 최종 규칙만 남김.

## 근거
- 성공작 카드명은 짧고(중앙값 3~4자), 희귀로 갈수록 추상·장엄(스파이어)하거나 고유명사(발라트로 전설)로 격상돼요.
- 브랜드 브리프의 "유체·성체는 다정, 각성체는 장엄"을 말씨의 층으로 옮긴 것이에요.
- 공용 불 카드는 불여우·유리 도롱뇽 둘이 배우므로 정령 어휘는 전용 카드로 제한해요(0015 "같은 카드, 다른 손").

## 기각한 것과 이유
- 전 등급 동사형(A 단독): 희귀가 특별하지 않고 동사가 고갈돼요.
- 전 등급 슬롯 틀(B 단독): 틀이 드러나면 조립품처럼 읽혀요.
- 라틴어·영어 음차: 현행 긴 이름이 거의 음차였고 현지화 주류와 어긋나요(확인 대기).
