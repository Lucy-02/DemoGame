## 맥락

## 고려한 선택지
- 준비 표식: a 접힌 모서리 / b 꼭지 표식(▼) / c 받침 줄
- 각성 중 카드: a 초상 홈 + 남은 턴 / b 카드 전체가 재질로 / c 묶음 바탕이 재질로
- 모션 성격: 가 가벼운 종이 / 나 묵직한 판 / 다 재질 따라

## 결정
- **준비 표식 c 받침 줄**: 숫자판 안쪽 아래 굵은 줄. 못 내는 카드는 속 빈 줄(채움 → 윤곽). 호버·포커스 카드에도 표시. 크기는 UI 크기 토큰을 따름(TODO_TOKEN).
- **각성 중 카드 c 묶음 바탕이 재질로** + 초상 홈 테 + 머리표 "각성 · 남은 N턴". 카드 몸체는 그대로. **재질 규칙 예외**: 정령 단위 상태에 한해 묶음 바탕에 그 정령의 속성 재질을 씀(0005 "재질: 손패는 이름 띠, 호버 때 전체"의 예외).
- **모션 성격 가 가벼운 종이**. 확정은 구조 세 가지: 기울기 씀, 넘침 씀(상한 토큰), 속성별로 다르게 하지 않음. 시간·곡선 값은 실전 속도 테스트 뒤(TODO_TOKEN). 빠르게 모드는 첫 박자(들어올림) 생략.
- **▲**: 원인과 상관없이 "기본보다 오름"(능력치·성장·각성). 원인은 호버 계산 줄.
- **대상 의존 준비**(점화 등): 조건을 채우는 대상이 하나 이상이면 표식. 대상별 확인은 조준 미리보기(0007).
- 쓰러짐 띠는 묶음 얼굴을 덮지 않게 옆으로. 모션 줄이기에서도 시전한 정령을 정지 표시로 남김.
