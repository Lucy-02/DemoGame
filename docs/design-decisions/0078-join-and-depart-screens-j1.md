## 결정
깃들기와 출전 준비 모두 **J1 무대 하나**예요. 시안 https://claude.ai/artifact/FsL7WxvqmjcMg4cNtVamHw, 프레임 `/mnt/project-files/design/round-j/J1/`.

- **깃들기**: 화면 전체 어두운 무대에 후보 둘이 가운데 축 대칭으로 같은 크기 · 같은 줄에 서요. 후보마다 그림(유체) · 이름 · 속성 · 역할 기호 · 성격 칩 · 대표 카드. 상자 없이 무대 두 자리이고, 고른 자리만 자두빛 테. 버튼은 아래 가운데 한 자리, 고르기 전엔 꺼진 `고르기`, 고르면 `<이름> 고르기`.
- **깃듦 박자**: 안 고른 후보가 사라지고 고른 정령이 가운데로 옮겨 서요 → 옅은 빛(섬광 없음) → 이름 · 기호 · 성격 → 정령 얼굴 줄에 새 자리 → `계속`. 누르면 끝 상태, 동작 줄이기는 끝 상태 정지 화면.
- **둘째 깃들기**: 한 판에 두 번 연달아일 때만 위 가운데 진행 표시(방금 얻은 얼굴 · 선 · 지금 자리 고리).
- **출전 준비**: 메인 화면 위 가운데 유리 틀. 가진 정령이 같은 크기 자리 칸으로 나란하고, 앞열은 자두빛 테 + 깃발 기호 하나. 칸을 누르면 앞열이 바뀌어요. 위에 오늘 센 기운 칩(기호만, 이름은 호버). 칸마다 이름 · Lv, 속성 · 역할 기호, 능력치, 작은 장비 칸, 새 카드 칩. `취소` · `떠나기`(첫 포커스, 밝은 유리 판, 깃발 기호 없음).

## 디렉터가 고친 점 (구현에 반영)
1. 오늘 센 기운 칩은 기호만, 이름은 호버 풀이(0050).
2. 빈 장비 칸은 0064 작은 장비 칸 정본 모양 그대로.
3. 진행 표시는 연달아 두 번일 때만.
4. 새 카드 칩과 성격 칩은 같은 칩 부품 · 같은 자리.
5. 시안 장면 근거의 상성 오류(숲 > 땅)를 고침. 상성은 물 → 불 → 숲 → 물뿐이에요.
