# 0066. 여정에서 장비가 보이는 곳과 바뀌는 곳

- 날짜: 2026-11-13
- 단계: 코어 기획 (장비 · 유저 여정)
- 라운드: 장비 기획 다각도로 확장 스레드
- 상태: 수락됨 (Lucy 2026-11-13 "추천대로" 셋)
- 관련: 0046 런 화면 묶음 A, 0047 정원과 창, 0048 공명 · 분해, 0056 장비 규칙, 0064 장비 화면

## 맥락
장비 화면을 정예 보상 하나만 만들었어요. 다른 화면에 장비를 놓기 전에 여정 전체에서 어디에 보이고 어디에서 바뀌는지를 정했어요.

## Lucy의 결정
### 원칙
1. 정령이 보이는 곳에는 장비 칸도 작게 보여요. 장비는 정령에 붙은 것이에요.
2. 화면의 숫자는 늘 장비가 반영된 값이에요. 어디서 온 값인지는 정령 보기에서만 쪼개요.
3. 장비가 바뀌는 순간은 넷이에요: 정예 보상, 보스 뒤, 런 끝, 정원.
4. 바뀌는 순간에만 크게 다루고, 나머지는 호버 말풍선이에요(0064).

### 여정 표
| 여정 | 보이는 것 | 할 수 있는 것 | 반영되는 것 |
| --- | --- | --- | --- |
| 정원 · 정령 관리 | 남긴 장비, 공명, 빈 칸 | 보기, 분해와 공명 권 | 능력치에 남긴 장비 값 |
| 갈래 고르기 | 전용 무기가 있으면 갈래별 기술 카드 | 보기 | 고른 갈래로 기술이 정해짐 |
| 각성체로 자람 | 칸 1 → 2, 공명 상한 | 보기 | 칸이 늘어남 |
| 출전 준비 | 정령마다 가져가는 장비 | 보기 | 남긴 장비가 그대로 따라감 |
| 지도 · 정령 보기 | 얇은 줄의 작은 칸, 펼치면 능력치의 장비 몫 | 보기 | 없음 |
| 전투 | 정령 옆 작은 칸 | 보기 | 능력치, 손패의 기술 카드, 조건부 효과, 전설의 대가 |
| 정예 보상 | 장비 줄, 줄 안 칸(0064) | 받기, 바꾸기 | 줄의 증감 |
| 상점 · 휴식 · 이벤트 | 정령 줄의 칸 | 보기 | 없음 |
| 덱 보기 | 대표 카드 자리에 기술 카드 | 보기 | 없음 |
| 보스 뒤 | 전설 셋 | 하나 고르기 | 얻는 것과 대가 |
| 런 끝 | 지닌 장비 | 남길지 고르기 | 다시 남기면 공명 +1 |
| 도감 | 얻어 본 장비 | 보기 | 없음 |

### 고른 것
- **정원에서의 관리는 보기와 분해 · 공명 권까지예요.** 규칙(0048 · 0056) 그대로예요.
- **상점 · 휴식 · 이벤트의 정령 줄에도 장비 칸이 늘 보여요.** 같은 것은 같은 자리에 있어요.
- **기술 카드가 장비에서 왔다는 표시는 덱 보기와 말풍선에만 있어요.** 카드 위에는 표식이 없어요.

## 기각
- 정원에서 남긴 장비 내려놓기, 출전 전에 가져갈 장비 고르기.
- 상점 · 휴식 · 이벤트에서 장비 칸 숨기기.
- 기술 카드 위의 장비 표식, 표시 없음.

## 구현 1단계 (2026-11-13, 평소 자리)
- 정령 관리 이름 카드: 능력치 아래 32px 칸과 공명 점, 빈 칸은 점선. 올리면 말풍선이 칸 아래에 떠요. 고정 장면 `?screen=spirits&scene=equip`.
- 전투 정보판: 상태 줄 오른쪽 끝에 24px 칸(든 칸만). 올리면 말풍선이 정보판 아래에 떠요. 카드를 집거나 끄는 동안에는 뜨지 않아요. 고정 장면 `?screen=battle&scene=equip`(`&hover=equip:<아군>:<칸>`).
- 말풍선과 그 값은 공용이에요: `src/presentation/run/equipTip.ts`(`drawEquipTip`), `run/fromCore.ts`(`equipSheet`), 작은 칸은 `run/equip.ts`(`miniSlotNode`). 크기는 Q2-A f5에서 잰 임시 값(`run/layout.ts` `EQUIP_MINI`)이에요.
- 전투 화면은 아직 규칙에 연결되지 않아서 고정 장면에만 보여요.
