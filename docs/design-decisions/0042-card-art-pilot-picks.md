# 0042. 카드 일러스트: 구도는 카드마다 고르고, 파일럿 8장 확정

- 날짜: 2026-11-07
- 단계: 카드 아트 (파일럿)
- 상태: 수락됨 (Lucy, 2026-11-07 "r6에서 네가 뽑은거 / 그리고 별빛은 원래 골랐던 게 낫다", "전체적으로 정돈되었으며 짜치지 않는다", 크기는 실물 기준)

## 맥락
R1~R3는 물체 하나를 가운데 두는 구도(B)만 시험했어요. 물체만 고집한 건 Claude의 가정이었어요. Lucy가 "산사태는 똥조각 같다", "왜 오브젝트만으로 표현하려 하냐. 상황·배경·상징 일러스트도 있을 수 있다"고 해서 R6에서 장면(S)·배경(P)·상징(M)을 더 뽑았어요. 기록은 `design/card/art/rounds/`에 있어요.

## Lucy의 결정
- 구도를 하나로 묶지 않아요. 카드마다 물체(B)·장면(S)·배경(P)·상징(M) 중 맞는 걸 골라요.
- 가장자리에서 몸 일부만 들어오는 구도(C)는 쓰지 않아요 ("꼬리인지 뿔인지만 보인다").
- 파일럿 8장 (그림은 `design/card/art/rounds/picks/`):

| 카드 | 구도 | 그림 |
|---|---|---|
| 별빛 | 물체 | R2 `star_01-B-o-s3101` |

## 크기 (Lucy 2026-11-07 "실물 크기 기준인데 적절히 조정", "흑요석 뿔도 좀 키워")
- 물체·상징 그림은 `tools/art/fit_art.py`로 창 가운데(톱니 아래 영역의 중심)에 놓고, **물건의 실제 크기 순서**대로 크기를 정해요. 장면·배경 그림은 창을 채우므로 맞추지 않아요.
- 파일럿 값(`--size`, 물체 크기 ÷ 그림 한 변): 유리 벽 0.56 · 흑요석 뿔 0.54 · 꼬리 쓸기 0.42 · 유리 파편 0.38 · 별빛 0.36. 결과는 `design/card/art/rounds/picks/fitted/`. 새 카드는 이 다섯 장 사이에 끼워 정해요.

## 게임에 넣은 것
- 목록 `design/card/art/picks.json` → `tools/art/import_card_art.py <원본 폴더>` → `public/assets/cards/<id>.webp`(512px) + `assets/provenance.jsonl`(status placeholder).
- 그리기: `CardVM.illustration`(`src/presentation/card/art.ts`의 `CardArtId`)이 있으면 그림 창에 덮어 그리고, 없으면 X 상자 자리. 확인용 장면 `?scene=art`.
- 유리 도롱뇽·산양은 아직 게임 데이터·얼굴·창 윗선이 없어서, 파일럿 그림은 실제 카드에 연결하지 않았어요.
