# 0024. 출시 범위: 초기 계보 12줄 + 땅·전기·얼음 1줄씩 = 15줄, 전부 분기

- 날짜: 2026-10-30
- 단계: 코어 기획 (범위)
- 상태: **추천안 채택** (Lucy 포괄 승인 "머지하고 쭉쭉 진행해", 2026-10-30). 0016·0020의 열린 질문 "출시 줄 수, 분기 적용 범위"를 닫아요.

## 맥락
정령 풀은 43줄(초기 12 · 동물 12 · 추상 13 · 정통 판타지 6)이고 줄마다 성체가 둘로 갈려요(0022). 43줄 × 분기는 1인 개발 범위를 넘어요. 0020에서 "출시 줄 수 결정(가안 초기 12)"으로 미뤄 뒀어요.

## 고려한 선택지
초기 계보 12줄은 불·물·숲·바람·빛·그림자 각 2줄이에요. **땅·전기·얼음 정령은 초기 계보에 없어요** (동물 1 · 추상 4 · 정통 판타지 5에 있음).

## 채택한 안
- **나. 출시는 초기 계보 12줄 + 땅·전기·얼음 1줄씩 = 15줄, 15줄 전부에 분기(성체 2)를 넣어요.** 분기를 "일부 줄만"으로 쪼개지 않아요. 필러 "키우면 넓어진다"가 줄마다 같은 깊이로 보여야 해서예요.
- 각성체는 15줄 모두 1개씩(갈리지 않음, 0022).
- **MVP는 그 중 3줄**(불여우·유리 도롱뇽·안개 고양이, 0017). 파티 선택("셋을 골라")은 **6줄**에서 처음 시험해요(0020).
- 땅·전기·얼음 3줄은 **Lucy가 모티프를 골라요**(0016: 모티프는 Lucy). 후보는 풀에 있는 대로: 땅 = 산양(동물) / 석등(추상) / 지진·룬(정통 판타지), 전기 = 섬광(추상) / 뇌우의 무녀·사념(정통 판타지), 얼음 = 첫눈(추상) / 겨울 여왕(정통 판타지). Claude 추천은 **산양·섬광·첫눈**(초기 계보의 "동물·자연물" 말씨와 가장 가깝고, 정통 판타지의 인간형은 각성체 톤과 겹쳐요).
- 나머지 28줄은 출시 후 확장(업데이트·DLC). 풀 문서(`design/canon/spirits/pool-2026-10-30.yaml`)는 그대로 두고 `lineage`로 구분해요.

## 근거
- 상성 고리 A(0023)의 여섯 속성이 정령 쪽에도 다 있어야 "2막에 얼음 적이 나오니 전기 갈래로 키워볼까"가 성립해요. 가(12줄)는 물·전기·얼음 적을 아무도 못 깨요.
- 스킨 60 + 인간형 리그 15는 1인 개발에서 출시까지 닿는 범위예요. 24줄이면 거의 두 배.
- 파티 조합 455면 "매 판 다른 셋"이 충분히 보여요.

## 기각한 것과 이유
- 가: 속성 셋이 비어 고리 A의 절반이 적 전용이 돼요.
- 다·라: 분량이 두 배·세 배. 분기를 빼고 줄만 늘리는 변형도 기각 — 줄마다 깊이가 다르면 "키우면 넓어진다"가 일부 정령에서만 참이 돼요.
- "분기는 일부 줄만": 위와 같은 이유.
