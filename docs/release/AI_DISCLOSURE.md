# AI 사용 공개 근거

스팀 콘텐츠 설문은 개발 중 AI 도구로 만든 것(그림 · 코드 · 소리 등)을 모두 적으라고 해요. 설문 = 장부 = 스토어 문구가 같아야 해요.
아래는 문구가 아니라 문구의 재료예요. 스토어에 실릴 문장은 Lucy가 정해요.

## 범위 (사실)
| 범위 | AI 사용 | 사람이 한 일 | 근거 |
| --- | --- | --- | --- |
| 정령 · 적 · 카드 · 배경 그림 | NovelAI Diffusion(V4.5 · V5)로 생성 | 방향 · 프롬프트 시트 결정, 생성, 선별, 후처리 | `assets/provenance.jsonl` |
| 기호 · 커서 등 UI 벡터 | 생성 모델 없음 | AI 코딩 도구(Claude)가 SVG로 그림, 모양은 Lucy 확정 | 같은 장부 (`model: 없음`) |
| 퍼핏(움직이는 정령) | 그림은 위와 같음 | 파츠 분리 · 리깅 | 같은 장부, `docs/architecture/0002-spirit-puppet.md` |
| 코드 · 문서 | AI 코딩 도구(Claude)가 대부분 작성 | 기획 · 방향 · 화면과 그림의 모든 결정, 검토 | 커밋 기록, `docs/design-decisions/` |
| 소리 | 아직 없음. 들어오면 장부에 출처 · 라이선스를 적어요 | | `assets/PROVENANCE.md` |
| 게임 실행 중 생성 | 없음 | | |

- 숫자는 `pnpm check:assets --summary`가 장부에서 바로 세요. 설문을 쓸 때 그날 값으로 다시 뽑아요.
- 2026-11-18 값: 빌드 파일 395개, 생성 모델 299개(모두 임시), 손으로 만든 것 96개(출시용 37).

## 빈칸
- 생성 값(seed · prompt)이 없는 줄 28개, 모델이 추정 · 미확인인 줄 4개예요. 모두 임시 상태예요.
- 이런 줄은 `release`로 올릴 수 없어요(`pnpm check:assets`가 막아요). 원본 PNG에서 값을 다시 읽어 채우거나, 출시 그림으로 바꿔요.

## 검사
| 명령 | 실패하는 때 | 도는 곳 |
| --- | --- | --- |
| `pnpm check:assets` | 기록 없는 파일, 기록과 해시가 다른 파일, 빈칸이 있는데 `release`인 줄 | `pnpm check`, CI |
| `pnpm check:assets --release` | 위에 더해 임시 상태 파일 | 출시 직전에 손으로 |

## Lucy가 정할 것
- 스토어 페이지에 실릴 AI 공개 문장. 사람이 한 일(기획 · 설계 · 선별 · 후처리 · 리깅 · UI)을 먼저 말하는 쪽을 권해요.
- 출품할 행사가 있으면 그 행사의 AI 규정(전체가 AI 생성물이면 배제하는 곳이 있어요).
