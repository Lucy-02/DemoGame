# 스팀: 연동 · 패키징 · 영어 · 위시리스트 자리

## 이미 된 것 (0101 · 0139)
- 데모 스위치와 데모 끝 화면, 버전 표시, 오류 기록 (0101).
- 저장 폴더 이름을 앱 이름과 떼어 `demogame`으로 고정했어요(`electron/main/index.ts`의 `USER_DATA_DIR`). 게임 이름이 정해져 `productName`이 바뀌어도 저장은 그 자리에 있어요.
- 두 번 실행 막기: 이미 떠 있으면 그 창을 앞으로 가져와요.
- 윈도 데모 패키지를 CI가 만들고 그 실행 파일로 스모크를 돌려요(`windows-package` 잡).
- 데이터에 없는 정령의 퍼핏은 패키지에 넣지 않아요(빌드 142MB → 79MB).

### 클라우드 경로
- 올릴 파일: 저장 폴더의 `saves/garden.json`, `saves/run.json`. 데모와 본편이 같은 곳을 써요(0101 5번).
- 올리지 않을 것: `saves/settings.json`(전체화면은 기계마다 달라요), `saves/runlog.json`, `saves/*.bak.json`, `logs/`.
- 폴더: 윈도 `%APPDATA%\demogame\saves`, 맥 `~/Library/Application Support/demogame/saves`, 리눅스 `~/.config/demogame/saves`.
- 폴더 이름 `demogame`은 한 번 밖에 내면 바꾸지 않아요. 바꾸고 싶다면 데모 공개 전에 말해 주세요.

## 성능 숫자
| 숫자 | 재는 곳 |
| --- | --- |
| 실행부터 첫 화면까지 | `pnpm test:e2e` (`tests/e2e/perf.spec.ts`), 결과 폴더 `perf.json` |
| 전투 화면 프레임 시간 (p50 · p95 · 최대) | 같은 곳. 실제 GPU 기계에서 `DEMOGAME_PERF_BUDGET=1`이면 800p 30fps 기준을 넘는지도 봐요 |

CI는 GPU가 없어 프레임 값이 느리게 나와요. 실제 값은 Lucy 기계나 테스터 기계에서 패키지된 앱으로 재요(`DEMOGAME_EXE`).

## 영어
넥스트 페스트는 게임당 한 번이라, 참가 전에 스토어와 데모가 영어로 나와야 해요. 한국어로 먼저 만들고 그 뒤에 해요.

- **양** (2026-11-18): 소스 안 한글 문자열 약 1,400개. 카드 이름 · 효과 데이터(`src/data/locales/ko/`), 화면 문구(`copy.ts` 15개 파일, 329줄), 용어 풀이(`src/presentation/glossary/terms.ts`). 늘 보이는 글자가 이름 · 숫자 · 버튼 동사뿐이라(0050) 화면 문구는 적어요.
- **구조에서 할 일**
  1. 화면 문구를 언어별로 고를 수 있게 `copy.ts`를 모아요.
  2. 효과문 틀(`src/core/text.ts`)에 영어 문장 틀을 더해요. 조사(`josa()`)는 한국어에서만 써요.
  3. 카드 · 정령 · 적 이름의 영어 이름. 이름은 Lucy가 정해요(`design/canon/naming/`).
  4. 효과문 상자와 버튼을 영어 길이로 확인해요.
  5. 글꼴이 라틴 글자를 덮는지 확인해요.
- 캡슐에 글자를 넣으면 지원 언어마다 따로 만들어야 해요.

## 위시리스트 자리 (제안, Lucy가 골라요)
지금은 데모 끝 화면에만 있고, 그 화면은 2막 보스를 이겨야 떠요. 봇 두 판은 모두 그 전에 져서 닿지 못했어요. 데모 플레이 시간의 중앙값은 30분을 넘지 않아요.

| 안 | 자리 | 장점 | 걸리는 것 |
| --- | --- | --- | --- |
| A | 데모 끝 + 메인 화면 메뉴에 한 줄 | 누구나 한 번은 봐요 | 메인 메뉴 줄이 하나 늘어요(0054) |
| B (추천) | A + 진 판의 판 결과 | 대부분의 판이 끝나는 자리예요 | 판 결과에 버튼이 하나 늘어요(0046) |
| C | B + 판 안 메뉴 | 자리가 가장 많아요 | 하던 판을 떠나게 해요 |

- 데모 빌드에만 보여요. 버튼 낱말과 모양은 데모 끝 화면과 같이 정해요(0101, Lucy 확인 대기).
- 스토어 페이지 주소가 생겨야 연결할 수 있어요.
