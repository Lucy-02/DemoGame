## 다음 관문: 데모 공개
데모는 **넓고 얕은 전체**예요(Lucy 2026-11-18): 지금처럼 2막까지, 임시 그림을 포함해요. 스팀 덱 · 컨트롤러는 지금 범위 밖이에요(Lucy 2026-11-18).
아래 통과 조건은 제안이에요. 고르거나 빼 주세요.
1. 깨진 저장에서 복구돼요 (P8-01, 다른 묶음).
2. 처음 보는 사람 5~6명이 첫 판을 해 봤고, 나온 문제를 고친 뒤 한 번 더 봤어요.
3. 소리 기본 세트가 들어가 있어요.
4. 게임 이름이 정해지고 스토어 페이지가 열려 있어요.
5. 윈도 패키지 스모크가 초록이고, 실제 윈도 기계에서 한 판을 해 봤어요.
6. 임시 그림은 임시로 읽혀요(빈 상자 없이). 어디까지 고른 그림으로 바꿀지는 Lucy가 정해요.
7. 스팀으로 실행하면 오버레이가 뜨고 닫힌 뒤 입력이 돌아와요.

## Lucy 몫 (바깥 일)
- 게임 이름 → 스토어 페이지(캡슐 + 스크린샷 5장 이상) → 데모 공개 → 출시 직전 넥스트 페스트 1회. 이름이 찜 수집의 첫 관문이에요.
- Steamworks 가입 · 앱 ID 발급(본편과 데모). 받은 뒤의 순서는 `docs/release/STEAM.md`.
- 콘텐츠 설문의 AI 항목 작성 (`docs/release/AI_DISCLOSURE.md`).
- 국내 등급 분류 경로 확인(게임물관리위원회 · Steamworks 최신 안내). 조사에서 확인하지 못했어요.
- 플레이테스트할 사람 모으기 (`docs/release/PLAYTEST.md`).
- 피치 묶음의 예산 · 일정 (`docs/release/PITCH.md`).
