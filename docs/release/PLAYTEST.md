# 플레이테스트: 처음 보는 사람

봇과 페르소나는 "글 없는 안내가 통하는가"에 답하지 못해요. 사람 5~6명을 보고, 고치고, 다시 봐요. 작게 여러 번이 한 번 크게보다 나아요.

## 한 번의 테스트
- **사람**: 이 게임을 처음 보는 5~6명. 덱빌더를 해 본 사람과 안 해 본 사람을 섞어요.
- **빌드**: `pnpm dist:demo`가 만든 `release/demo/` 폴더를 그대로 건네요. 윈도용은 CI `windows-package` 잡의 `demo-win-unpacked`에서 받을 수 있어요(7일 보관).
- **시키는 것**: 첫 판 하나. 설명하지 않고, 물어도 답하지 않아요. 화면과 소리(말)를 녹화해요.
- **끝난 뒤 세 가지만 물어요**: 무엇을 하는 게임 같았나요 / 어디서 막혔나요 / 한 판 더 하고 싶나요.

## 판 기록
끝난 판마다 한 줄이 저장 폴더의 `saves/runlog.json`에 남아요(최근 200판). 이 기계에만 남고 어디로도 보내지 않아요.
- 줄 하나: 끝난 시각 `at`, 시드 `seed`, 출전 정령 `party`, 끝난 막 `act` · 층 `floor`, 전투 수 `fights`, 끝난 모양 `end`(`victory` · `defeat` · `abandon`), 그 판의 마지막 막 `lastAct`.
- 저장 폴더: 윈도 `%APPDATA%\demogame`, 맥 `~/Library/Application Support/demogame`, 리눅스 `~/.config/demogame`.
- 같은 판을 다시 보려면 개발 서버에서 `?demo&seed=<시드>`.
- 테스트가 끝나면 이 파일과 `logs/error.log`를 같이 받아 와요.

## 고리
1. 5~6명을 봐요.
2. 두 명 이상이 같은 곳에서 막힌 것만 고쳐요. 글을 더하는 대신 형태 · 모션으로 고쳐요(0019).
3. 새 사람으로 다시 봐요. 같은 사람은 두 번 쓰지 않아요.
