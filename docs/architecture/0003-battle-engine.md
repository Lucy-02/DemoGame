## 구조

`src/core/battle/` 한 폴더예요. 바깥에서는 `src/core/battle`(index)만 import해요.

| 파일 | 역할 | 새 기믹을 넣을 때 |
| --- | --- | --- |
| `state.ts` | 전투 상태 타입 (`BSpirit` · `BEnemy` · `BCard` · 상태 칸 · 이벤트) | 상태 이름을 `STATUS_IDS`에 더해요 |
| `engine.ts` | `Engine` 인터페이스: 표와 핸들러가 쓸 수 있는 규칙 원시 동작 | 원시 동작이 더 필요하면 여기 선언하고 `Battle`에 구현해요 |
| `effects.ts` | 카드 효과 표 `EFFECTS`: 효과마다 처리(`resolve`) · 놓는 즉시인지(`immediate`) · 소멸 여부 · 효과문(`describe`) | 효과 하나 = 항목 하나. `types.ts`의 `CardOp`에 꼴을 더하면 컴파일이 빠진 핸들러를 잡아요 |
| `statuses.ts` | 상태 표 `STATUSES`: 쌓이는 문구 · 턴을 세는지 · 지워지는 때 · 턴 끝 처리 · 맞은 뒤 반응 | 상태 하나 = 항목 하나. 턴 끝 순서는 표 순서예요 |
| `passives.ts` | 정령에 붙어 이벤트에 반응하는 것: 지속 효과 `AURAS` · 해방 `RELEASE` · 성격 `PERSONALITY_PASSIVES`. 훅 목록은 `Passive` | 훅이 더 필요하면 `Passive`에 더하고 부르는 자리를 하나 만들어요 |
| `pipelines.ts` | 우선순위 단계 목록: 능력치 · 아군 타격 피해 · 적 공격 피해 · 적 공격 대상 · 카드 시간 · 피해 받기 | 단계를 끼우거나 순서를 바꿀 때는 목록의 `order`만 고쳐요 |
| `enemy-actions.ts` | 적 행동 표 `ENEMY_ACTIONS`: 의도 표기 · 종류 · 처리 | 행동 하나 = 항목 하나 |
| `battle.ts` | `Battle`: 상태 · 턴 흐름(턴 시작 · 턴 끝 · 라운드 끝 단계 목록) · 시간축 · 카드 놓기와 재생 · 원시 동작 구현 | 턴 흐름에 끼어드는 처리는 단계 목록에 항목으로 |

효과문은 `src/core/text.ts`가 카드 대상 문맥을 만들고, 문장은 효과 핸들러의 `describe`가 내요. 문장 조각 규칙은 `src/core/clauses.ts`예요.

## 판정 순서 (지금 값, 2단계 기믹 포함)

- 카드 효과 배율(재생 시작 때 한 번): 품은 카드 × `hold_mult` → 받아칠 기회 × `ready_mult`(기회를 쓰는 카드만, 쓰면 1 줄어요). 카드의 주 수치(`main`)에만 곱해요.
- 아군 타격 피해: 기본값(+성장 · 배율) → 강화 → 타격 보너스(길조 · 별의 장막) → 지속 효과 보너스(흑요석 뿔 · 위장막) → 파워 → 상성 → 치명 → 취약 → 약화 → 해방 → 허점타(창, 아니면 휘청 1 소모) → 반올림 → 뒤처리(별빛이면 별 새기기)
- 적 공격 피해: 기본값 → 피해 보너스 → 약화 → 대상 취약 → 대상 숨음 × `hidden_mult` → 반올림
- 적 공격 대상: 전체 공격 → 숨음 → 도발 → 해방 도발 → 규칙(앞열 · 최저 · 무작위)
- 피해 받기: 벽(다른 아군의 벽 방어도가 먼저, 관통 제외) → 자기 방어도 → HP → (아군) 맞은 뒤 반응(반격; 벽이 대신 받았으면 벽 주인의 반격도)
- 카드 시간: 기본 시간 → 밀물(절반) → 품은 카드 −`hold_time_cut_ms` → 디딤 → 0 아래 금지 → 스피드
- 능력치: 런 기본값 → 정령에 붙은 것(용맹)
- 턴 시작: 머리 → 아군 턴 값 지우기(상태 turnStart 훅 · 유리 성채는 벽 절반 유지) → 적 방어도 · 혜성 낙하 · 취소된 행동 건너뛰기 → 시간축 → 마력 → 뽑기(+용궁) → 품은 카드 되돌리기 → 낙하 고르기 열기 → 첫 턴 훅 → 손패 훅 → 적이 건 비용 → 적이 건 봉인
- 턴 끝: 별 세기(문턱마다 낙하 1) → 아군 상태(표 순서) + 지속 효과 → 적 상태 → 품기 → 손 버리기
- 라운드 끝: 아군 상태 줄이기 · 기한 찬 상태 지우기 · 해방 끝 → 적 상태 줄이기

새 상태 · 효과 · 지속 효과는 각각 `STATUSES` · `EFFECTS` · `AURAS`에 항목 하나예요. 별 · 낙하 · 품기의 턴 단위 상태는 `Battle.stars` · `Battle.hold`에 있어요.

## 바꾸지 않은 것

- 이벤트 `BattleEvent`는 연출용 그대로예요(0001). 규칙 트리거는 `Passive` 훅과 상태 표로 하고, 연출 이벤트와 섞지 않아요. 2단계에서 연출용으로 더한 이벤트: `fallOffer` · `fall` · `hold` · `ready`, 피해 이벤트의 `wall`.
- 리팩터링 PR(#60)에서는 상수 · 데이터 · 효과문 · 골든 스냅샷이 그대로였어요. 2단계 PR은 시작 덱이 바뀌어 골든이 바뀌었어요(이유는 그 PR 본문).
