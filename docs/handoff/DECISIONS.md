# 지금까지 결정한 것 (2026-11-06 기준)

표시 규칙

- ✅ **Lucy 확정**: Lucy가 프로젝트 대화에서 직접 정했거나 컨펌한 것
- 📝 **Claude 초안 · 미검토**: Claude가 만들었고 Lucy가 아직 보지 않았거나 확정하지 않은 것. 바꿔도 되는 것으로 다뤄요
- 🧪 **가설**: 테스트로만 확인한 것. 근거가 약해요
- 🟡 **추천안 채택**: Lucy의 포괄 승인("쭉쭉 진행해")으로 Claude 추천안을 채택한 것. Lucy가 다른 안을 고르면 새 기록으로 대체해요

## 1. 게임 방향 ✅

| 항목 | 결정 |
| --- | --- |
| 장르 | 덱빌딩 로그라이트 + 정령 키우기. "키운 정령이 배운 마법이 곧 내 덱" |
| 플랫폼 | PC (스팀) |
| 기술 스택 | Phaser 4 + Vite + TypeScript, Spine(spine-phaser-v4) |
| 아트 파이프라인 | TTI(NovelAI Diffusion 5)로 SD 정령 원화 → 파츠 분리 → Spine 리깅. 체형별 리그에 스킨 교체 |
| 개발 조건 | 1인 개발. 이미지·UI는 Lucy 강점 |

## 2. 정령 정의 ✅

- **능력치**: HP / 파워 / 가드 / 포커스 + 스피드(시간 = 카드 기본 시간 ÷ 스피드, 0036). 같은 카드도 시전 정령의 능력치에 따라 수치가 달라짐
- **해방**: 각성체가 전투마다 한 번 켜는 2턴 일시 변신. 게임에서 연출에 힘을 주는 유일한 장면
- **속성**: 9속성 상성 고리 A(물 > 불 > 숲 > 땅 > 전기 > 얼음 > 물), 바람 중립, 빛 ↔ 그림자 (0028)
- **역할 4종**: 수호 / 공격 / 보조 / 교란. 체형과 독립, 이름표 배지로 표시
- **성격**: 능력치형 3 + 기믹형 5. 유체부터 보이고(0033) 효과는 성체부터, 다시 뽑기 없음(0034)
- **성장 단계**: 유체 → 성체 → 각성체 (MVP는 유체·성체만)

## 3. 전투 규칙 ✅

- **정령이 쓰러지면**: 기본 모드는 그 전투에서 기절 + 그 정령 카드 봉인, 전투 후 HP 1로 복귀. 도전 모드는 런 끝까지 이탈. 영구 사망 없음
- **치명타**: 타격마다 확률 판정(기본 5%, ×1.5), 안 터지면 확률이 쌓이는 보정
- **캐스팅 끊기**: 강공은 차징, 차징 중 브레이크(카드 효과, 대체로 무거움)로만 취소. 빙결은 취소가 아니라 늦추기(0039)
- **기본 카드 3칸**: 모든 정령은 기본 피해 / 기본 방어 / 기본 기술 3칸 틀을 공유
- **카드풀 해금**: 해금 카드는 덱에 바로 들어가지 않고 런 보상 후보에 나옴. 런은 항상 얇은 덱에서 시작
