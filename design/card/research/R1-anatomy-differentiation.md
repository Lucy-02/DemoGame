# R1. 카드 해부도와 구분 축 리서치

작성 2026-10-29 · 조사 범위: 덱빌더/카드 배틀러 16종 + 속성 체계 참고 1종(Cassette Beasts)
전제: `CONTEXT.md`의 확정 사항(5:7 그림 창 + 얇은 이름 띠, 왼쪽 아래 SD 초상 홈, 정령별 그림 창 윗선, 효과 기호+숫자판, 속성 = 재질 + 단색 기호, 못 내는 카드 표시 규칙 등)은 **바꾸지 않을 제약**으로 두고 읽었어요.
이 문서는 리서치예요. 시각 결정을 내리지 않고, 마지막 장의 "선택지"도 Lucy가 고를 후보일 뿐이에요. 색·크기 값은 하나도 제안하지 않아요.

---

## 요약

1. **업계 표준 해부도는 거의 고정돼 있어요.** 비용은 왼쪽 위(MTG만 오른쪽 위), 이름은 위쪽 띠, 그림은 위쪽 절반, 규칙 글은 아래쪽 절반, 전투 수치는 아래 모서리. 거의 모든 게임이 이 배치를 따르고, 차이는 "무엇을 어디에 덜 보여 주느냐"에서 나와요.
2. **카드 종류(타입)는 보통 "모양"으로 구분해요.** Slay the Spire(공격 = 아래가 뾰족한 틀, 스킬 = 직사각, 파워 = 타원)와 Hearthstone(하수인 = 타원 초상, 주문 = 다른 틀)이 대표적이에요. 모양은 색약과 무관하게 읽혀서 가장 안전한 채널이에요.
3. **진영·속성·색 정체성은 보통 "색 + 기호"를 함께 써요.** MTG는 마나 기호, LoR은 지역 아이콘을 따로 둬요. Riot은 지역별로 틀을 물들이는 안을 **색각 이상 문제 때문에 기각**하고 아이콘을 모서리로 옮겼어요.
4. **희귀도는 거의 모두 "작은 부품 하나의 색"으로 처리해요.** Hearthstone은 보석, MTG는 확장 기호, StS는 이름 띠와 틀 색을 써요. 색에만 기대는 경우가 많아 접근성 면에서는 약해요. 예외로 Pokémon TCG Pocket은 **기호 개수와 모양**(◆1~4, ★, 왕관)을 써서 색 없이도 읽혀요.
5. **여러 캐릭터 카드가 한 손패에 섞이는 게임(Cobalt Core)은 "캐릭터 = 색"으로 소유자를 구분해요.** Across the Obelisk는 영웅마다 차례를 따로 써서 손패가 섞이지 않아요. 우리 게임은 손패가 섞이는 쪽이라 Cobalt Core와 더 가깝고, 이미 SD 초상 홈 + 윗선 모양 + 묶음 배치로 "색 없이 소유자 표시"를 확정했어요. 이건 업계보다 앞선 지점이에요.
6. **특수 성질(소멸·보존·지속 등)은 대부분 "규칙 글 속 굵은 키워드"로만 표시해요.** 따로 시각 채널을 쓰는 건 StS의 파워(타원 틀)와 Hearthstone류의 "조건 충족 시 카드 테두리 빛남" 정도예요.
7. **우리 게임에서 남은 축은 역할 · 희귀도 · 성질 셋이에요.** 색(강조 낮게)과 윗선 모양(정령)은 이미 쓰이고 있어서, 남은 채널은 **위치 고정 작은 기호, 개수(점·눈금), 테·부품 모양, 상태 변화(움직임 최소)**예요.
8. **가장 큰 차별화 기회는 "카드가 정령의 성장을 보여 준다"는 점이에요.** LoR 챔피언의 레벨업 그림 변화, Griftlands의 사용 경험치 강화, Inscryption의 눈에 보이는 카드 개조가 각각 일부를 하지만, **카드 전체가 주인의 성장 단계를 반영하는 게임은 찾지 못했어요.** SD 초상 홈 하나만 바꿔도 비용을 적게 들여 그 효과를 낼 수 있어요.

## 1. 게임별 정리

### 1.1 Slay the Spire (1편) — 장르 표준

| 항목 | 내용 |
|---|---|
| 해부도 | 비용 구슬 왼쪽 위 · 이름 띠 위쪽 · 그림 가운데 위 · 타입 글자(공격/스킬/파워) 그림 아래 작은 꼬리표 · 규칙 글 아래 절반 [관찰] |
| 카드 종류 | **틀 모양**으로 구분: 공격 = 아래 가장자리가 뾰족한 직사각, 스킬 = 평범한 직사각, 파워 = 타원 틀 [출처: StS wiki "Card"] |
| 희귀도 | **이름 띠와 틀의 색**: 일반 회색, 비일반 파랑, 희귀 금색. 기본 카드는 일반과 같은 회색 [출처] |
| 캐릭터 | 카드 바탕색이 캐릭터별(빨강/초록/파랑/보라), 무색 카드는 회색 [관찰] |
| 특수 성질 | 소멸(Exhaust)·보존(Retain)·휘발(Ethereal)·선천성(Innate)은 **규칙 글 안 키워드**뿐, 따로 표시 없음 [관찰] |
| 강화 | 이름 뒤 "+" 표시 [출처], 강화로 바뀐 수치는 초록 글자 [관찰] |
| 수치 변화 | 힘·약화 등으로 바뀐 피해량은 카드 글 안 숫자가 **초록(증가)/빨강(감소)**으로 바뀜 [관찰] |
| 중복 인코딩 | 타입 = 모양 + 글자 꼬리표 (튼튼함). 희귀도 = 색만 (약함). 캐릭터 = 색만이지만, 한 판에 캐릭터가 하나라 문제없음 |

**우리에게 주는 교훈:** "판단에 쓰는 축(타입)은 모양으로, 수집에 쓰는 축(희귀도)은 색으로"라는 분업이 깔끔해요. 그리고 **변한 수치를 카드 글 안에서 바로 바꿔 보여 주는 방식**은 우리 "최종 수치 크게, 기본 N 작게"의 선례예요. 다만 StS는 기본값을 숨기고, 색 하나로만 증감을 알려요.

### 1.2 Slay the Spire 2

- 2026년 1월 뉴스레터에 따르면, 희귀 카드 보상에 **희귀도에 따른 반짝이는 효과**가 들어갔다가 "톤 다운"됐어요 [출처: Neowsletter #18]. 희귀도 연출을 과하게 넣었다가 줄인 사례라서, "휘황찬란 금지" 방침을 뒷받침해요.
- 카드 틀 체계 자체는 1편과 같은 모양 분업을 유지하는 것으로 보여요 [관찰, 미확인].

### 1.3 Monster Train (1/2)

| 항목 | 내용 |
|---|---|
| 카드 종류 | 주문·몬스터(유닛)·역병(Blight)·잡동사니(Junk)·장비·방 6종. 역병·잡동사니는 생김새가 따로 있음 [출처: Trainworks 모딩 위키] |
| 유닛 vs 주문 | 유닛 카드는 아래쪽에 공격/체력·크기(칸) 수치가 붙어서 **수치 부품이 있느냐 없느냐**로 바로 갈림 [출처+관찰] |
| 진영(클랜) | 클랜마다 틀 색과 장식 모티프가 다름 [관찰] |
| 희귀도 | 틀/보석 쪽 색 차이 [관찰, 미확인] |
| 특수 성질 | 소비(Consume)·보유(Holdover)·순간(Intrinsic) 등은 규칙 글 키워드 [관찰] |
| 강화 | 업그레이드 돌을 박으면 카드에 붙은 강화가 **카드 위에 쌓여 보임** [관찰] |

**교훈:** 유닛/주문처럼 "수치 부품의 유무"가 곧 타입 표시가 돼요. 우리는 효과 숫자판이 모든 카드에 있으니 이 방법은 쓸 수 없어요.

### 1.4 Wildfrost — 비교작

| 항목 | 내용 |
|---|---|
| 카드 종류 | 리더·동료(Companion)·아이템·클렁커(Clunker)·그림자(Shade). 동료는 체력·공격·카운터 기호가 카드 둘레에 붙고, 클렁커는 체력 대신 **고철(Scrap) 기호**를 씀 [출처: Wildfrost wiki "Clunkers"] |
| 수치 표시 | 수치를 글 안에 넣지 않고, **카드 가장자리에 붙은 기호 + 큰 숫자 배지**로 뺌 [관찰] |
| 특수 성질 | 부적(Charm)을 붙이면 카드 위에 부적 그림이 **눈에 보이게 붙음** [출처: Charms 페이지 + 관찰] |
| 중복 인코딩 | 체력/공격/카운터를 **기호 모양 + 위치**로 구분해서 색 없이도 읽힘 |

**교훈:** 우리 "효과 기호 + 숫자판"과 가장 가까운 선례예요. 수치 종류는 기호 모양으로, 크기는 숫자로 읽게 해요. 또 **카드에 무언가 붙거나 바뀐 걸 실물처럼 보이게 하는 방식**(부적)은 "덱이 자란다"를 보여 주는 좋은 참고예요.

### 1.5 Balatro (조커)

- 조커 카드는 희귀도를 **설명 말풍선 안의 희귀도 꼬리표(색 + 글자)**로만 알려요. 카드 그림 자체에는 희귀도를 넣지 않아요 [관찰].
- "판(版)"(포일·홀로그래픽·폴리크롬·네거티브)은 **카드 표면 재질/셰이더**로 표시하고, 이게 실제 효과(칩·배수 추가)를 가져요 [관찰].
- **교훈:** 희귀도를 카드 면에서 빼고 **호버 설명으로만** 보여 줘도 게임이 잘 돌아간다는 강한 선례예요. 우리 정보 원칙("익히는 정보는 호버")과 잘 맞아요. 반대로 재질에 기능 의미를 실으면 재질 채널이 "효과"를 나르게 되는데, 우리는 재질을 이미 속성에 쓰고 있으니 이 방식은 피하는 게 맞아요.

### 1.6 Inscryption

- 카드 오른쪽 위에 비용(피 방울/뼈 기호를 **개수**로), 아래 모서리에 공격/체력, 그림 아래에 **인장(Sigil) 기호**를 둬요 [관찰].
- 능력은 글이 아니라 **인장 기호**로만 표시하고, 뜻은 들여다볼 때 알려 줘요 [관찰].
- 카드를 개조하면 결과가 카드에 **눈에 보이게** 남아요. 제물로 바치면 인장이 옮겨 새겨지고, 모닥불 강화는 수치가 바뀌며, 죽음 카드는 비용·수치·인장을 서로 다른 세 카드에서 가져와 합쳐요 [출처: Deathcard 페이지].
- **교훈:** (1) 비용을 **개수**로 보여 주면 숫자를 읽지 않아도 돼요. (2) "이 카드는 내 손을 거치며 변했다"는 느낌이 수집 욕구를 크게 키워요. 우리 "성장 N"이나 정령 성장 반영에 바로 쓸 수 있는 정서예요.

### 1.7 Hearthstone

| 항목 | 내용 |
|---|---|
| 해부도 | 마나 비용 왼쪽 위, 그림·이름·규칙 글 판. 하수인은 공격 왼쪽 아래·체력 오른쪽 아래, 무기는 공격·내구도 [출처: HS wiki "Card"] |
| 카드 종류 | 하수인 = 타원 초상, 주문 = 다른 그림 틀, 무기·장소·영웅 각각 다른 틀 [관찰]. **모양**으로 구분 |
| 직업 | 틀 색과 장식이 직업별 [관찰] |
| 희귀도 | **가운데 작은 보석 색**: 일반 흰색, 희귀 파랑, 영웅 보라, 전설 주황. 기본(Free)은 보석 없음. 전설은 그림 위에 **용 장식**이 더해짐 [출처: HS wiki "Rarity"] |
| 조건부 효과 | 연계(Combo) 등 조건이 맞으면 손패 카드 테두리가 노랗게 빛남 [관찰] |
| 설계 근거 | GDC 2015 Derek Sakamoto, "우리 게임은 UI다" — 카드를 실물처럼 만지는 느낌을 강조 [출처: Game Developer 요약] |

**교훈:** 희귀도 보석은 **작고 한 군데에만** 있어서 판단 정보를 가리지 않아요. 전설만 실루엣(용)을 더하는 "최상위만 모양 추가" 방식은, 장식을 줄여야 하는 우리 쪽에선 쓰지 않는 편이 맞아요. **조건 충족 빛남**은 우리 "연속 N"에 직접 대응하는 선례예요.

### 1.8 Marvel Snap

- 비용(왼쪽 위)과 힘(오른쪽 위) 두 숫자만 크게 두고, 능력은 **짧은 한 문장**이에요 [출처: Game Developer, 실물 카드 프로토타입 기사].
- 희귀도 개념 대신 같은 카드의 **꾸밈 단계**(틀 없음 → 그림이 틀 밖으로 → 3D → 움직임 …)를 둬요. 꾸밈은 효과와 무관해요 [관찰].
- 시각 효과 팀의 목표는 "멋있게"가 아니라 **"카드가 무엇을 하는지 알려 주기"**라고 해요 [출처].
- **교훈:** 판단 숫자만 크게 두는 우리 원칙과 같은 방향이에요. 꾸밈 단계를 "수집 보상"으로 쓰는 방식은 휘황찬란 금지와 충돌하니 참고만 해요.

### 1.9 MTG Arena (Magic: The Gathering)

| 항목 | 내용 |
|---|---|
| 해부도 | 이름 왼쪽 위, **마나 비용 오른쪽 위**, 그림, 타입 줄, 확장 기호(타입 줄 오른쪽), 규칙 글, 공격력/방어력 오른쪽 아래 [출처: MTG wiki "Frame"] |
| 색 정체성 | 비용 안의 **마나 기호(모양 + 색)**가 카드 색을 결정. 색마다 **틀 배경 무늬**도 다름(백 = 대리석, 청 = 소용돌이, 흑 = 거품, 적 = 갈라진 돌, 녹 = 걸러진 빛). 다색은 금색, 무색은 회색 [출처] |
| 희귀도 | 확장 기호 색: 일반 검정, 비일반 은색, 희귀 금색, 신화 주황 [출처] |
| 가독성 사고 | 아티팩트 틀과 백색 틀이 한눈에 헷갈려서 아티팩트 틀을 어둡게 바꿈(Fifth Dawn) [출처] |
| 중복 인코딩 | 색 = 마나 기호 모양 + 틀 색 + 틀 무늬(재질) 3중. 희귀도 = 색만 |

**교훈:** MTG는 **색 + 무늬(재질) + 기호**를 겹쳐서 진영을 나르는데, 우리 "속성 = 재질 + 단색 기호"가 정확히 이 구조예요. 그리고 **흰 틀 ≈ 무색 틀 혼동 사고**는 우리 리뷰에서 나온 "바람 ≈ 무속성" 지적과 같은 종류예요. MTG의 해법은 한쪽의 명도를 확실히 떼는 것이었어요(구체 값은 우리가 정하지 않음).

### 1.10 Legends of Runeterra

- 지역(진영) 아이콘을 원래 규칙 글 배경 워터마크로 뒀다가 **오른쪽 위 모서리로 옮겼어요**(2.2 패치) [출처: Out of Games].
- 근거: 긴 글과 다국어(일본어·독일어)용 공간 확보, 글 위 상호작용 키워드와 아이콘 겹침 문제 [출처].
- **지역별로 틀을 물들이는 안은 기각**: 틀 색은 이미 "추종자 vs 챔피언"을 나르고 있고, 지역 색은 **색각 이상 플레이어에게 어려울 수 있어서** [출처].
- 챔피언은 조건을 채우면 **레벨업하며 그림·수치·때로 이름이 바뀌어요** [출처: cardsrealm, dotesports].
- **교훈:** (1) 한 채널(틀 색)에 두 축을 싣지 않는다. (2) 진영은 고정 위치 아이콘. (3) "카드가 성장해서 겉모습이 바뀐다"는 LoR 챔피언이 가장 가까운 선례지만, **챔피언 카드에만** 해당해요.

### 1.11 Griftlands

- 전투 덱과 협상 덱 두 개를 따로 운영해요 [출처: Wikipedia].
- 카드마다 **사용 경험치**가 있어서, 쓰다 보면 강화할 수 있어요 [출처: Gamer Journalist]. 다만 그 진행 정도가 카드 면에 어떻게 보이는지는 확인하지 못했어요.
- 협상 카드는 외교/적대/평정 같은 성향 분류가 있어요 [출처].
- **교훈:** "쓸수록 자란다"는 우리 "성장 N"과 같은 계열이에요. Griftlands는 진행 정도를 크게 보여 주지 않는 편이라, 우리 ▲ 성장 표시가 이 부분을 더 잘할 여지가 있어요.

### 1.12 Across the Obelisk — 다중 캐릭터 파티

- 영웅 4명이 각자 **자기 덱과 자기 차례**(속도 순)를 가져요 [출처: Gamesfuze 가이드]. 그래서 **한 손패에 여러 영웅 카드가 섞이지 않아요.**
- 카드는 직업군(전사/정찰/마법/치유)별로 나뉘고, 직업별 틀 색이 다르며, 강화 카드는 두 갈래(A/B)와 타락(Corrupted) 버전이 따로 있어서 틀 색으로 구분돼요 [관찰, 위키 접속 실패로 미확인].
- 설명 툴팁을 설정에서 확장할 수 있어요 [출처].
- **교훈:** 소유자 구분 문제를 **차례 분리**로 해결했어요. 우리는 손패가 섞이는 구조라 이 방법은 쓸 수 없지만, "강화 갈래를 틀 색으로" 같은 방식은 우리 색 강조 원칙과 충돌하니 피해야 해요.

### 1.13 Cobalt Core — 다중 캐릭터 파티 (가장 가까운 선례)

- 승무원 3명을 고르고, 각자 고유 카드를 가져요 [출처: PC Gamer].
- **승무원마다 색이 하나씩 있어서, 카드와 유물이 누구 것인지 한눈에 구분돼요** [출처: TV Tropes]. 카드 틀/바탕 색이 승무원 색이에요 [관찰].
- CAT의 고유 공격은 **손패에 있는 카드 색 수**에 따라 강해져요 [출처: TV Tropes]. 소유자 색이 단순 표시를 넘어 **규칙의 일부**가 된 사례예요.
- 적 Wizbo는 파티원을 **일시적으로 사라지게** 하는데, 이때 그 승무원 카드를 쓸 수 없게 되는 것으로 알려져 있어요 [출처는 "사라짐"까지, 카드 사용 불가 표시는 관찰]. 우리 "정령 쓰러짐 → 봉인"과 같은 구조예요.
- 소멸·임시·재사용 같은 성질은 카드 아래쪽 작은 **성질 아이콘**으로 보여 주는 것으로 알고 있어요 [관찰, 미확인].
- **교훈:** 다중 소유자 손패의 업계 해법은 "소유자 = 색"이에요. 우리는 "속성·정령 색 강조 낮게"로 정했으니, Cobalt Core의 색 역할을 **SD 초상 + 윗선 모양 + 묶음 배치**가 대신하고 있어요. 색에 덜 기대는 만큼 색약 친화적이고, 이건 차별점이에요.

### 1.14 Cassette Beasts (카드 아님, 속성 체계 참고)

- 14개 타입이 있고, 상성은 피해 배율이 아니라 **"화학 반응"**(버프/디버프/타입 변환)이에요 [출처: Chemistry 블로그].
- 대상 선택 시 결과를 **아이콘으로 미리 보여 주고**, 대상 아래 고리를 빨강(디버프)/초록(버프)/노랑(변환)으로 빛내요 [출처].
- 설계 근거: "칸 색만 외워도 쓸 수 있고, 세부 효과를 익히면 더 깊어진다" — 익힘의 두 단계 [출처].
- **교훈:** 우리 "조준 시 필드 결과 미리보기"와 같은 방향이에요. 상성 결과를 카드가 아니라 **대상 쪽**에 보여 주면 카드 면을 비워 둘 수 있어요.

### 1.15 Pokémon TCG Pocket

- 희귀도 기호가 **왼쪽 아래 모서리**에 있어요. ◆ 1~4개(일반~더블 레어), ★ 1~3개, 특수 별, 왕관 [출처: Bulbapedia].
- 높은 희귀도로 갈수록 **그림이 틀을 넘거나 전면 그림**이 되고, 최상위는 움직이는 그림이에요 [출처].
- 3◆ 레어는 테두리가 반짝이는 정도로만 다르다 [출처].
- **교훈:** **희귀도 = 기호 개수**는 색 없이 읽히고, 작은 자리 하나면 돼요. 우리 희귀도 4단계(기본/일반/고급/희귀)를 이렇게 나르는 선택지가 있어요. 단, 왼쪽 아래는 우리 SD 초상 홈 자리라 그대로 가져올 수는 없어요.

### 1.16 Shadowverse

- 추종자/주문/아뮬렛을 틀 모양으로 나누고, 희귀도는 브론즈/실버/골드/레전드 **틀 재질·색**으로 나눠요 [관찰].
- 추종자는 **진화하면 그림이 바뀌어요**(진화 전/후 그림 두 장) [관찰].
- **교훈:** 희귀도에 재질을 쓰는 방식은 우리 "재질 = 속성"과 바로 충돌해요. 진화 그림은 LoR과 같은 "성장 → 겉모습 변화" 계열이에요.

### 1.17 Dicey Dungeons

- 장비 카드의 **색이 효과 종류**를 나타내요(팬 모드 페이지 기준: 빨강 = 화상, 파랑 = 빙결, 초록 = 회복 등) [출처: itch.io 모드].
- 원작은 색에 많이 기대서, 팬이 **모서리에 작은 기호를 더하는 색약용 모드**를 만들었어요 [출처].
- **교훈:** 색 하나로 축을 나르면 결국 기호를 덧붙여야 해요. 처음부터 기호 + 고정 위치로 가는 게 싸요.

### 1.18 Ring of Pain (참고)

- 카드가 원형 고리로 늘어서고, 카드 면은 그림 + 큰 수치 몇 개로 단순해요. 성질은 **아이콘**으로만 보여 주고 뜻은 들여다볼 때 알려 줘요 [관찰].
- **교훈:** 어두운 화면에서 그림 + 숫자만 띄우는 절제된 해부도의 예예요. 우리 "무채 유리 + 한 가지 강조" 톤과 분위기가 가까워요.

## 2. 업계 표준 해부도와 경험칙

### 2.1 거의 모두가 하는 배치

| 부위 | 일반적 위치 | 예외 |
|---|---|---|
| 비용 | 왼쪽 위 원/보석 | MTG 오른쪽 위, Inscryption 오른쪽 위 개수 |
| 이름 | 위쪽 가로 띠(그림 위나 아래) | Marvel Snap은 이름이 거의 안 보임 |
| 그림 | 위쪽 절반, 가장 큰 면적 | 고희귀도에서 전면 그림(PTCG Pocket, Snap) |
| 종류 | 그림 아래 작은 꼬리표 + 틀 모양 | Balatro·Snap은 종류 표시 없음 |
| 규칙 글 | 아래쪽 절반 | Inscryption·Ring of Pain은 기호만 |
| 전투 수치 | 아래 두 모서리(왼쪽 공격, 오른쪽 체력) | Snap은 오른쪽 위 힘 |
| 희귀도 | 가운데 작은 보석/기호, 또는 이름 띠 색 | Balatro는 호버에서만 |
| 진영/색 | 틀 전체 색 + 고정 위치 아이콘 | LoR은 아이콘만 |

### 2.2 경험칙

1. **판단 정보는 크고 모서리에, 익히는 정보는 작고 안쪽에.** 비용·수치는 손패에 겹쳐도 보이도록 모서리에 둬요. 우리 정보 원칙과 같아요.
2. **카드 종류는 모양으로.** StS·Hearthstone·Shadowverse 모두 틀 실루엣을 바꿔요. 손패가 부채꼴로 겹쳐도 윗부분 모양만으로 읽히게요.
3. **한 채널에 한 축.** LoR이 지역 색 틀을 기각한 이유가 "틀 색이 이미 다른 축을 나른다"였어요.
4. **색은 늘 짝꿍이 필요해요.** 진영 색에는 기호(MTG 마나, LoR 아이콘), 희귀도 색에는 기호나 개수(PTCG Pocket)가 붙는 게 좋아요. 색만 쓴 곳(StS 희귀도, Dicey 장비)은 약점으로 남거나 모드로 메워졌어요.
5. **특수 성질은 글 키워드가 기본이에요.** 시각 채널을 따로 주는 건 "규칙이 그 성질을 참조할 때"(StS 파워 = 타원)나 "지금 판단에 필요한 상태일 때"(조건 충족 빛남)뿐이에요.
6. **희귀도 연출은 줄이는 쪽으로 가요.** StS2도 희귀도 반짝임을 줄였어요. 희귀도는 보상 화면에선 중요하지만 전투에선 거의 쓸모없어요.
7. **변한 수치는 카드 위에서 바로 바뀌어요.** StS·Monster Train 모두 버프된 최종 값을 카드에 그대로 써요. 증감은 대개 색(초록/빨강) 하나로만 알려요.
8. **다국어 공간을 미리 남겨요.** LoR의 아이콘 이동 근거 중 하나였어요. 우리 한국어/영어 병행 시 이름 띠 길이에 영향이 있어요.

## 4. 이 프로젝트에 주는 교훈

### 4.1 지금 채널이 어떻게 차 있나 (확정 사항 기준)

| 축 | 이미 확정된 채널 | 남은 상태 |
|---|---|---|
| 속성(5) | 재질(이름 띠, 호버 시 전체) + 단색 기호(손패, 고정 위치 지적 있음) | 충분. 색 강조는 낮게 |
| 주인 정령 | SD 초상 홈(위치·그림) + 그림 창 윗선 모양 + 손패 묶음 배치 | 충분. **3중 인코딩, 색 불필요** |
| 판단 수치 | 효과 기호 + 숫자판(최종 크게, 기본 작게) | 확정 |
| 사용 불가 | 몸체 가라앉힘(정령 얼굴은 컬러) + 비용 동전 테(마력) + 글 띠(기타) | 확정 |
| 성장 N | 손패 ▲ 표시 + 호버 계산 줄 | 확정 |
| 역할(공격/수호/보조/교란) | 없음 | **미정** |
| 희귀도(기본/일반/고급/희귀) | 없음 | **미정** |
| 지속/소멸/보존 | 없음 | **미정** |
| 연속 N(조건부) | 없음 | **미정** |

**이미 쓰인 채널:** 재질(속성), 윗선 모양(정령), 왼쪽 아래 자리(정령), 몸체 명도(사용 가능 여부), 비용 동전 테(마력).
**비어 있는 채널:** 카드 바깥 실루엣의 아래쪽/옆쪽, 비용 동전의 모양, 이름 띠의 끝 모양, 작은 기호 자리(속성 기호 외), 개수(점·눈금), 움직임(각성 외엔 절제).

### 4.2 충돌 경고

1. **희귀도에 재질을 쓰면 안 돼요.** 재질은 속성 전용이에요. Shadowverse·Balatro식(금속/포일 틀)은 바로 충돌해요.
2. **희귀도·역할에 색을 쓰면 정보 원칙과 부딪혀요.** "속성·정령 색 강조 낮게"인데, 색 채널에 축을 하나 더 실으면 강조 색이 늘어나요. "무채 유리 + 한 가지 강조" 팔레트에서 그 "한 가지"가 무엇인지가 흐려져요.
3. **그림 창 윗선 모양은 정령 전용이에요.** StS처럼 "틀 모양 = 종류/성질"을 하려면 **윗선이 아닌 다른 부위**(아래 가장자리, 비용 동전, 이름 띠 끝)를 써야 해요. 같은 윗선에 두 의미를 섞으면 Riot이 피한 바로 그 문제예요.
4. **왼쪽 아래는 SD 초상 홈 자리예요.** PTCG Pocket의 희귀도 위치를 그대로 가져오지 않아요.
5. **"효과 설명 상시 노출"은 기각됐어요.** 성질 키워드를 StS처럼 글로만 두면 손패에서 안 보여요. 손패에서 꼭 보여야 하는 성질만 골라 기호로 빼야 해요.

### 4.3 축별 판단: 손패에서 보여야 하나?

우리 정보 원칙(판단 정보만 상시)으로 각 축을 걸러 봤어요.

| 축 | 전투 중 판단에 쓰나? | 손패 상시 표시 필요 | 근거 |
|---|---|---|---|
| 역할 | 부분적. 효과 기호(검/방패 등)가 이미 역할을 대부분 알려 줌 | **낮음** — 효과 기호와 겹칠 가능성 | 규칙이 역할을 참조하는지 확인 필요(아래 열린 질문) |
| 희귀도 | 거의 안 씀 | **없음** — 보상/상점/도감에서만 | Balatro는 호버에서만, StS2는 연출을 줄임 |
| 지속 | 씀 (내면 사라지고 전투 내내 효과) | 중간 | StS는 파워에 틀 모양을 따로 줌 |
| 소멸 | 씀 (덱 순환 계산) | 중간 | StS는 글 키워드만 — 그래도 플레이 가능 |
| 보존 | 씀 (턴 끝 손패 유지) | 낮음~중간 | 턴 끝에만 의미 |
| 성장 N | 씀 | 확정됨(▲) | — |
| 연속 N | 씀 — **"지금 충족됐나"**가 판단 정보 | 충족 상태만 높음 | Hearthstone 조건 충족 빛남 |

### 4.4 채널 배분 선택지 (Lucy가 고를 후보, 값은 모두 TODO_TOKEN)

아래는 축이 서로 부딪히지 않게 나누는 **세 가지 방향**이에요. 어느 쪽도 확정이 아니에요.

**선택지 A — "최소 표시" (Balatro·Ring of Pain 쪽)**
- 역할: 손패 표시 없음. 효과 기호가 대신하고, 호버 말풍선에 역할 이름.
- 희귀도: 전투 손패 표시 없음. 보상/상점/도감 화면에서만 **개수 기호**(PTCG식 점 개수)로 표시.
- 지속/소멸/보존: 호버 말풍선의 키워드만. 단, 소멸·지속은 카드를 낸 뒤 연출(사라짐/필드에 남음)로 배우게 함.
- 연속 N: 충족 시에만 숫자판 쪽에 작은 상태 표시(조건 충족 기호 + 수치 변화).
- 근거: 판단 정보만 남기는 원칙에 가장 충실해요. 카드 면이 가장 조용해요.
- 위험: 처음 하는 플레이어가 소멸 카드를 모르고 낼 수 있어요. StS도 같은 위험을 감수하고 있어요.

**선택지 B — "성질만 모양으로" (StS 쪽)**
- 지속: 카드 **아래 가장자리나 비용 동전의 모양**을 바꿔서 표시(윗선은 정령 전용이라 건드리지 않음).
- 소멸/보존: 이름 띠 끝이나 숫자판 옆 **고정 위치의 작은 단색 기호**.
- 역할: 표시 없음(A와 같음).
- 희귀도: 손패에선 이름 띠 안 아주 작은 **개수 표시**, 보상 화면에선 크게.
- 근거: 덱 순환에 영향을 주는 성질을 모양으로 빼는 건 업계 검증된 방식이에요. 색을 하나도 더 쓰지 않아요.
- 위험: 카드 부품이 하나 더 늘어나요. 윗선 모양과 아래 모양이 둘 다 바뀌면 실루엣이 복잡해질 수 있어요.

**선택지 C — "역할을 숫자판에 녹이기"**
- 역할: 효과 숫자판의 **판 모양**(예: 공격 = 뾰족, 수호 = 둥근 방패꼴 등 형태 계열만, 실제 모양은 시안에서)으로 표시. 숫자판은 이미 상시 보이는 판단 부품이라 따로 자리를 늘리지 않아요.
- 성질: B와 같이 작은 기호.
- 희귀도: A와 같이 보상 화면 전용.
- 근거: 역할이 규칙상 중요하거나(예: "수호 카드를 쓰면…" 같은 효과가 생길 때) 덱 구성 판단에 쓰인다면, 가장 자주 보는 부품에 싣는 게 효율적이에요.
- 위험: 효과 기호와 숫자판 모양이 같은 정보를 두 번 말할 수 있어요(효과 기호가 이미 검/방패라면 중복).

**공통 권고 (선택지와 무관):**
- 희귀도에 **재질·색·반짝임을 쓰지 않는다**(재질 = 속성, 색 강조 낮게, 반짝임 보류).
- 새로 붙이는 기호는 모두 **단색 + 고정 위치**(속성 기호와 같은 규칙), 손패가 겹쳐도 보이는 쪽.
- 컨트롤러 포커스 = 호버 상태라서, 호버에 맡기는 정보는 컨트롤러에서도 똑같이 보여요. A안의 부담이 PC 전용 게임보다 작아요.

### 4.5 차별화 기회 — "정령을 키우면, 덱이 자란다"

조사한 게임 중 **카드가 주인 캐릭터의 성장을 겉모습으로 보여 주는 경우는 없었어요.** 가까운 사례는 이 정도예요.

| 사례 | 무엇을 하나 | 한계 |
|---|---|---|
| LoR 챔피언 레벨업 | 조건 충족 시 그림·수치·이름 변경 | 챔피언 카드에만, 그 카드 자체의 성장 |
| Shadowverse 진화 | 필드에서 진화하면 그림 교체 | 전투 중 일시적 |
| Griftlands 카드 경험치 | 쓸수록 강화 가능 | 진행 정도가 잘 안 보임 |
| Inscryption 개조 | 인장·수치·조합이 카드에 남음 | 카드 단위, 주인 개념 없음 |
| Wildfrost 부적 | 붙인 부적이 카드 위에 보임 | 아이템 장착 |
| StS 수치 색 | 버프된 최종 값을 초록/빨강으로 | 색만 쓰고 원인(누가?)은 안 보임 |

여기서 우리만 할 수 있는 것들이에요(모두 아이디어 단계, 시안 전 Lucy 컨펌 필요).

1. **SD 초상 홈이 성장 단계를 따라 바뀌기.** 정령이 유체 → 성체 → 각성체로 자라면, 그 정령의 모든 카드의 초상 홈 그림이 바뀌어요. 카드 일러스트는 그대로라서 그림 작업량이 정령 수 × 단계 수로 끝나요(카드 수와 무관). "같은 카드가 키운 정령 따라 달라 보인다"를 가장 싸게 보여 주는 방법이에요. LoR 레벨업의 "겉모습 변화"를 **카드 전체가 아니라 주인 표시 부품 하나**로 줄인 형태라 휘황찬란 금지와도 맞아요.
2. **"기본 N → 최종 수치"의 원인을 보여 주기.** StS는 최종 값만, 색으로만 알려요. 우리는 기본값을 작게 함께 써서 "정령 능력치가 이만큼 키웠다"를 숫자로 읽게 해요. 호버 계산 줄에서 **SD 초상(원인)과 수치(결과)를 같은 줄에** 놓으면 브랜드 훅이 화면 문법이 돼요. 색 대신 숫자 두 개로 말하니 색약에도 안전해요.
3. **덱 보기/보상 화면에서 "정령별 성장 전후" 비교.** 보상 카드를 고를 때 "지금 이 정령이 쓰면 N"을 바로 보여 주는 건 StS·Monster Train도 하지 않아요(보상 화면은 기본값). 판단에 바로 쓰이는 정보라 정보 원칙과도 맞아요.
4. **각성 = 유일한 연출 순간에 카드도 참여.** 각성 2턴 동안 그 정령 카드의 초상 홈만 각성체로 바뀌는 정도로, 연출을 각성 장면 하나에 모으는 톤 방침을 지키면서 손패에도 흔적을 남겨요.
5. **싱크로율 기여를 손패에서 보이기.** Cobalt Core의 CAT처럼 "소유자"가 규칙에 들어간 사례는 있지만, **카드 한 장이 주인 게이지에 얼마나 보태는지**를 보여 주는 게임은 못 봤어요. 묶음 배치 위나 초상 홈 근처에 작게 두는 방향이 가능해요.
6. **봉인 상태의 서사화.** Cobalt Core의 "파티원 사라짐 → 카드 사용 불가"와 같은 구조인데, 우리는 이미 "몸체는 가라앉고 정령 얼굴은 컬러"로 정했어요. 쓰러진 정령은 얼굴이 어떻게 되는지(봉인 사유 표시와의 관계)는 아직 열려 있어요.

### 4.6 우리 구조가 이미 업계보다 나은 점

- **소유자 3중 인코딩(초상·윗선·묶음)에 색이 없음** — Cobalt Core는 색에 기대요. LoR이 색약 때문에 피한 함정을 처음부터 피했어요.
- **속성 = 재질 + 기호** — MTG의 "색 + 무늬 + 마나 기호" 구조와 같은데, 색 강조를 낮춘 만큼 재질이 주 채널이에요. 다만 MTG가 겪은 "흰색 ≈ 무색" 문제가 우리 "바람 ≈ 무속성"으로 이미 나타났으니, 기호 고정 위치 외에 재질 쪽 대비도 리뷰가 필요해요.
- **사용 불가 사유를 부위별로 나눔(동전 테 = 마력, 글 띠 = 기타)** — 조사한 게임 대부분은 "회색 처리" 하나로 끝내요.

## 5. 열린 질문 (리서치로 답할 수 없는 것)

1. **역할(공격/수호/보조/교란)을 참조하는 규칙이 있나요?** 있으면 손패 표시가 필요하고(StS 타입처럼), 없으면 호버로 충분할 가능성이 커요.
2. **희귀도가 전투 중 의미를 갖나요?** (예: 희귀 카드만 성장 N이 붙는다 등) 없으면 보상/상점 화면 전용으로 둘 수 있어요.
3. **지속 카드가 필드 어디에 남나요?** StS 파워는 캐릭터 머리 위 아이콘으로 남아요. 우리는 그 정령 근처에 남는지에 따라 손패 표시 필요도가 달라져요.
4. **성장 단계별 SD 초상(4.5-1)을 만들 여력이 있나요?** 정령 수 × 단계 수만큼 초상이 필요해요. Spine 리그 스킨 교체로 뽑을 수 있는지 확인이 필요해요.
5. **[관찰]로 표시한 항목**(Across the Obelisk 틀 색, Cobalt Core 성질 아이콘, Monster Train 희귀도 표시)은 시안 근거로 쓰기 전에 스크린샷 확인이 필요해요.
