# 카드 디자인 스레드 — 프로젝트 배경 요약 (2026-10-29)

이 스레드의 모든 작업은 이 파일에서 시작해요. 정본은 `/mnt/project-files/design-concepts/LEDGER.md`이고, 여기는 카드에 관련된 것만 모은 요약이에요.

## 게임
- 정령 키우기 + 덱빌딩 로그라이트. PC(스팀), 1280×800 기준, Steam Deck·컨트롤러 고려. 1인 개발(Lucy). 이미지·UI가 강점, 액션·이펙트·애니메이션은 새로 배우는 중.
- 기술: Phaser 4 + Vite + TypeScript, Spine(spine-phaser-v4). 정령은 체형별 Spine 리그 + 스킨 교체. 원화는 NovelAI Diffusion 5.
- 브랜드 훅(확정): "정령을 키우면, 덱이 자란다". 같은 카드도 시전 정령의 능력치에 따라 수치가 달라짐 (최종값 = 기본값 × 능력치/10).
- 톤: 유체·성체 귀엽고 아늑, 각성체 우아·장엄. **휘황찬란하고 과한 장식 금지.** 다크 팔레트("무채 유리 + 한 가지 강조"), 글꼴 Orbit 단일.
- 비교작: Cassette Beasts, Wildfrost, Slay the Spire.
- 연출에 힘을 주는 유일한 장면 = 각성(싱크로율 100%). 나머지는 절제.

## 카드 데이터 구조 (MVP 40장, 수치는 가안)
- **카드 타입(공격/스킬/파워 같은)은 기획상 두지 않음.** 대신 카드마다: 속성(불/물/숲/바람/무), 역할(공격/수호/보조/교란), 희귀도(기본/일반/고급/희귀), 비용(0~3), 대상(적 1/적 전체/자신/아군 1/아군 전체), 주인 정령.
- 특수 성질 키워드: 지속(사용 시 전투 내내 효과, 카드 소멸 = 파워 카드 비슷), 소멸, 보존, 성장 N(쓸수록 수치 증가), 연속 N(이번 턴 앞서 N장 썼으면 추가 효과), 드로우, 화상/점화, 냉기/빙결, 반격, 재생, 취약/약화, 강화, 도발, 앞열.
- 상성 물>불>숲>물, 바람·무 중립. 약점 타격마다 적 실드 1칸 감소 → 0이면 브레이크(행동 취소). 차징 중인 적 강공을 브레이크/빙결로 끊기 가능.
- 싱크로율: 한 정령 카드를 쓸수록 차고 100%면 2턴 각성.
- 성격(기믹형): 고집(한 턴 두 번째 카드 복사), 장난(무작위 1장 비용 -1), 용맹(HP 절반 이하 파워 +30%), 명랑.
- 정령이 쓰러지면 그 정령 카드는 봉인(사용 불가).
- 손패 최대 10장, 턴당 마력 3.

## 이미 확정된 카드 시각 결정 (Lucy) — 바꾸지 않음
- 카드 구조: 그림 창 + 얇은 이름 띠, 비율 5:7, 왼쪽 아래 SD 초상 홈(주인 정령), 정령별 그림 창 윗선 모양, 효과 기호+숫자판(최종 수치 크게, "기본 N" 작게), 손패에는 단색 속성 기호.
- 일러스트 필수 (그림 창).
- 재질: 손패에서는 이름 띠에만, 호버 시 카드 전체로. 불=밝은 용암석, 물=유약, 숲=한지+잎맥, 바람=비단, 무속성=무지. 반짝임(shimmer)은 보류("효과는 나중에").
- 기각: 반짝임·등급 시안의 나머지, 정령 테마 시안 나머지, 구운 흙 반점, 카드 하단 바 큼, 효과 설명 상시 노출(→ 호버).
- 정보 원칙(전투): 익히는 정보(효과 설명, 속성, 주인, 아이콘 뜻)는 기호·호버, 판단 정보(최종 수치, 비용 증감, 사용 불가 사유, 마력)만 항상 눈에 띄게. 속성·정령 색 강조는 낮게.
- 전투 R5(정본): 손패는 주인 정령별 묶음. 호버 = 살짝 키우고 옆 카드 밀림 + 카드 위 짧은 설명 말풍선(H1), 필드는 어둡게 하지 않음. 카드를 집어 조준하면 필드에 결과 미리보기(조준 대상 결과 + 아군 받을 피해 a→b만). 손패 ▲ 성장 표시 + 호버 계산 줄. **못 내는 카드는 몸체만 가라앉히고 정령 얼굴은 컬러. 마력 부족 = 비용 동전 테, 다른 사유 = 글 띠**("싱크 50 필요" 같은).
- 재질 리뷰 지적: 손패에서 바람≈무속성 구분 약함 → 속성 기호 고정 위치. 텍스트 영역엔 결 없이. 컨트롤러 포커스 = 호버와 같은 확대 상태.
