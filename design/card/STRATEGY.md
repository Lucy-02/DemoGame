## 0. 전략 한 줄

**카드는 조용히, 정령은 또렷하게, 크게 움직이는 건 각성 한 번.**

- 업계는 카드 한 장에 정보를 많이 싣고 색과 빛으로 구분해요. 우리는 이미 "익히는 정보는 기호·호버, 판단 정보만 상시"로 정했고, 주인 정령을 색 없이 세 겹(초상 홈·윗선·묶음)으로 표시해요. 이건 조사한 16종 중 누구도 안 한 방식이에요(Cobalt Core는 색에 기대고, LoR은 색약 문제로 지역 색 틀을 포기했어요).
- 그래서 차별화는 "카드를 더 화려하게"가 아니라 **"카드가 주인 정령의 성장을 비춘다"**에서 나와요. 브랜드 훅 "정령을 키우면, 덱이 자란다"를 카드 문법으로 옮기는 게 이 전략의 중심이에요.

## 1. 차별화 축: 카드가 정령을 비춘다

조사한 게임 중 **카드가 주인의 성장을 겉모습으로 보여 주는 게임은 없었어요**(LoR 챔피언 레벨업·Shadowverse 진화는 카드 자신의 변화). 우리만 할 수 있는 것 다섯 가지예요.

| # | 무엇 | 비용 | 판단 |
|---|---|---|---|
| D1 | **SD 초상 홈이 성장 단계를 따라 바뀜** (유체 → 성체 → 각성체). 카드 일러스트는 그대로 | 정령 수 × 단계 수 (카드 수와 무관) | 추천. 가장 싸고 훅을 바로 보여 줌 |
| D2 | **원인 → 결과 수치**: 숫자판에 최종값 크게 + "기본 N" 작게(확정), 호버 계산 줄에 정령 초상(원인)과 능력치(결과)를 같은 줄에 | 추가 그림 없음 | 추천. 확정 구조의 연장 |
| D3 | **보상·덱 보기에서 "이 정령이 배우면 N"** 을 바로 보여 줌. StS·Monster Train은 보상에 기본값만 보여 줌 | 화면 스레드와 조율 | 추천 (덱 보기 시안에 전달) |
| D4 | **각성 2턴 동안 그 정령 카드의 초상 홈만 각성체로**. 카드 몸체는 그대로 | D1에 포함 | 추천. 연출을 각성 하나에 모으는 톤 유지 |
| D5 | **싱크로율 기여를 손패에서 보이기**: 카드를 집으면 주인 정령의 싱크 게이지에 "+N" 미리보기 | 필드 미리보기 예산(R5)과 충돌 가능 | 보류. R5 미리보기 예산을 늘리는 일이라 Lucy 판단 |

## 2. 구분 체계: 축마다 채널 하나

### 2-1. 이미 정해진 채널 (바꾸지 않음)

| 축 | 채널 |
|---|---|
| 속성 (불·물·숲·바람·무) | 재질(손패는 이름 띠, 호버는 전체) + 단색 기호(오른쪽 위 고정) |
| 주인 정령 | SD 초상 홈(왼쪽 아래) + 그림 창 윗선 모양 + 손패 묶음 |
| 판단 수치 | 효과 기호 + 숫자판 (최종 크게, 기본 작게), ▲ 성장 |
| 사용 불가 | 몸체 가라앉힘 + 비용 동전 테(마력) + 글 띠(다른 사유) |

### 2-2. 비어 있는 축: 역할 · 희귀도 · 성질(지속·소멸·보존)

공통 규칙 (어느 안이든)
- 희귀도에 **재질·색·반짝임을 쓰지 않아요.** 재질은 속성 것이고, 색 강조는 낮게, 반짝임은 보류예요.
- 그림 창 **윗선은 정령 것**이라 다른 축을 싣지 않아요. 왼쪽 아래는 초상 홈 자리예요.
- 새 기호는 **단색 + 고정 위치**. 남은 자리는 아래 가장자리, 비용 동전 모양, 이름 띠 끝, 숫자판 모양, 개수(점)예요.

| | A. 최소 표시 | B. 성질은 모양으로 | C. 역할은 숫자판 모양으로 |
|---|---|---|---|
| 역할 | 손패 표시 없음 (효과 기호가 대신, 호버에 이름) | A와 같음 | 숫자판의 판 모양 4종 |
| 희귀도 | 손패 없음. 보상·상점·덱 보기에서만 **점 개수** | 이름 띠 끝 아주 작은 점 개수 | A와 같음 |
| 지속 | 호버 키워드만 + 낸 뒤 연출(정령 곁에 남음) | **카드 아래 가장자리 모양**이 다름 | B와 같음 |
| 소멸·보존 | 호버 키워드만 | 숫자판 옆 고정 자리 작은 기호 | B와 같음 |
| 좋은 점 | 카드 면이 가장 조용함. 정보 원칙에 가장 충실 | 덱 순환에 영향 주는 성질이 손패에서 보임 (StS 파워 선례) | 역할이 규칙에 쓰이면 가장 효율적 |
| 위험 | 처음 하는 사람이 소멸 카드를 모르고 냄 | 부품 하나 늘어남. 실루엣이 위아래 둘 다 바뀜 | 효과 기호(검·방패)와 같은 말을 두 번 함 |
| 추천 | ○ | **추천** (지속·소멸은 판단에 쓰이고, 역할은 효과 기호와 겹침) | 역할을 참조하는 규칙이 생기면 |

## 3. 상태 체계

### 3-1. 레이어 (아래 → 위)

| 층 | 무엇 | 규칙 |
|---|---|---|
| L0 신원 | 이름, 속성 기호, 주인 얼굴, 윗선 | 어떤 상태에서도 모양·위치 불변 |
| L1 사용 가능성 | 몸체 가라앉힘 | 켜짐/꺼짐만. 그림 창·바탕에만 걸고 글자엔 안 걺 (XAG 102: 비활성 글자도 3:1) |
| L2 판단 정보 | 비용(+동전 테), 최종 수치, ▲▼, 사유 글 띠 | L1이 켜져도 읽힘 |
| L3 기회 신호 | 기믹 활성 (연속·점화·고집…) | L1이 켜지면 강조는 끄고 기호의 찬/빈 상태만 남김 |
| L4 일시 상태 | 호버·포커스, 집힘, 새로 뽑음 | 맨 위. 못 내는 카드도 포커스는 받음(사유를 읽어야 하니까) |

원칙 세 줄: 카드 하나에 눈을 끄는 채널은 하나만 · 판단 정보는 꺼지지 않고 기회 신호는 꺼질 수 있음 · 같은 뜻은 같은 자리(사유는 띠, 비용 변화는 동전).
사유 우선순위: 봉인 > 조건 미충족(싱크 등) > 대상 없음 > 마력 부족. 마력 부족은 채널이 달라(동전 테) 글 띠와 같이 보여도 돼요.

### 3-2. 기믹 활성은 어디에

**정령 단위(고집·각성·봉인·용맹) → 정령 묶음과 초상 홈. 카드 단위(연속·성장·장난·점화) → 숫자판과 비용 동전.** 손패가 정령별 묶음이라 정령 상태를 카드마다 칠할 필요가 없어요.

| 기믹 | 손패 표시 제안 |
|---|---|
| 연속 N | 숫자판 위 작은 칸 N개가 낸 장 수만큼 참 → 다 차면 추가 효과 기호가 숫자판에 나타남 |
| 성장 | 확정 ▲ 유지 + 누적 횟수 표기 여부만 결정 |
| 점화(대상 의존) | 손패: 조건 대상이 하나라도 있으면 "가능" 표시. 조준: 대상별 확정값 |
| 고집 | 묶음 위 정령 얼굴 옆 ×2 표식 (그 정령의 다음 카드가 복사됨) |
| 장난 | 비용 동전에 새 값 + 원래 값 취소선. 생긴 순간 한 번만 움직임 |
| 각성 | 그 정령 카드의 초상 홈이 각성체로 + 묶음에 남은 턴 수 |
| 봉인 | 묶음 전체에 한 번 "쓰러짐" 띠 + 카드 몸체 가라앉힘. 얼굴 처리 → 질문 Q1 |
| 용맹 | 따로 표시 없음 (▲와 계산 줄로 드러남) |

기믹 활성의 표현 강도 3안 (시안 페이지 3)
- **A. 칸 채우기**: 진행 칸·찬 기호만. 밝기 변화 없음. 가장 조용함
- **B. 기호 + 숫자판 한 단계 밝게**: 준비되면 숫자판 바탕이 한 단계 밝아짐 (빛 테두리 아님)
- **C. 기호 + 켜지는 순간 한 번 움직임**: 준비되는 순간 숫자판이 한 번 들썩, 그 뒤 정지. 반복 맥동 없음

### 3-3. 상호작용 가능 · 대상 유효
- "낼 수 있음"은 표시하지 않아요(기본). "못 냄"만 가라앉혀요. → StS·HS의 "낼 수 있음 빛"을 쓰지 않아 손패가 조용해요.
- 조준 중 유효 대상: 대상 판 둘레의 **모양 단서**(괄호·테·바닥 표식). 무효 대상엔 아무것도 없음. 전체 대상은 그룹 둘레에 하나.
- 결과 종류(쓰러뜨림·브레이크·끊김)는 미리보기에 **기호**로.

## 4. 상호작용 정의

카드의 일생: 뽑기 → 손패 배치 → 호버/포커스 → 집기 → 조준 → 사용(시전) → 해결 → 버림/소멸/지속으로 남음 → 섞기. 그 밖에: 생성(복사본), 봉인, 비용 변화, 성장, 보존.

컨트롤러 (제안): 좌우로 카드, 어깨 버튼으로 정령 묶음 점프, 확정으로 집기, 조준 시 유효 대상만 순회, 대상 없는 카드는 확정 한 번 더, 취소하면 같은 카드로 포커스 복귀. 못 내는 카드도 포커스는 받음.

## 5. 연출 구조

### 5-1. 등급 (위력이 아니라 의미로)
| 등급 | 언제 | 범위 |
|---|---|---|
| T0 UI 피드백 | 호버·포커스·집기·조준·사용 불가 | 카드 1장 |
| T1 일반 사용 | 피해·방어·회복·드로우 | 시전 정령 + 대상 |
| T2 결실 | 점화·빙결·브레이크·치명·연속 발동·끊기 | 대상 주변, 브레이크만 화면 살짝 |
| T3 각성 | 싱크 100% | 화면 전체. **이 등급은 각성 전용** |

희귀 카드라도 효과가 평범하면 T1이에요 (희귀도 연출 안 함 — 기각된 "반짝임·등급" 방향과 일치).

### 5-2. 카드 사용 연출 3안 (시안 페이지 4)
- **A. 카드가 날아간다** (장르 표준): 카드가 대상까지 날아가 사라짐. 가장 익숙함
- **B. 카드가 정령에게 돌아간다**: 카드가 주인 정령 초상으로 빨려 들어가고, 정령이 시전함. "정령이 배운 마법"을 매번 보여 줌. Spine 시전 모션이 주인공
- **C. 이름 띠가 풀려 나간다**: 카드는 손에서 녹고, 이름 띠 재질(용암석·유약·한지·비단)이 띠처럼 풀려 대상에 닿음. 재질 = 속성 문법을 움직임으로 확장

### 5-3. 속성 모션 동사 (재질이 움직이는 방식)
불(용암석): 달아올랐다 식으며 굳음 · 점화는 갈라진 틈으로 터짐
물(유약): 흘러내림 · 빙결은 흐르던 유약이 그 자리에서 멈춰 굳음
숲(한지): 결을 따라 스미고 번짐 · 성장은 결을 따라 한 칸씩 자람
바람(비단): 스치고 감김 · 연속은 앞 카드 수만큼 한 겹씩 감겼다 풀림
무(무지): 놓이고 눌림 · 브레이크는 실드 칸이 하나씩 빠지다 마지막 칸이 깨짐

### 5-4. 구현 구조 (Phaser 4 + Spine)
- 지금 코드: `Battle`이 상태를 바꾸며 `BattleEvent`를 쌓고, 씬이 `drain()`해서 `delayedCall` 누적 ms로 연출해요. 이미 로직/연출 분리 구조라 출발점이 좋아요.
- 제안: `BattleEvent[]` → **Director**(이벤트를 연출 스텝으로 번역) → **Sequencer**(직렬/병렬 스텝, 속도 배율·빨리감기·건너뛰기·모션 줄이기를 한곳에서) → 끝나면 화면을 게임 상태에 맞춤.
- 효과는 카드·키워드별 **레시피 데이터**(등급, 속성 동사, Spine 애니 이름). 40장 대부분은 속성 기본 레시피로 충분하고, 결실 키워드만 따로.
- 카드: Phaser Container + Filters(Glow·ColorMatrix 등은 호버한 1장에만). 정령·각성 컷인: Spine. Spine 애니의 `hit` 이벤트가 시퀀서에 타격 순간을 알려요.
- 마일스톤: M0 Spine 버전 정리 → M1 시퀀서·속도·모션 줄이기 → M2 손패 모션 → M3 레시피 4~6개 → M4 Spine 동기화 → M5 각성 → M6 다듬기·Deck 성능.
