## 고친 것 (v0.2)
- [플레이어·브랜드, 반대자 핵심] D1 성장 시안의 숫자가 셋 다 9였음 → 실제 공식으로 다시 계산. 유체 8 → 성체 8(6×1.4=8.4) → 각성 12. **성체 능력치 +1이 반올림에 묻혀 숫자로는 성장이 안 보인다**는 걸 확인 → 기획 질문으로 올림. 초상 홈(D1)만으로 부족하다는 반대 의견은 유효 → D1은 "확인용", 성장 순간 알림·D3(보상에서 정령별 값)가 주 신호라는 쪽으로 전략 문장 수정.
- [UX·플레이어·아트·접근성] B의 성질 기호가 그림 창 안 속성 기호 밑에 있었음 → 숫자판 안 맨 앞으로. 이름 띠 끝 희귀도 점(말줄임표로 읽힘) 삭제, 아래 받침(윤곽 변경) 삭제.
- [UX] 연속이 다 차도 추가 효과가 안 보였음 → 숫자판에 "×3" 표시.
- [UX] 고집 ×2가 대기인지 썼는지 모름 → "고집 · 다음 카드 ×2"(대기)로. 쓴 뒤 표시는 질문.
- [UX·접근성·플레이어] 장난 할인 카드가 원래 0비용이었고 취소선 원래값이 10px → 1비용 카드(순풍)로 바꾸고 원래 값을 동전 밖 글자로.
- [접근성] 모션 줄이기의 각성이 화면 전체 밝은 판으로 순간 전환 + 이름 대비 2.2:1 → 어두운 판 위 이름만, 더 오래. 기믹 C 들썩임이 페이지 토글을 안 따랐음 → 따르게.
- [아트] 빙결 막이 방패(돔)로 읽힘 → 흘러내린 모양으로.
- [브랜드] 쓰러짐/봉인 혼용 → 카드 위 글자는 "쓰러짐"(원인), 규칙 용어는 "봉인"으로 나눔.
