## 2. 결정별 합의와 추천

### 준비 표식 → 추천 **c(받침 줄)**, 아래 고칠 점 반영 조건
- 관할 안 4명 중 3명이 c. 근거가 서로 달라 독립적으로 모임: 연속 칸·효과 기호와 자리 다툼이 없고 칸이 움직이지 않음(UX), "밑줄 = 눈여겨볼 것"으로 읽혀 다른 뜻과 안 겹침(player), 면적이 가장 커 색 없이도 판독이 쉬움(a11y).
- **b는 지지 0, 서로 다른 문제 세 개**: ▼가 옆 카드의 ▲(오름)와 짝으로 읽혀 '내려감'으로 오해(PL-001, 심각도 3), 표식이 켜질 때 연속 칸이 옆으로 밀림(UX-002), 그림 창 침범 = R1 기각 사유와 같음(ART-003). 기각을 권해요.
- **a는 art-director의 선택**: 숫자판 경계 안에서 끝나는 유일한 안. 반대로 player는 접힌 모서리가 '남겨 둠'(보존)으로 읽힐 수 있다고 봄(PL-002). c의 약점(이름 띠 경계에 맞닿음, ART-004)은 줄을 숫자판 안쪽으로 옮기면 풀리므로, c를 고치면 art의 우려도 대부분 해소돼요.
- 세 안 공통으로 꼭 고칠 것: 호버·포커스 카드에 표식이 없음(UX-001, 심각도 3), 못 내는 카드의 흐린 표식 대비 1.6~2.0:1(A11Y-001, 심각도 3).

### 각성 중 카드 → 추천 **c(묶음 바탕 재질)**, 단 재질 규칙 예외를 Lucy가 승인할 때. 아니면 **a**
- c 3(player·a11y·brand) 대 a 2(game-ux·art). **충돌 카드**로 올려요.
  - c 쪽 근거: 입문자가 "이 정령 묶음이 지금 특별하다"를 한눈에 봄(player), 색이 아닌 결 단서 + 글 칩(a11y), 정령 단위 변화로 '함께 자라는 동료'를 보이면서 카드 몸체는 평소대로(brand). 0008의 "정령 단위 상태는 묶음에"와도 방향이 같음.
  - a 쪽 근거: 0008 규칙(머리표 + 초상 홈)을 그대로 따름, 호버 표지와 섞이지 않음(UX), 재질은 속성 전용이라는 잠금 규칙을 지키는 유일한 안(ART-002). 약점은 카드 단위 단서가 1.5px 강조색 테뿐(A11Y-005).
- **b는 지지 0**: 잠금된 "재질: 손패는 이름 띠, 호버 때 전체" 규칙을 깸(ART-001, 심각도 3), 손패가 가장 화려한 상태로 2턴 머묾(BR-003), 호버와 포커스 위치가 흐려짐(UX 선택 사유). 기각을 권해요.

### 모션 성격 → 추천 **가(가벼운 종이)**, 구조 축만 확정하고 시간 값은 TODO_TOKEN
- 4명이 가: 반응이 빠르고 동작 간 리듬이 일정(UX), "손에 든 카드"라 따로 배울 것 없음(player), 귀여움 2·아늑함 2·단순 2와 맞음(brand), 카드 몸체의 종이 계열 표면과 겉모습·움직임이 일치(art).
- a11y만 나: 회전·넘침이 없어 반복 동작의 전정 자극이 가장 적음. → 가를 택하되 회전·넘침 크기에 상한 토큰을 두는 규칙(A11Y-004)으로 수용 가능.
- **다는 지지 0**: 같은 동작이 속성마다 달라 예측성 저하(UX), 평상시 볼거리 증가로 '크게 움직이는 건 각성 한 번'이 약해짐(BR-002), 손패에선 띠에만 보이는 재질이 움직임 전체를 정함(art).
- **반대자 의견(UX-005)**: 세 성격의 차이는 코드상 전부 임시 파라미터(시간 배율·이징·기울기·착지)라, 느낌으로 고르면 임시 시간 값을 고르는 셈. 이번에는 ① 기울기 쓰나 ② 넘침 쓰나 ③ 속성별로 다르게 하나 — 세 구조 축만 정하고 시간은 실전 속도 테스트 뒤로. 추천안 "가"를 이 축으로 옮기면 ①예 ②예(상한 있음) ③아니오.

## 4. Lucy에게 남기는 것

1. **준비 표식**: 추천 c(고칠 점 1~4 반영). art-director의 a 선호와 player의 "a = 보존 연상" 지적이 맞서요. b는 기각 권장.
2. **각성 중 카드 a vs c (충돌)**: c를 고르시면 "정령 단위 상태에 한해 묶음 바탕에 그 정령 속성 재질을 쓴다"를 재질 규칙(0005)의 명시적 예외로 결정 기록에 남겨야 해요(ART-002). 예외를 원치 않으시면 a + 고칠 점 11.
3. **모션 성격**: 추천 가. 반대자 제안대로 이번엔 구조 축(기울기 예 / 넘침 예·상한 / 속성별 차이 아니오)만 확정하고 시간 값은 실전 테스트 뒤에 정할지.
4. **▲의 뜻 (PL-004 · BR-001 중복)**: 각성의 일시 오름도 성장과 같은 ▲를 쓸지. 0008 보류 "성장 용어 세 뜻"과 함께 결정 권장.
5. **대상 의존 준비(UX-003)**: 점화처럼 대상에 따라 달라지는 준비는 "조건을 만족하는 대상이 하나 이상 있음"으로 정의하고, 실제 대상별 확인은 조준 미리보기(R5)에 맡길지(기획 규칙).
6. **동사 통일(BR-004)**: 카드를 "낸다 / 쓴다 / 사용"이 섞여 있어요. 플레이어용 동사 하나를 정해 주세요(후보는 Lucy).
7. **player 시점**: 이번엔 지정이 없어 "장르 입문자"로 가정했어요. 숙련자 시점 리뷰가 필요하면 말씀해 주세요.
