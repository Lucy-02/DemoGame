# R2 — 카드 상태·상호작용·접근성 리서치

작성 2026-10-29 · 리서치용 문서예요. 시각 결정은 아니에요. 아래 "권고"와 "선택지"는 모두 Lucy 컨펌 전 제안이고, 색·크기·시간 값은 하나도 정하지 않았어요(정해지지 않은 값은 `TODO_TOKEN`).

## 요약

- 덱빌더 카드는 대략 **20가지 상태**(맥락 포함)를 오가요. 그런데 장르 공통 문법은 몇 가지뿐이에요. ① "낼 수 있음"은 테두리 빛으로, ② "조건 충족"은 그와 다른 빛으로(Hearthstone 초록/노랑, LoR 파랑/금색), ③ 바뀐 수치는 숫자 색으로, ④ 대상 지정은 화살표와 대상 강조로 보여 줘요.
- 이 문법은 대부분 **색 하나에 기대요.** Hearthstone은 색약 플레이어(Brian Kibler)를 위해 노란 빛을 다시 그렸고, Slay the Spire 1에는 색약 모드가 없어요. XAG 103과 GAG는 "색 말고 다른 단서 하나 더"를 기본 요건으로 둬요.
- 우리 프로젝트는 이미 색에 덜 기대는 쪽으로 정해 뒀어요. **몸체 가라앉힘(밝기) + 동전 테(모양) + 글 띠(글자)**예요. 남은 일은 기믹 활성, 수치 증감, 대상 유효성도 같은 원칙으로 **"모양/위치/글자 + 밝기"** 조합에 얹는 거예요.
- 상태가 겹칠 때는 레이어 규칙이 필요해요. **신원(이름·속성·주인)은 절대 안 바뀜 → 사용 가능성(몸체) → 판단 정보(비용·수치·사유, 가라앉아도 읽혀야 함) → 기회 신호(기믹 활성, 낼 수 있을 때만 강조) → 포커스(맨 위)** 순서를 권해요.
- 컨트롤러에서는 **"포커스 = 호버"**(확정)를 넘어서, 조준 단계의 포커스 모델(유효 대상만 순회, 확정/취소)도 정해야 해요. 지난 리뷰 세 안 모두 이 경로가 없었어요. StS·Wildfrost 플레이어 불만의 핵심도 "지금 뭘 고르고 있는지 모르겠다"였어요.
- Steam Deck 기준 글자는 1280×800에서 최소 9px, 권장 12px예요(Valve). 사용 불가 카드의 글자도 3:1 이상이어야 해요(XAG 102). 그래서 "흐림"보다 "가라앉힘 + 사유 글자"가 맞아요.
- 열린 질문 9개는 맨 끝 6장에 모았어요. 특히 **봉인 카드도 정령 얼굴을 컬러로 둘지**는 확정 규칙과 부딪쳐서 Lucy 판단이 필요해요.

출처 표기: [S숫자]는 맨 아래 출처 목록이에요. **"관찰"**이라고 적은 건 직접 플레이 경험이나 널리 알려진 화면에서 나온 내용인데, 이번 조사에서 1차 문서로 확인하지 못한 거예요. 시안에 쓰기 전에 스크린샷으로 다시 확인하는 게 좋아요.

### 1-2. 장르 공통 문법 정리

1. **"낼 수 있음"을 켜는 쪽이 "못 냄"을 끄는 쪽보다 흔해요.** (HS·LoR·StS 모두 가능한 카드에 빛을 켜요.) 우리는 반대로 **못 내는 카드를 가라앉혀요.** 손패 10장 중 대부분이 낼 수 있을 때 화면이 조용하다는 점에서 우리 톤("과한 장식 금지")에 더 맞아요.
2. **"조건 충족"은 "낼 수 있음"과 다른 단계로 따로 둬요.** HS 초록→노랑, LoR 파랑→금색, StS 푸름→금빛. 둘 다 '빛'이라 색으로만 갈려요. Hearthstone이 색약 때문에 노란 빛을 다시 손본 게 그 약점의 증거예요.
3. **바뀐 숫자는 "숫자 자체를 바꾸고 색으로 방향 표시"**(StS·HS). 방향(올랐나 내렸나)이 색에만 있으면 색약 사용자는 놓쳐요.
4. **대상 유효성은 "유효한 것만 강조"**(Skyweaver의 노란 오라). 결과 미리보기(Skyweaver 해골, MTGA 오토태퍼, StS 대상 위 숫자 갱신)가 판단 부담을 크게 줄여요.
5. **못 내는 이유를 글자로 알려 주는 게임은 소수예요.** StS는 '누른 뒤' 말풍선으로 알려 줘요. 우리 확정안(글 띠 상시 노출)은 이보다 한 단계 앞서 있어요.

### 2-2. 상태 표 (상태 → 뜻 → 흔한 표현 → 권장 중복 채널)

"권장 채널"은 **모양 / 위치 / 아이콘(기호) / 글자 / 움직임 / 밝기** 중 어느 것을 같이 쓸지예요. 색은 마지막 보조로만 써요. 구체 값은 하나도 정하지 않았어요.

|---|---|---|---|---|---|
| 1 | 기본(idle) | 정보만 있는 상태 | — | — | 기준선. 이 상태가 가장 조용해야 해요 |
| 2 | 낼 수 있음 | 마력·조건·대상 다 OK | 테두리 빛(HS 초록, LoR 파랑) | **표시 없음**(기본과 같음). 반대 상태를 가라앉혀서 대비를 만들어요 | 우리 확정안과 같은 방향 |

## 3. 상태가 겹칠 때: 우선순위와 레이어

### 3-1. 레이어 순서 (아래에서 위로)

| 층 | 무엇 | 규칙 |
|---|---|---|
| L0 신원 | 이름, 속성 기호, 주인 정령 얼굴, 그림 창 윗선 모양 | **어떤 상태에서도 모양·위치가 변하지 않아요.** 확정 규칙의 "정령 얼굴은 컬러"가 바로 이 층이에요 |
| L1 사용 가능성 | 몸체 가라앉힘 | 켜짐/꺼짐 두 단계만. 이유는 L2에서 말해요 |
| L2 판단 정보 | 비용(+동전 테), 최종 수치, ▲▼, 사유 글 띠 | **L1이 켜져도 읽혀야 해요.** XAG 102는 비활성 요소의 글자도 3:1 이상을 요구해요. 그러니 가라앉힘은 몸체(그림·바탕)에만 걸고 L2 글자에는 걸지 않는 구조를 권해요 |
| L3 기회 신호 | 기믹 활성(연속·점화·고집 등) | **L1이 켜지면 강조를 꺼요.** 다만 기호의 '찬/빈' 상태(정보)는 남겨요. 낼 수 없는데 '지금 내라'고 빛나면 모순이에요(HS·StS도 낼 수 있는 카드에만 빛을 켜요, 관찰) |
| L4 일시 상태 | 호버/포커스, 집힘, 새로 뽑음 | 맨 위. 못 내는 카드도 포커스를 받으면 확대해요(이유를 읽어야 하니까). 확대돼도 가라앉힘은 유지해요 |

### 3-2. 충돌 예시

| 겹침 | 보여 줄 것 | 근거 |
|---|---|---|
| 연속 준비 + 마력 부족 | 가라앉힘 + 동전 테. 연속 기호는 '찬' 상태로 두되 강조 없음 | L3는 L1에 눌려요. 다음 턴 계획에는 '찼다'는 정보가 쓸모 있어요 |
| 장난 할인(비용 -1) + 여전히 마력 부족 | 가라앉힘 + 동전 테 + **바뀐 비용과 취소선 원래 값** | 할인은 판단 정보(L2)라 꺼지지 않아요 |
| 성장 ▲ + 약화로 ▼ | 최종값 하나 + 기호 하나(순 방향만). 왜 그런지는 호버 계산 줄 | ▲▼를 둘 다 띄우면 작은 기호가 두 개가 돼요. 리뷰에서 이미 작은 ▼의 대비 문제가 나왔어요 |
| 봉인 + 마력 부족 | 봉인 사유만(글 띠). 동전 테는 생략 | 사유 우선순위: **봉인 > 조건 미충족(싱크 등) > 대상 없음 > 마력 부족**. 이번 턴에 풀 수 없는 이유가 먼저예요. 다만 마력 부족만은 모양 채널(동전 테)이 달라서, 글 띠와 '같이' 보여도 겹치지 않아요 → Q3 |
| 조건 미충족(싱크) + 마력 부족 | 글 띠("싱크 50 필요") + 동전 테 둘 다 | 채널이 달라서 겹치지 않아요. 둘 다 풀어야 낼 수 있다는 정보가 돼요 |
| 각성 중 + 연속 준비 | 각성 표시(정령 단위) + 연속 기호 찬 상태 | 각성은 정령 단위(L0 근처의 얼굴/묶음)이고, 연속은 카드 단위라 층이 달라요 |
| 조준 중 + 다른 손패 기회 신호 | 다른 손패의 L3를 잠시 꺼요 | 조준할 때 시선이 필드로 가야 해요 |
| 생성 카드 + 강화 | 생성 기호 + 강화 표식 둘 다(작게) | 둘 다 신원에 가까운 정보 |

### 3-3. 원칙 세 줄

1. **카드 하나에 '눈을 끄는 채널'은 하나만** 써요(움직임이든 밝기 강조든). 나머지는 기호 상태로 조용히 둬요. Ascension 불만("깜빡임이 읽기 힘듦")이 반례예요.
2. **판단 정보는 꺼지지 않고, 기회 신호는 꺼질 수 있어요.**
3. **같은 뜻은 같은 자리에.** 사유는 언제나 글 띠 자리, 비용 변화는 언제나 동전 자리. 전투 R4 리뷰에서 지적된 "같은 손패 안에서 사유 표시 규칙이 엇갈림"을 막아요.

## 4. 접근성

### 4-1. 색약 안전 인코딩

- **XAG 103**: 색으로 구분한 핵심 정보에는 모양·패턴·아이콘·글자 중 하나를 더해요. **회색 처리한 비활성 요소에는 두 번째 방법을 더해요**(Sea of Thieves 자물쇠, Forza "Not available" 글자). 색이 주된 지표라면 색을 바꿀 수 있게 해요. [S20]
- **GAG**: "Ensure no essential information is conveyed by a fixed colour alone"(시각, Basic). [S21]
- **사례**: Hearthstone은 노란 빛을 색약 플레이어 기준으로 다시 그렸어요[S2][S3]. StS1은 "색약 모드 없음"으로 기록돼 있어요[S22]. Balatro는 고대비 카드(무늬별 색 변경) 옵션을 둬요[S13].
- **우리 프로젝트에 적용**:
  - 사용 불가 → 밝기 + 모양(동전 테) + 글자(띠): 이미 세 채널이라 충분해요.
  - 수치 증감 → 초록/빨강에 기대지 말고 ▲▼ **모양**을 주 채널로 두고, 색은 보조로만.
  - 조건 활성 → '빛 색' 대신 **기호의 찬/빈 모양**을 주 채널로(4장 기믹 표).
  - 대상 유효 → 색 오라 대신 **테/괄호 모양**.
  - 속성(불/물/숲/바람/무) → 이미 기호로 정했어요. 재질 리뷰 지적대로 손패에서는 기호를 고정 위치에 둬요.

### 4-2. 모션 줄이기

- WCAG 2.3.3(AAA): 상호작용이 일으키는 움직임은 꺼질 수 있어야 해요. 내용을 보는 데 지장이 없어야 하고요. OS 설정을 따르거나 자체 토글을 둬요. [S23]
- GAG: "Avoid flickering images and repetitive patterns"(Basic), "Provide an option to turn off / hide background movement"(Intermediate), "Avoid any sudden unexpected movement"(Advanced). [S21]
- 장르 관례: StS·Balatro는 화면 흔들림 끄기, StS는 게임 속도 조절, Balatro는 CRT·그림자 끄기를 지원해요. [S13][S22]
- **권고**: 상태를 **움직임으로만** 알리는 일은 없게 해요. 움직임은 늘 '덤'이에요.
  - 새로 뽑음, 이동(버림·소멸) → 모션 줄이기 때 즉시 배치나 짧은 페이드
  - 호버/포커스 들림 → 위치 변화는 남기되 튕김 같은 보간은 생략
  - 기믹 활성 → 반복 맥동(펄스)은 쓰지 않아요. 모션을 켠 상태에서도 '바뀌는 순간 한 번'만
  - 각성 연출(유일하게 힘주는 장면) → 모션 줄이기 때 쓸 정지 화면 판을 따로 준비해요
  - 설정 이름과 단계(끄기/줄이기)는 `TODO_TOKEN`

### 4-3. 글자 대비와 크기

| 기준 | 내용 | 출처 |
|---|---|---|
| Steam Deck | 1280×800에서 가장 작은 글자 높이가 **9px 미만이면 안 되고**, 가능하면 **12px**를 권장. 30cm 거리에서 읽혀야 함 | [S24] |
| XAG 102 | 일반 글자 4.5:1, 큰 글자 3:1, **비활성 요소 글자 3:1**, 고대비 모드 7:1. 단색이 아닌 배경 위 글자는 **배경에서 가장 대비가 낮은 부분**으로 재요. 해결책으로 글자 뒤 단색 판이나 테두리를 둬요 | [S25] |
| GAG | "Use an easily readable default font size"(Basic), "Provide high contrast between text/UI and background"(Basic), "Allow the font size to be adjusted"(Advanced) | [S21] |

- **우리 상황**: 지난 리뷰에서 손패의 "기본 N"이 2.2:1, ▼가 1.78:1, 사유 띠가 10.5px로 나왔어요. 판단 정보(사유·증감·비용)는 **12px 권장선**을 목표로 하고, 익히는 정보는 호버 카드로 옮겨요(재질·전투 리뷰 결론과 같아요).
- 재질(용암석·유약·한지·비단) 위에 글자를 얹으면 XAG 102의 '가장 낮은 대비 지점' 규칙에 걸려요. → 재질 리뷰 결론대로 **글자 영역은 결 없이**.
- "가라앉힘"이 글자까지 흐리면 비활성 3:1에 걸려요. → 3-1의 L1/L2 분리를 권해요.

### 4-4. 호버에 기대지 않기

- 컨트롤러·터치에는 호버가 없어요. XAG 103과 GAG의 "Ensure that all areas of the user interface can be accessed using the same input method as the gameplay"(Motor, Basic)에 걸려요[S21].
- 전투 R4 리뷰에서도 세 안 모두 효과 설명, 실드 칸 뜻, 순서표 기호가 `title`·`:hover`에만 있었어요.
- **권고**: '호버 전용' 정보는 모두 **포커스로도 열려야** 하고, 판단 정보는 **애초에 호버 밖**에 있어야 해요(확정 정보 원칙과 같아요).

### 4-5. 컨트롤러로 손패 다루기

**사례와 불만**
- StS1: 출시 초기에 "키보드로 카드를 골라도 대상 지정·사용엔 마우스가 필요", "드래그 동작 때문에 손목 통증(RSI)"이라는 불만이 있었어요. 개발자는 "전체 키보드 조작은 할 일 목록에 있다"고 답했어요[S26]. 이후 패치 2.3에서 Steam Input을 전면 지원했어요[S27].
- StS 스크린리더 모드(Say the Spire): 포커스한 카드의 이름·비용·설명을 '버퍼'로 읽어 줘요. **대상이 없는 카드는 확정 버튼을 한 번 더 눌러야 나가고, 대상이 있는 카드는 대상을 고르면 바로 나가요**[S28][S29]. → 컨트롤러 확정 모델로도 쓸 만한 패턴이에요.
- Wildfrost: Switch 컨트롤러 사용자의 불만은 "뭘 고르고 있는지 분명하지 않음", "위를 누르면 아래 길로 순환됨", "실수 한 번에 런이 끝나니 되돌리기가 필요"였어요[S15]. 이후 BetaJester가 장면에 상관없이 쓰는 UI 상호작용 시스템을 따로 만들었어요[S14].
- Balatro: 버튼 여러 개 + 스틱 하나, 동시 입력 없음, 누르기 유지는 토글로 바꿀 수 있어요[S13]. 플레이어들은 정렬·선택 단축키를 더 원해서 QoL 모드를 써요[S30].
- MTGA: 실수로 탭했을 때 Z로 되돌려요[S9].

| 되돌리기 | 턴 안 마지막 행동 되돌리기를 둘지 → **기획 질문**(Q8) | |

- 못 내는 카드도 **포커스는 받아요**(이유를 읽어야 하니까). 집기만 막고, 집으려 하면 사유 띠를 한 번 강조해요(StS 말풍선의 역할).
- 버튼 기호는 입력 장치에 맞춰야 해요(Valve 요건: 쓰는 입력에 맞는 글리프)[S24].

### 4-6. 스크린리더·텍스트 대체

- GAG: "Ensure screen reader support, including menus & installers"(Advanced). XAG 103: 메뉴 그래픽에는 알맞은 대체 글자를 달고, 유니코드 기호의 기본 이름에 맡기지 마요(예: ▲가 '위쪽 삼각형'으로 읽힘)[S20][S21].
- 1인 개발 범위에서는 **전면 지원보다 '읽을 문장 데이터'를 먼저 갖추는 것**을 권해요. 카드마다 "이름, 비용(원래 비용), 최종 수치(기본 수치, 이유), 사용 가능 여부(사유), 활성 기믹"을 한 문장으로 만드는 함수가 있으면, 나중에 스크린리더(TTS)나 모드 지원, 툴팁 생성에 그대로 써요. `src/core`의 상태에서 파생되니 UI 교체와 상관없어요.

## 5. 이 프로젝트에 대한 권고

### 5-1. 확정 규칙 위에 얹기

확정: **"못 내는 카드 = 몸체만 가라앉힘, 정령 얼굴은 컬러. 마력 부족 = 비용 동전 테, 다른 사유 = 글 띠."**

이 규칙을 그대로 두고, 접근성 관점에서 시안 단계에 확인할 것:
1. **가라앉힘의 범위**: 그림 창·바탕만 가라앉히고, 이름·숫자판·비용·사유 띠는 그대로 두는지(L1/L2 분리). 비활성 3:1 기준[S25].
2. **동전 테의 모양**: 색만 다른 테가 아니라 형태가 다른 테인지(XAG 103의 '회색 처리 + 두 번째 방법'). 후보 형태 2~3개는 시안에서.
3. **글 띠의 자리**: 모든 사유가 같은 자리에 오는지. 글자 크기는 판단 정보 단계(12px 권장선 목표, 값은 `TODO_TOKEN`).
4. **"가라앉힘"의 방식**: 밝기만 낮추는지, 아래로 살짝 내려앉는 위치 변화도 같이 쓰는지(위치 = 색과 무관한 채널). → Q2

### 5-2. 기믹별 표현 제안

원칙: 기믹 활성은 **카드에 이미 있는 기호의 상태 변화**로 보여 줘요. 새 장식(빛 테두리, 반짝임)을 더하지 않아요. 반짝임은 보류됐고, 빛 테두리는 "휘황찬란 금지"에 걸려요.

| 기믹 | 카드 단위인가 정령 단위인가 | 손패에서 언제 켜지나 | 제안 채널 (2~3안, 고르기 전) | 조준 때 |
|---|---|---|---|---|
| **연속 N 준비** | 카드 | 이번 턴 앞서 N장을 냈을 때 | A. 연속 기호 옆 **N칸 진행 칸**(찬 칸 수 = 낸 장 수, 다 차면 준비) · B. 연속 기호 **빈 모양 → 찬 모양** 한 단계만 · C. B + 숫자판에 추가 효과 기호가 '나타남' | 추가 효과가 결과 미리보기에 포함 |
| **성장 누적** | 카드 | 이번 전투 누적이 있을 때 | 확정: 손패 ▲ + 호버 계산 줄. 남은 결정은 누적 횟수를 손패에 숫자로 둘지(▲만 vs ▲+N) | 최종 수치에 이미 반영 |
| **점화 (대상이 화상이면)** | 카드 × 대상 | **조건 대상이 하나라도 있을 때** (StS Dropkick 방식, 관찰) | A. 점화 기호 빈/찬 · B. 숫자판의 추가 수치를 '조건부' 표기(흐린 괄호)로 두다가 조건 대상이 생기면 실선으로 | **조건을 채우는 대상과 못 채우는 대상의 미리보기 수치가 달라짐** → 유효 대상 테에 '조건 충족' 하위 표식(모양)을 둘지 Q5 |
| **고집 (한 턴 두 번째 카드 복사)** | 정령 | 그 정령의 첫 카드를 낸 뒤 → 다음 카드가 '두 번째' | A. **정령 묶음 단위** 표식(묶음 위나 SD 초상 홈에 ×2 기호) · B. 해당 정령 카드 각각의 숫자판 옆에 복사 기호 | 결과 미리보기에 "2회" 표기 |
| **장난 (무작위 1장 비용 -1)** | 카드(결과) + 정령(출처) | 할인된 카드가 생긴 순간부터 | 비용 동전에 **바뀐 값 + 원래 값 취소선**(전투 R4 리뷰 권고). 출처(장난)는 호버 계산 줄에 글자로. 할인이 생긴 순간 한 번만 움직임 | — |
| **각성 (싱크 100%, 2턴)** | 정령 | 각성 중 2턴 | 유일하게 연출에 힘주는 장면. 카드 쪽은 **정령 단위**로: A. SD 초상을 각성 초상으로 교체 · B. 정령 묶음에 남은 턴 수(글자) · C. A+B. 카드 몸체엔 손대지 않음 | — |
| **봉인 (정령 쓰러짐)** | 정령 | 쓰러진 순간부터 | 글 띠("봉인" 또는 "○○ 쓰러짐") + 몸체 가라앉힘. **정령 얼굴 컬러를 유지할지가 확정 규칙과 충돌** → Q1. 손패가 정령별 묶음이니 **묶음 전체를 한 번에** 표시하는 안도 가능 | 집을 수 없음 |
| **싱크 조건 (싱크 50 필요 등)** | 카드 | 조건 미충족일 때 | 확정: 글 띠 | — |
| **용맹 (HP 절반 이하 파워 +30%)** | 정령 | 조건 충족 시 | 최종 수치 ▲로 이미 드러나요. 이유는 호버 계산 줄. 따로 표시하지 않는 쪽을 권해요 | — |
| **약점 상성** | 카드 × 대상 | 조준 시 | 손패에서는 표시 안 함(대상 의존). 조준 시 결과 미리보기에 **실드 칸 깨짐**(전투 R4 리뷰: 색 아닌 채움/빗금으로) | 실드 미리보기 |

**표에서 나온 일반 규칙**
- **정령 단위 상태(고집·각성·봉인·용맹)는 정령 묶음이나 SD 초상에, 카드 단위 상태(연속·성장·장난·점화)는 숫자판·비용 동전에.** 손패가 정령별로 묶이는 확정 구조 덕에 정령 상태를 10장에 반복해 칠할 필요가 없어요. 장식이 줄어요.
- **대상에 따라 갈리는 조건(점화·상성)은 손패에서는 '가능성'만, 조준할 때 '확정값'을.** StS도 손패에서는 "조건을 채우는 적이 하나라도 있으면" 금빛을 켜는 쪽이에요(관찰).

### 5-3. 상호작용 가능 / 대상 유효

| 상황 | 제안 |
|---|---|
| 손패의 '낼 수 있음' | 표시하지 않아요(기본 상태). '못 냄'만 가라앉혀요 |
| 조준 중 유효 대상 | 대상 판 둘레에 **모양 단서**(괄호, 테, 바닥 표식 중 2~3안). 무효 대상엔 아무것도 없음 |
| 조준 중 무효 대상에 커서/포커스 | 커서는 '안 됨' 모양, 이유는 글자(예: "앞열만"). 컨트롤러는 무효 대상을 건너뛰어요 |
| 전체 대상(적 전체/아군 전체) | 대상 하나하나가 아니라 **그룹 둘레**에 하나. 확정 한 번으로 사용 |
| 자신 대상 | 집으면 주인 정령 판에 유효 표식. 대상 없는 카드처럼 확정 한 번 더 |
| 결과 종류(쓰러뜨림·브레이크·차징 끊김) | 미리보기에 **기호**로(Skyweaver 해골 패턴). 색에 기대지 않기 |

### 5-4. 덱 보기·보상·상점

- **덱 보기(전투 밖)**: 사용 가능성·조건 활성은 없어요. 강화·성장 영구분, 주인 정령, 봉인(전투 중 더미 보기에서만)을 보여요.
- **수치를 기본값으로 보일지, 정령 능력치를 반영한 값으로 보일지**: 브랜드 훅("정령을 키우면 덱이 자란다")을 생각하면 반영값이 의미 있어요. 다만 StS는 덱 보기에서 기본값을 보여 줘요(관찰). → Q6
- **보상**: 새 카드는 '주인 정령'과 '그 정령 능력치 반영값'이 판단 정보예요. 강화판 미리보기를 둘지는 Q7.
- **상점**: 감당 못 하는 가격은 **가격 글자 + 밝기**로 보여 주고, 카드 몸체는 가라앉히지 않는 쪽을 권해요. 전투의 '못 냄'과 같은 표현을 쓰면 두 뜻이 섞여요.
