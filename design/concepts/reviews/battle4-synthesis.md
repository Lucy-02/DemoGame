# 전투 R4 리뷰 종합 (게임 UX · 플레이어 · 접근성 · 브랜드)

## 한 줄
UX·플레이어·접근성 셋 다 **C(판단 동선)**를 뼈대로 추천. 브랜드는 "A의 성장 표시 + B의 정령 존재감 + C의 받을 피해 미리보기" 조합을 추천.

## C를 뼈대로 할 때 먼저 고칠 것 (여럿이 겹침)
1. 조준하지 않은 적에도 결과가 떠서 단일 공격이 전체 공격으로 읽힘 → 결과는 조준 대상에만 (UX 3, 플레이어 3)
2. "받을 피해"가 쉬는 상태에서 사라짐 → 늘 보이게 두고, 카드를 들면 그 자리에서 a→b (UX 2, 플레이어 2)
3. 호버만 / 집기·조준 / 범위·무작위 / 아군 대상 카드 상태 정의가 없음 (UX 2)
4. 못 내는 카드에서 정령 얼굴까지 회색 → 카드만 가라앉히고 얼굴은 유지 (브랜드 2, 플레이어 1)
5. 판 없는 필드 보조 글자 대비 3.2~4.4:1, 끊긴 차징 흐림 2.4:1, 실드 칸 상태가 색으로만 구분 (접근성)
6. "끊김"이 네 곳에 동시에, 호버 순간 강조가 많음 → 한 곳 + 취소선, 우선순위로 단계 표시 (UX 1, 브랜드 1)

## 세 안 공통
- 적·아군에 컨트롤러 포커스가 닿지 않아 대상 지정 경로가 없음 (UX·접근성, 다음 라운드 필수)
- 차징을 끊기까지 남은 실드 칸 수를 늘 보이게 (UX·플레이어)
- 약화 "↓2"가 공격 알약과 같은 모양이라 피해로 읽힘 (플레이어)
- 사용 불가 카드 흐림으로 이름·수치 대비가 3.21:1로 떨어짐 → 흐림보다 사유 표시 (접근성)
- 아군별 받을 피해 합계 (A·B에 없음, C는 카드 들 때만)

## 다른 안에서 가져올 조각
- A: 손패 ▲ 성장 표시 + 호버 계산 줄(훅 "키우면 덱이 자란다"의 증거), 적 호버 정보판(이름·끊기 규칙 배우는 곳), "마력 부족은 동전 테·다른 사유만 글 띠" 규칙, "덜어 낸 정보가 간 곳" 표
- B: 큰 정령 무대(애착) — 단, 단계별로 자리 크기가 달라지는 정의 필요(유체도 서 보기), 순서표 마디의 차징 양 표시, 판 안 취소선 미리보기 표기

## 기획 확인 필요
- C 미리보기는 의도 고정(질문 7)과 실드 칸 규칙(질문 5)에 기댐
- 카드 초상이 지금 성장 단계를 따라가는지 (브랜드)
