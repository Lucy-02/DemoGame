# R4 정령 화면 — 게임 UX 리뷰어
1. [3] 성장 배지 흐름 엇갈림: s5 ↑ 배지가 정원 탭에, 키우기 버튼은 개요에 → 타일→탭→버튼 끊김. 배지 탭과 행동 버튼을 같은 탭에.
2. [3] 컨트롤러 탭 조작 불가: role=tab span, tabindex 없음, LB/RB 안내 없음. 범퍼=탭, 십자키=띠.
3. [2] 타일만으로 상태 구분 어려움: s1 세 타일 ◆◆◆·막대 가득 동일, 배지 종류도 툴팁 필요. 최종 단계 막대 별도 상태, 배지 종류 무툴팁 구분.
4. [2] 개요 대표 버튼 "카드 보기" = 탭 이동 중복. 실행 동사(그 자리에서 배우기)로.
5. [2] 남은 개발 용어·빈 값: "보정 +13", "각성 효과 —", "예시 A~E/예시 유체". 툴팁·메모 레이어로.
가장 큰 위험: 성장→정원→개요 배지 엇갈림으로 어디서 키우는지 못 찾음.
