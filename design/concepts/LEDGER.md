- 마력·턴 종료: 관례형 분리
- 카드: 그림 창 + 얇은 이름 띠, 5:7, SD 초상 홈, 정령별 창 윗선, 기호+숫자판, 손패는 단색 속성 기호. 재질은 손패 이름 띠 → 호버 시 카드 전체. 불=밝은 용암석, 물=유약, 숲=한지+잎맥, 바람=비단. 반짝임 보류

- 기각: 작전판, 테이블 위 카드 게임
- **카드 전략 R1 (Lucy 2026-10-29 20:13, 0008)**: 성질(지속·소멸·보존) = 숫자판 맨 앞 작은 단색 기호. 희귀도 = 손패 없음, 보상·상점·덱 보기에서 카드 아래 점 개수. 역할 = 카드에 표시 안 함. 기믹 준비 = 숫자판 모서리 준비 표식(모양, 색·밝기 안 씀), 연속 다 차면 추가 횟수. 정령 단위 상태는 묶음 머리표·초상 홈. 카드를 내면 주인 정령에게 돌아감(→ 0010에서 대체). 쓰러진 정령 = 묶음 "쓰러짐" 띠 하나 + 포커스 카드에 사유, 얼굴 컬러. 카드 스레드 범위는 카드 자체 표기·모션(스킬 이펙트 밖). 정본 https://claude.ai/artifact/5mqvjk7SG4Di2wzm5yzFkN
- **카드 R2 (Lucy 위임, 0009)**: 준비 표식 = 숫자판 안쪽 받침 줄(못 내면 속 빈 줄). 해방 중 = 묶음 바탕이 그 정령 재질 + 초상 홈 테 + "남은 N턴"(재질 규칙 예외). 카드 모션 = 가벼운 종이(기울기·넘침 상한, 속성별 차이 없음, 시간 값 TODO). ▲ = 원인 무관 오름. 대상 의존 준비 = 조건 대상 하나 이상.
- **카드 R3 (Lucy 20:54, 0010)**: 준비 켜짐 = 빛이 한 번 쓸고 지나감 → 받침 줄(반짝임은 "준비됨" 전용). 흔들림·기울기·들썩임 없음. 카드가 정령에 들어가지 않음. 추천 적용(확인 대기): 빛 범위 s1 카드 전체, 사용 u2 제자리에서 빛으로 풀림.
