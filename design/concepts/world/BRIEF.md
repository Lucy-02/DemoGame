# 세계관 시안 공통 브리프 (S3 R1, 2026-10-30)

조사 R2 §7(권장 워크플로)의 1단계예요. **전제·테마·톤 경계·하드 규칙**까지만 정해요. 지도·연표·세력·각성체 기원 신화·엔딩은 미뤄요. 세계관·스토리·네이밍은 Lucy가 정하고, 여기서는 서로 다른 축의 시안을 펼쳐요.

## 고정 조건 (바꾸지 않음)
- 브랜드: "함께 자라는 동료", 훅 "정령을 키우면, 덱이 자란다" (0003, `design/BRAND_BRIEF.md`). 성격 슬라이더 귀여움2·아늑함2·동화적2·겉인상 단순2·플레이 깊이3. 유체·성체는 이 톤, 각성체는 우아·장엄한 성숙 인간형.
- 메인 포인트 C 발견, 필러 "동료" 넷, 코어 판타지 가("보호자"는 자리표시) → `docs/design/01-vision.md`, `02-pillars.md`, 0021.
- 메커닉이 이미 말하는 것(R2 §5.2): 기절하면 그 정령의 카드가 봉인됨(상호의존) / 카드를 쓸수록 싱크가 오르고 100%면 각성(유대의 축적) / 유체→성체 때 성격 공개(발견) / 기절해도 HP 1로 돌아옴(죽지 않음) / 정원 돌봄이 싱크·호감도로(돌봄이 힘).
- 세계 하드 규칙 후보(이미 결정된 규칙을 세계 말로 옮길 것): 속성 9종, 상성 고리 A 물>불>숲>땅>전기>얼음>물 + 바람 중립 + 빛↔그림자(0023) / 막 = 지역, 지역마다 속성 제한(0023) / 성체에서 한 번 갈림, 배운 카드가 갈래를 엶(0022) / 정령 43줄, 출시 15줄(0024) / 정원↔탐험.
- 플레이어: 정령 셋을 데리고 탐험, 정원에서 돌봄. 세계 안에서 누구인지는 **시안이 제안**해요(정원지기? 함께 자란 아이? 이름 없는 손?).
- 서사 범위: 사다리 1단계(도감 + 바크 + 이벤트 10~15개, 1.5만~3만 자)를 기본값으로 가정. 그보다 큰 서사를 요구하는 전제는 피해요.
- 원칙: "전투에서 쓰이는 것은 하드, 정원 바깥의 기원은 소프트"(R2 §3.3). 빙산 — 알고도 쓰지 않는 것을 최소로.

## 시안마다 담을 것 (형식 고정)
1. **로그라인** 1문장 + 전제 2~3문단
2. **플레이어는 누구인가** 1문단 (코어 판타지의 "보호자" 자리를 무엇으로 채우나)
3. **컨트롤링 아이디어** 1문장("[원인]이 [가치 변화]를 이끈다") + 반대 명제 1문장
4. **메커닉 일치표**: 위 메커닉 5개 각각이 테마를 강화/중립/위배하는지 한 줄씩
5. **톤 경계**: "절대 보여주지 않는 것" 5개 이상 (예: 정령이 죽는가, 적은 악인가 오염인가, 정령은 말하는가)
6. **하드 규칙 5~7개**: 상성 고리(특히 "전기가 얼음을 깨뜨린다" 한 줄), 싱크·각성, 기절·봉인, 성장 단계와 갈래, 정원↔탐험, 막 = 지역. 각 규칙은 게임 규칙 ↔ 세계 설명 두 줄.
7. **소프트로 남기는 신비** 3개 (일부러 답하지 않는 질문과 내부 답 한 줄)
8. **1막 지역 한 줄**: 불·숲·바람 적이 나오는 지역의 정체성(실재 풍토 모티프 하나)
9. **샘플 도감 2개**: 불여우 유체·성체 (각 100~200자)
10. **샘플 바크 5줄**: 런 시작·각성·기절·런 종료·진화 (정령이 말하는지 아닌지는 시안이 정함)
11. **용어 2개**: 세계 안에서 "덱"과 "각성"을 뭐라 부르나 (게임 UI 용어는 바꾸지 않음, 세계관 용어만)
12. **이 시안이 잘하는 것 / 포기하는 것** 각 2~3줄, **비용**(서사 분량 추정, 아트·시스템에 요구하는 것)

## 시안 축 (서로 다르게)
| 시안 | 축 | 한 줄 |
| --- | --- | --- |
| W1 정원 | 정원 중심 · 서로를 지킨다 · 말 없는 정령 · 단일 화자 없음 | 세계가 고장 난 게 아니라, 정원이 자라는 이야기 |
| W2 여정 | 여정 중심 · 세계를 고친다 · 말하는 정령 · 단일 화자 있음 | 불균형이 번진 땅을 정령들과 되돌리는 순례 |
| W3 계절 | 순환 중심 · 아무것도 고치지 않는다 · 정령은 소리만 · 화자 = 정원 | 여섯 원소가 한 바퀴 도는 계절의 세계, 탐험은 계절 따라가기 |
| W4 기억 | 발견 중심 · 잊힌 것을 기억한다 · 정령은 성체부터 말함 · 화자 = 각성체 | 정령은 잊힌 이름이고, 자라면서 자기 이름을 되찾는다 |

## 규칙
- 이름(정령·지역·고유명)은 모두 임시예요. `TODO_NAME`을 달아요. 음차 금지(0018).
- 기존 결정(0003~0024)과 충돌하면 충돌을 숨기지 말고 "부딪히는 곳" 절에 적어요.
- 분량: 시안 하나에 한국어 2,000~3,500자. 길면 잘라요.
- 산출물: `design/concepts/world/W{n}-<축>.md`. 결정은 Lucy가 조각 단위로("W2의 전제 + W3의 상성 설명") 골라요.
