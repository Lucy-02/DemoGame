# 전투 상단 해결 순서표 — 규칙 질문과 답

규칙은 `docs/design-decisions/0036-battle-flow-timeline-in-turn.md`, 표기는 `0038-resolve-table-notation.md`가 정본이에요.

1. 카드 사용과 적 행동이 섞이나요? → 섞여요. 한 턴 안에서 정령별 줄과 적 행동이 시간 순서대로 풀려요. 계획 후 재생(놓을 때 미리보기, 턴 종료 때 재생).
2. 상태(화상·약화·취약·냉기)는 턴 시작에 줄어드나요, 턴 끝에 줄어드나요? → 턴 경계 규칙은 지금 코드 그대로예요. 시간축 위의 시점은 미정(`TODO_TOKEN`).
3. 적 행동 순서는 무엇으로 정하나요? → 적 행동마다 박히는 시점이 데이터로 정해져 있어요. 한 턴에 몇 번 움직이는지는 적마다 달라요. 같은 시점이면 아군 먼저(확정), 적끼리는 왼쪽 먼저(제안).
4. 행동을 늦추거나 당길 수 있나요? → 적 밀기가 있어요(교란 역할). 아군 쪽 조작은 희귀 카드에만. 밀린 행동이 축 끝을 넘으면 다음 턴 첫 시점부터. 빙결 같은 상태 기믹은 따로 정해요.
5. 차징은 어떻게 보이고, 끊기면 어떻게 빠지나요? → 적 줄 위의 막대로 보이고 막대 끝에서 터져요. 브레이크(카드 효과)로 취소돼요. 순서표에는 끊김 예정이 보여요(0038).
6. 다음 턴 시작에 터지는 지연 효과 카드가 있나요? → 미정(`TODO_TOKEN`).
7. 적 의도는 턴 시작에 고정되나요? → 턴 시작에 시간축에 박혀요.
8. 순서표의 단위는 무엇인가요? → 촘촘한 시간 값(카드 기본 시간 ÷ 정령 스피드)이고, 화면에는 값 없이 끝나는 순서만 보여요(0038).
