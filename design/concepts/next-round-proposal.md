# 다음 라운드 제안: "자라는 순간" (2026-10-29)

근거: research/screen-flow.md (연구), reviews/flow-ux.md · flow-player.md (컨펌, 둘 다 조건부 동의)

## 진단
- 화면 26개 중 확정 4개(정령 관리·지도·전투·보상). 모두 한 판 안 또는 정원 안이에요.
- 판과 판 사이 경계 화면(런 종료, 해금 알림, 성장 연출, 출전 준비)이 통째로 비어 있어요. 훅 "정령을 키우면, 덱이 자란다"가 실제로 보이는 곳이 여기예요.

## 제안 범위
1. 런 종료 (클리어와 실패 같은 무게) — "이번 판에서만 쓴 것"과 "정령에게 남는 것"을 나눠 보여 줘요.
2. 해금·성장 알림 — 무엇이 달라지는지("이제 보상 후보에 나와요")를 말해요. 다음 판 보상에서 "새로 열린 후보" 표시와 이어져요.
3. 성장 연출 유체 → 성체 (필수) — 성격 공개, 능력치 변화, 바뀐 카드 수치까지 이어요.
4. 출전 준비 (조건부) — 앞열과 시작 덱 확인만. 시작 덱은 장수 대신 "지난 출전보다 바뀐 수치"(전투의 a→b·▲). 기각한 출전 편성 모드 E를 되살리지 않아요.
- 공용 조각(먼저): 덱 보기 레이어(카드 제거 겸용), 큰 카드 상세.
- 모든 시안: 런 종료에서 키우기까지 몇 번 누르는지 적고, 끝에 "다음 할 일" 하나. 컨트롤러 포커스 순서와 취소는 메모로.

## 막는 질문 (Lucy)
1. 탐험이 끝나면 무엇을 가져오나요? 실패해도 남나요? (Q1)
2. 레벨(Lv2·Lv3)이 따로 있나요? (Q2)
3. 유체 → 성체 진화는 언제? 정원에서 키우기 / 탐험 중 조건 / 런 종료 정산 (Q3)
4. 해금은 런 종료에서 바로? 정원에서 "받기"? (Q5)
5. 탐험 전에 앞열을 고르나요? (Q4·Q7, 출전 준비 화면 필요 여부)
6. 보상 화면도 다크로 맞추나요?
7. 시안에 쓸 정령 이름: 이그니·테스투·실바(MVP 데이터) vs 불·별·해파리 정령(받은 일러스트)?

## 미뤄 두는 것
- 안 2 "길 위의 칸들"(상점·이벤트·휴식): 장르 관례로 수렴하기 쉬워 뒤로. 단 덱 보기·큰 카드는 공용이라 먼저.
- 안 3 "정원으로 들어가는 문"(타이틀·허브·도감·설정): 게임 이름과 정원 형태(Q6) 뒤로.
- 지도 시안의 "유물" 표기는 기획서에 없음 (Q9).
