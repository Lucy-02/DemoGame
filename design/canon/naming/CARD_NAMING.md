# 카드 네이밍 규칙 (정본)

- 상태: Lucy 결정 2026-10-30 (`docs/design-decisions/0016-card-naming-rules.md`). 조사 근거: `docs/research/core-design/R4-card-naming.md`
- 적용 범위: 카드 이름(한국어·영어). 정령·적·상태 이름은 따로 정해요.
- 이 문서는 규칙만 적어요. 예시 이름은 전부 예시이고 확정이 아니에요.

## 1. 등급 사다리 — 올라갈수록 몸짓에서 이름으로

이름만 늘어놓아도 등급이 들리게 해요. 아래는 기본에서 희귀로 가는 네 칸이에요.

| 등급 | 꼴 | 어휘층 | 예시 |
| --- | --- | --- | --- |
| 기본 | 고유어 동사 명사형 **"○○ ○○기"** | 고유어. 정령의 몸짓이 보이는 말 | 불꽃 할퀴기, 안개 불기 |
| 일반 | "~기" 동사형, 또는 짧은 고유어 명사구 | 고유어. 동화적 비유 허용 | 불씨 튕기기, 안개 이불 |
| 고급 | 명사구. **"~기" 금지** | 고유어 + 한자어 | 유리 파편, 한기 물결 |
| 희귀 | **고유명사·문어**. 틀 없이 한 장씩 지음 | 한자어·문어·세계관 고유명 | 만년설, 불사의 숨결 |

- 기본·일반은 기능이 읽히는 것이 먼저예요. 동작(할퀴기·불기·깔기)이 효과와 어긋나면 안 돼요.
- 고급부터는 "그 기술이 남기는 것"을 불러요. 동작 대신 장면·물건·현상이에요.
- 희귀는 그 카드만의 이름이에요. 같은 틀로 두 장을 짓지 않아요. 각성체 일러스트와 같은 말씨(우아·장엄)예요.
- 희귀의 고유명사는 세계관(S3)에서 가져와요. 세계관이 정해지기 전에는 임시명으로 두고 `TODO_NAME`을 달아요.

## 2. 어휘 경계

- **공용 카드는 속성 어휘만** 써요(불씨·불꽃·안개·물결). 불 카드는 불여우와 유리 도롱뇽이 함께 배우니, 어느 손에 가도 어색하지 않아야 해요.
- **정령 어휘는 전용 해금 카드(Lv2·Lv3·성체)에만** 써요(불여우 = 꼬리·여우불, 유리 도롱뇽 = 유리·비늘, 안개 고양이 = 수염·발바닥).
- 속성 어휘는 속성을 넘지 않아요. 물 카드에 불 어감 금지. 물·얼음, 불·전기, 바람·숨처럼 가까운 속성 사이 어휘는 상성 구조를 정할 때 같이 나눠요.

## 3. 예약어

기믹·키워드·역할·능력치에 쓰는 말은 카드명에 쓰지 않아요. 쓰면 그 효과가 반드시 있어야 해요.

- 키워드: 화상, 냉기, 빙결, 약화, 취약, 도발, 가시, 방어도, 강화, 점화, 연속, 고집, 장난, 각성
- 역할: 수호, 공격, 보조, 교란
- 능력치: HP, 파워, 가드, 포커스, 싱크
- 지금 위반: 카드 "점화"(ignite)는 기믹 "점화"와 같은 말이라 개명 대상이에요.

## 4. 길이와 소리

- 기본이 가장 짧고, 위로 갈수록 길어질 수 있어요. 상한은 카드 이름 띠 실측으로 정해요: 한국어 공백 제외 `TODO_TOKEN`자, 영어 `TODO_TOKEN`자.
- 라틴어·영어 **음차는 쓰지 않아요**(인첸디움·아비수스·플람마 플루마 같은 꼴). 성공작 표본에서 음차는 소수이고, 우리 현행 이름 중 긴 것은 거의 음차였어요. "간지"는 한자어·문어·세계관 고유명사로 내요.
- 소리 내어 읽기 쉬워야 해요. 받침이 몰려 뭉개지거나 다른 말로 들리면 바꿔요.

## 5. 중복 금지

- 게임 안의 다른 카드·정령·적·상태·기믹·UI 문구와 같은 이름 금지.
- 다른 유명 게임의 대표 카드·기술명과 같은 이름 금지(검색하면 그쪽이 먼저 나와요). 지금 해당: second_wind(스파이어·하데스), 버티기(포켓몬), 돌진.

## 6. 영어명

- 기본~고급: 한국어 뜻을 옮겨요(Flame Swipe, Glass Shards). 1~2단어.
- 희귀: 영어로 따로 지어요(Everfrost, Undying Breath). 한국어 희귀명과 같은 격이면 돼요.

## 7. 운영

- 네이밍 시트: `design/canon/naming/cards.csv` (작업명 · 등급 · 속성 · 공용/전용 · 한국어 · 영어 · 글자 수 · 검사 통과 여부 · 메모). 이름은 시트에서 정해지고 `src/data/cards.json`은 시트를 따라가요.
- 한 장씩 검사하는 체크리스트는 R4 6.2(길이·기능·예약어·공용/전용·중복·발음·맥락·검색·상표·영어)예요.
- 순서: 길이 상한 실측 → 예약어 목록 확정(위 3절) → 속성·정령 어휘 표 → 카드 40장 1차 → 영어명 → 검사 → 결정 기록.

## 8. 아직 정하지 않은 것 (기본값 제안)

| 항목 | 기본값 제안 | 이유 |
| --- | --- | --- |
| 띄어쓰기 | 띄어 써요 (불꽃 할퀴기) | 읽기 쉬움. 포켓몬식 붙여 쓰기는 고유명사 느낌이 강해 희귀에만 어울림 |
| 강화 카드 표기 | 이름 뒤 "+" | 스파이어 관행, 이름을 다시 짓지 않아도 됨 |
| 분기 진화 뒤 전용 카드명 | 유지 | "같은 동료가 자란다"를 지킴. 진화 구조가 정해지면 다시 봐요 |
| 카드 동사 (UI 문구) | "낸다" | 0009 열린 항목. 카드명 규칙과는 별개 |
