# 정령 한 장 템플릿

새 정령은 이 한 장을 채워야 데이터에 들어가요. 이름·아트는 Lucy 몫이고, 진화·세계관 칸은 그 결정이 난 뒤에 채워요. 빈 칸은 `TODO`로 남겨요.

```
# <이름> (<key>)
- 속성 · 계보 · 역할 · 몸 형태(애니메이션 템플릿용, 아트 아님)
- 전투 정체성 한 문장: 이 정령이 파티에 있으면 전투가 어떻게 달라지나
- 능력치: HP / 파워 / 가드 / 포커스 / 싱크 (합계), 성체 주 성장 2개
- 각성 (2턴): 한 줄
- 전용 카드 3장: Lv2 / Lv3 / 성체 (이름·효과·기준선 대비)
- 이 손에서 빛나는 공용 카드 2~3장
- 짝과 약점: 같이 두면 좋은 역할, 혼자면 막히는 상황
- 분기 진화 가설: 조건 2~3개 (이름 없음, 진화 구조 결정 뒤 확정)
- 세계관 자리: TODO (S3)
- 아트 메모: Lucy
```
